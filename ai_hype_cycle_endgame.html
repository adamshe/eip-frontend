3. 合理 CAPEX 算法

3.1 Sustainable CAPEX 公式

Sustainable_Annual_CAPEX = Compute_Margin * Revenue * Asset_Life 其中: Compute_Margin = 计算基础设施在 LLM 价值链中能拿走的 margin ~30-50% Revenue = 行业级 LLM revenue (steady-state) Asset_Life = GPU 经济寿命 (年), 取 3-5 (technically) 或 5-6 (accounting)

3.3 AI 文明进步前提: 收税企业 40% margin floor

AI 不是 narrative 是 infrastructure layer. Infrastructure 由 收税企业 承载 -- NVDA (compute 税) + MU (memory 税) + TSM (foundry 税) -- 每个 AI workload 经过都抽水. AI 文明持续推进的前提是这些收税企业能持续 fund 下一代 R&D + CAPEX (Rubin / B400 / HBM4 / 18A foundry节点).

Margin floor 机制:

  • ~40% net margin 是 "收税企业" 必须门槛. 40% 是 sustainable CAPEX 公式里 compute_margin 中位 (见 3.2 Base case 40%) -- 不是 arbitrary, 是 sustainability 数学 derived 的下限
  • 跌破 40% = R&D + 下一代 fab + EUV 设备投入不能 self-fund = 必须靠外部融资 (政府 / 主权 / 借债) = infrastructure 进步停滞 OR 全 commoditize
  • NVDA: 当前 gross margin ~75% / operating margin ~65% (FY2026 guidance) -- 远超 floor, fund Rubin / Vera Rubin / Feynman 三代路线毫无压力
  • MU: HBM cycle peak 阶段 gross margin ~40-45% (vs 历史 commodity DRAM 5-15%) -- 刚到 floor, 一旦 HBM 价跌或 cycle 拐 -> margin 回到 25-30% = 跌破 floor = HBM4 / 1c node 投入受限
  • SNDK: 纯 NAND commodity, gross margin 25-30% peak -- 永远在 floor 之下, 这就是为什么 SNDK 没有 NAND 下一代 ramp capability, 行业 NAND 进步靠 Samsung/SK Hynix integrated 模式 + 政府补贴
  • TSM: gross margin ~55-60% peak -- 远超 floor, 这是为什么 2nm/A16 节点能持续推进

Thesis implication: 任何 AI 概念股票, 检查它在价值链上的 margin 位置. >40% = 真收税 = LONG 候选 (周期内); <40% = commodity 被税 = SHORT 候选 (尤其周期顶). NVDA 高 margin 是 AI 文明能继续的前提条件, 不是泡沫信号. 真泡沫信号是 margin floor 跌破而 valuation 不调整 -- MU 在这边缘.

推论: 若强压 NVDA margin (e.g., 反垄断 / 监管 / DOJ 切分) = AI 进步速度直接放缓 = 这是 "AI 国家化" 真正的尾风险, 远超估值修正风险.

4. END GAME -- 三分支加权 + 触发器

Scenario A: 软着陆 25%

路径: Token 价格止跌, enterprise 渗透 2026-2028 缓慢爬坡, AGI-adjacent 产品 (real agents, real coding) 接住增长. CAPEX 增速从 50%+ 降到 15-20%, 不下杀.

赢家: 垂直 AI (legal/medical/code), 拥有 distribution 的 incumbent (MSFT/GOOG/CRM), 部分 Tier 2 hyperscaler.

NVDA: EPS 续涨, multiple 从 ~60x 压到 25-30x. 股价 plateau 而非崩.

识别信号: 2026 Q3-Q4 hyperscaler guidance 不下修 + token 价稳住 + OpenAI/Anthropic Q4 ARR 顺利上 $40B/$50B (run-rate, 当前已 $24B/$30B).

Scenario B: CAPEX 崩 + 周期出清 50%

路径: 一家 hyperscaler (大概率 META 或 AMZN, GOOG 次之, MSFT 最后) 在 2026 H2 - 2027 H1 砍 CAPEX guidance. 资本市场 reprice. NVDA 订单 cut -> AVGO custom silicon 推迟 -> AI startup 融资窗口关 -> AI infra ETF -50% to -70%.

触发器 (任一即可):

  • 下一次 DeepSeek-class 效率冲击 (开源模型把 inference cost 再降 10x)
  • OpenAI / Anthropic 年度 ARR 增长率首次跌破 30%
  • 任一家 hyperscaler 季度 CAPEX 指引下修
  • NVDA 出现首次 inventory 累积或客户 backlog 减少
  • 10Y Treasury 站稳 5%+ 持续 6 月

赢家: 现金 + 短端 + 真正盈利的 vertical AI + 开源工具链 (Hugging Face / Together / Fireworks 部分) + 电力基础设施 (即便 AI 慢下来, 电力需求仍真实, 但估值要回归).

输家: NVDA / AVGO / VRT / SMCI / 大半 AI startup / 二线 cloud 转型故事股 / 任何 implied TAM > $300B 估值的标的.

Scenario C: AGI 分叉 (能力跃迁 + winner take most) 25%

路径: 2027-2028 出现真正能力跃迁 (GPT-6 / Claude 5+ tier), 自动化 white-collar 显著扩张. TAM 真打开到 $500B+. 但赢家高度集中 (2-3 个 frontier lab + 1-2 个 hyperscaler).

NVDA: 续涨但风险变成监管 + 地缘 + alignment.

风险变体: AGI 真到, 但被 nationalized / regulated / sanction (中美分叉). Tail risk 不在估值, 在 ownership 能否兑现.

识别信号: frontier lab 公开模型在 ARC-AGI / FrontierMath / SWE-bench 跨非线性跳跃; OR 一家 lab 首次在年度自动续约率 demonstrate "AI 替代 headcount" 而非附加.

6. 投资姿态 (action mapping)

Long (高 conviction)

  • 垂直 AI (legal/medical/coding): 真 ARR, 真 retention, 真 distribution. 不依赖 LLM 算力分蛋糕, 而是分 SaaS 客户钱包.
  • 开源 AI 工具链: Hugging Face / Fireworks / Together / Modal 类 -- inference cost downside 时 they win.
  • 电力基础设施 (有 selectivity): GE Vernova / Vistra / Constellation -- 真实需求, 但估值已涨, 等回调.
  • 现金 + 短端: 干粉等 Scenario B 触发

Short / Avoid (B 触发后才下大注)

  • NVDA 尾部风险: 不裸空, 用远月 OTM put (cheap convexity). Trigger = guidance 下修信号.
  • AVGO / VRT / SMCI / CRWV: AI infra 二阶 (custom silicon / power management / liquid cooling / neo-cloud), beta 比 NVDA 大.
  • 循环融资链条上的客户: Oracle (OCI 集中暴露 OpenAI), CoreWeave (单一客户依赖).
  • 任何 "AI-powered" 估值 > 20x sales 但没有 organic 真增长的 SaaS.

Watch / Wait (不动手, 监测)

  • Frontier labs (OpenAI/Anthropic): 私募只能等 secondary, IPO 窗口 likely closed 1-2 年
  • Microsoft: 真 enterprise distribution + 不全押 AI, 跌时是 lower-risk 进场对象, 不是 short.
  • 中国 AI 链 (DeepSeek 生态 / 阿里腾讯): 政治风险溢价大, 但效率竞争是开源 thesis 的 leverage 点

7. 核心 take (画在脑门上)

  1. AI 真有用 != AI infra valuation 合理. 这是两个 separate question.
  2. LLM 是 commodity, 不是 utility. Commodity 没有 pricing power, sigmoid 曲线 not exponential.
  3. Sustainable CAPEX 公式: Revenue * Compute_Margin * Asset_Life. 当前数字超 5-10x. 不可持续就是不可持续.
  4. End game 不是 AI 失败, 是 AI infra 周期性出清 + 价值转移到 Wave 2 (真实 deployment).
  5. Timing: 2026 H2 看首家 hyperscaler 砍 guidance. 之前持有 cash + 真增长 vertical, 之后开始建空头底仓.
  6. 逆向布局: 当 Scenario B 触发, 共识恐慌时, 加仓 Wave 2 winner. 这才是 alpha 窗口.

9. 强行增税论 + Crisis RESET 必要性 (灵魂判断)

核心论断: 当前 AI 普及路径不是 organic adoption (像电力 / 互联网那样 cost 下降), 而是 通过 6 重渠道向社会强行抽税补贴 hyperscaler CAPEX. 这条路不可持续, 必须经历 crisis RESET 才能让 AI 真正普及.

9.2 这不是普及, 是 forced subsidy

历史对照:

  • 电力普及 1900-1940: 单位 kWh cost 持续下降 (从 $0.50 等值降到 $0.05 等值), 居民/工商用电渗透率 5% -> 95%. 成本下降驱动普及.
  • 互联网普及 1995-2010: dial-up $20/mo -> broadband $50/mo 同时速度 10-100x, 单位带宽 cost 跌 99%. 成本下降驱动普及.
  • 移动 internet 2007-2020: 3G -> 4G -> 5G, 单位数据 cost 跌 95%, smartphone 渗透 5% -> 80%. 成本下降驱动普及.
  • AI 2023-2026: API per-token cost 确实跌 85-92%, BUT 上层 toll fee (订阅 / 云 / 电价 / 补贴) 同期涨 30-50%. 表面普及, 实际是 hyperscaler 截留 + 社会买单. 成本上升 disguised as 普及.

关键差异: token cost 下降不等于 user-facing AI cost 下降. Hyperscaler 把 token 价跌幅 (open-source 竞争压力) 用 wrapper subscription / cloud markup / enterprise lockin 反向抽走. 净效应 = 用户付更多, hyperscaler 抽更多, 真用户 surplus 没 increase.

9.4 Crisis RESET 的必要性 (机制层)

Reset 不是 wish, 是 mechanism. 当前路径有 4 个 self-defeating loop, 任一触发就启动 RESET:

  1. Token 通缩 vs 订阅通胀的反向裂口: 用户终将发现 self-host DeepSeek/Llama 4 + 一台 H100 fleet 比 ChatGPT Pro $200/mo 更便宜. 企业 IT 部门 2026-2027 开始 in-source. 订阅 ARR 增长曲线断点.
  2. 电网物理上限: VA/TX 电网到 2026-2027 reach 极限, 新 datacenter permitting 卡死. CAPEX 想花花不出去. 强制 CAPEX cut.
  3. 财政压力 + CHIPS Act 政治反噬: 2026-2028 美国财政赤字突破 7% GDP, CHIPS Act 续期受阻. MU/Intel/TSMC AZ 失补贴, fab 利用率不足.
  4. 股东 ROI 实测翻车: 2027 hyperscaler 首次披露 AI segment 实际 ROIC (vs 内部 transfer pricing 美化), 数字若 <8% (低于资本成本), buyback 全面恢复 + AI CAPEX 砍 30-50%.

4 个 loop 中 2 个触发就启动 cascade. 概率 65-75% 在 2026 H2 - 2027 H2 之间 fire 至少 2 个.

9.5 RESET 后才有真普及 (健康路径)

健康普及路径 (2029-2035, Wave 2)

  • Inference cost 跌到 $0.01-0.05/M token (vs 今天 $0.5-3): edge inference 普及, on-device 推理, 真正零边际成本
  • 开源 frontier 跟 closed frontier 性能差 <10%: 商业模式从 model 转 application + distribution
  • 垂直 AI 主导: legal/medical/code 类 SaaS 不依赖 LLM provider, 直接 self-host + fine-tune
  • 电力先于 compute 成为 binding constraint: 真投资机会在 nuclear/SMR/grid, 不是 GPU
  • 真 productivity gain: white-collar 自动化真兑现, 但价值留在 application 层不是 model 层

9.6 这次 cycle 与历史 cycle 的关键差异

RESET 不会更慢, 反而更快, 原因:

  • 开源威胁是历史空前的: 铁路/电力/电信都没有 "免费替代品". AI 有 DeepSeek/Llama 4 24/7 拍脸. 通缩传导比 dot-com 快 3-5 倍.
  • Hyperscaler 资产负债表更强: MSFT/GOOG/AMZN/META 有 $400B+ 现金缓冲, 不会像 WorldCom 那样直接破产. RESET 形式 = 减值 + buyback 削减 + multiple 压缩, 不是 bankruptcy.
  • 但二线玩家更脆: CoreWeave / Oracle OCI / xAI / AI startup ecosystem 杠杆比 1999 telecom 更狠. 这些会真倒.
  • 政治反噬来得更早: 居民电费上涨 + ChatGPT 订阅涨价 + 失业焦虑, populist backlash 2026 中期选举周期就开始

10. 整合结论

  1. 价格 anchor: MU $800 / SNDK $1500 把 memory 链推到 1999 Q4 melt-up 量级. 这本身就是 RESET 必要性的最强证据 -- valuation 已严重脱离 sustainable economics.
  2. MU + SNDK 配置方向: 当前不是 long entry, 是 远月 OTM put 标的. 真 long zone 在 RESET 后: MU $150-250, SNDK $200-400 (各 -75 to -85% from current).
  3. 强行增税论被这两个价格 confirm: $800 MU + $1500 SNDK 不可能来自 organic demand 估值, 只能来自 forced subsidy + 散户 melt-up + 循环融资 + buyback halt 资金 reallocation.
  4. Crisis RESET 概率 85-90%, 时间窗口 3-9 个月. 因为 memory 链 melt-up 已经走到 dot-com 终段的位置, 历史可比窗口很短.
  5. RESET 不是 AI 失败, 是 AI 健康普及的前提. 当前 $215-375B/yr 强行增税 + memory 链 $1T+ 估值泡沫, 不 RESET 就没有真普及. Dot-com 已演示路径.
  6. 逆向布局: 当前用 cheap OTM put convexity 押 RESET (MU + SNDK + NVDA 三角空头, 总 premium ~1-2% AUM/year). RESET 触发后, 加仓 Wave 2 winner (vertical AI + 开源 + 电力 + post-crash memory consolidation). 先空后多 + 二段式 alpha.
  7. 本报告立场: 不站台 hyperscaler hype, 不 chase melt-up, 不站台 doom. 站台 "crisis is the cleanser" -- 用 cheap put 等 RESET, 用现金 + vertical AI + 电力做 Wave 2 真普及的种子仓.
