判断与推翻条件

  • 现价对应 IRR: PE 倒算全负 (到 FY28 末 A -30% / B -43% / C -57%; 到 FY30 末 A -11% / B -23% / C -35%); EV/S 倒算 A +5% / B -15% / C -35% (FY28), 即 "A 全兑现且倍数只压缩 40%" 才持平; 15% IRR 需要 FY30 收入 $25B。
  • 机会窗口: 不在做多现价。(a) 10-29 若首次出 Act IV 美元 KPI 而价不涨 (财报后 < $360) = 认知差未被定价, 开 1/3 仓; (b) 买入区间 $210-250 = 大额期权交易者 2028-01 深 ITM call 卖出行权价 ($210 / 220) + 2030 转债转股价 $247.67 + 6 月 30 日收盘 $245.28 + EV/S 17-20x FY27-28 B 收入; 该区仍是 保守公允价 (PE 基 $71-83) 的 2.5-3.5 倍 = 溢价区, ; (c) 持有者: 学大额期权交易者, 卖 2028 $470-520 call 收 60-69% IV 的租 (= 转债 cap 与转股价之间, 公司自己也在那里封顶)。
  • 转为看多的条件: 2026-10-29 Q3 收入 >= $760M (+35%) 且 FY26 上调到 >= $2.95B, DBNR >= 122%, 大客户 >= 5,000, non-GAAP GM >= 74%, 加任何 Gateway / Pay Per Crawl 美元 KPI; 加 2027-02 FY27 指引 >= +30% 且 non-GAAP OM >= 18%。全中 = A 情景 + EV/S 30x, IRR +5%, 升 "持有"。
  • 转为看空的条件: DBNR < 110 连续两季; 大客户增速 < 15% (2027-02 前); non-GAAP GM < 70%; Google 长尾 AI access 付款行上线 (2027-06-30 前); AWS 标准出口费降 > 50%; 创始人 10b5-1 之外的自主卖出或 Form 4 出现质押; 2030 转债 (2030-06-15) 前辛迪加不续。
