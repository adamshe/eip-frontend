判断与推翻条件

  • 五年每股 FCF 增幅 (FY2026 -> FY2030): A x2.44 / B x2.03 / C x1.62; 三年三年检验指标 (FY2026 -> FY2029): A x2.04 / B x1.74 / C x1.41; EPS 三年: A x1.68 / B x1.37 / C x0.96。即使 C, 每股 FCF 三年仍 +41% (capex 随周期下砍), 这是 TSM 作为 "公司本体" 与 LITE (供给翻倍压价) / GEV (押金反向) 的本质区别: 基本面尺三情景都过 "三年长高" 门。
  • 现价对应 IRR: 到 2028 末 A +12.9% / B -6.3% / C -35.2%; 到 2030 末 A +12.0% / B -0.9% / C -15.8%; 概率加权 (A 35% / B 45% / C 20%, 估) 2028 末约 -5%, 2030 末约 +1%。
  • 买入区间: 大额期权交易者布局隐含对冲线 $420 (2027-04 420P 4,514 张买入, -9%, SMA50 411-436) 与愿买入线 $350 (2028-01 350P 2,600 张卖出, -24%); 保守公允价 $315 (18x) / $350 (20x) / $385 (22x); 买入带 $350-420: 上沿 = 大额期权交易者对冲线 = 22x B 情景 FY27 EPS, 下沿 = 大额期权交易者卖 put 线 = 20x 保守公允价; 在 $385 以下 B 情景 2028 末 IRR 转正 (18x), 在 $350 B 情景 2030 末 IRR +7%。
  • 机会窗口: 不在做多现价 (IRR 期望为负, 腿到中位)。(a) 10-15 财报若 Q4 指引 < $48B 或 GM < 65% 引发 -8% 以上, 到 $420 接第一笔 (大额期权交易者同一价位); (b) 2027-01-15 的 2027 capex 指引若 >= $75B 且四家 2027 capex +25% 以上 = A 情景被公司与客户同时确认, 那时现价 (若仍在 $460 附近) 的 2030 末 IRR 12% + 倍数从 18x 回到 24x 的凸性才是 "认知窗口", 大额期权交易者的 2027-12 460-470C 就是押这个; (c) 持有者在 10-16 opex 前卖 $500 以上 call 收 36% IV 的租, 用 2027-04 420P 的同款做对冲线。
  • 转为看多的条件: 10-15 Q4 指引 >= $50B 且 GM >= 66.5% 且公司预告 2027 capex "明显高于 2026"; 加 2027-01 capex 指引 >= $75B; 加四家 2027 capex 指引 +25% 以上; 加 NVDA 2026-11 财报 supply commitments 再增 -- 四条全中 = A 情景 24x, 现价 2028 末 IRR +13%, 买入区间上移到 $460 (= 现价, 即 "持有" 变 "长期持有")。
  • 推翻条件 (B 转 C, 减仓到尾部仓位): temporary receipts 连降两季 (2026-09 < NT$234B 且 2026-12 再降) + 应付设备款 q/q 降; NVDA supply commitments q/q 降; 四家 2027 capex 指引持平; 任一季 GM < 60% (= 公司长期下限 56% + 海外稀释 4 pts); CoWoS 报价下降 ; 232 关税落在晶圆 ; Intel 拿到 AAPL / NVDA 外部量产 。台海 : 军演常态化 -> 仓位归零, 与估值无关。
