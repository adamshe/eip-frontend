判断与推翻条件

  • 三年检验指标: 每股完全稀释 FCF FY26 -> FY29 三情景都由负转正或仍为负 (A -2.52 -> 2.04 / B -2.58 -> 0.41 / C -2.98 -> -0.37), 对 FY25 基数 $1.76 三年后 A 1.16x / B 0.23x / C 负; 五年 (FY25 -> FY30) A 3.2x / B 1.04x / C 0。公司本体尺不过: 本体三年不长, 这是 capex 超周期的必然结果, 不是经营失败。
  • 机会窗口: 不在 $354 做多。(a) 买入区间: 信 A 的人要 15% IRR 须 <= $267 (A FY30 $8.05 x 60x / 1.15^4.25); 大额期权交易者地板 $300 (2028-12 put 行权价) 与 hunt SMA50 地板 $336 都在其上, 不是买入区间; 保守公允价 $63 只是机械下限, 不是目标。(b) 做空不主张: 2025 奖励把管理层激励钉在市值 $2T+, IV 45-50% 与叙事事件让空头成本高; 若要表达, 用大额期权交易者同型结构 (远月 put 价差或领口) 而非裸空。(c) 估值层观察名单, 等 U2 / U8 两个事件落地。
  • 转为看多的条件: 2028-01 (Q4 2027 财报) 前同时满足: 有效 FSD 订阅 >= 3.5M; 无监督 Robotaxi >= 10 个都会区且披露累计付费里程 >= 1 亿英里; Cybercab 获联邦标准豁免并公开运营; FY27 FCF >= 0 (capex <= CFO)。全中 = A 为基准且 2030 末 100x 可辩护, IRR +21%。近端: 2026-10-21 Q3 财报汽车毛利 (剔积分) >= 18% 且 2027 capex 口径 <= $25B, 则 B 上调至 FY27 EPS >= $2.0。
  • 转为看空的条件: 连续两季汽车毛利 (剔积分) < 14% (2027-01 / 2027-04 财报); 2027-09-29 前 DDTL 提款 > $10B 且 capex 未降; 储能毛利两季 < 18%; BYD 2026 海外 >= 200 万 (2027-01 月报); 2028-01-19 前后 Musk 出售或质押 > 236M 股。
