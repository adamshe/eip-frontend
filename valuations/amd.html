结论

现价 = 39.5x FY27 共识 EPS $15.58 = 27x A 情景 FY28 非GAAP EPS $22.8 (FY28 共识无数据), 市场已按 "14 GW 协议全部交付 + GPU 份额升到 10% + 毛利率不降 + warrant 稀释不计" 零折现付清; 三情景倒算 IRR 到 FY28 末 (2.24 年): A 公司自述全兑现 +4.8% (30x) / B 中性 -27% (22x) / C 下行 -59% (15x); 到 FY30 末 (4.24 年): A +1.7% / B -17% / C -42%。 与 GEV 不同, AMD 的风险不只在倍数, 在 FY28 EPS 本身 (稀释 + ASP 年降 + CoWoS / HBM 配额)。

判断与推翻条件

  • 机会窗口: 不在做多现价。(a) 买入区间: 保守公允价 $236 (22x) 至 $268 (25x) 是 B 情景的价; B 情景 FY28 EPS x 25x 零折现 $346 与 FY27 共识 x 25x $390 之间是卖出期权买入区间 $300-390 (估), 需现价 -40% 到 -50%; 大额期权交易者布局隐含的买入区间 $444 (2028-12 P600 保本) 与 $560 (2027-06 合成多头成本) 是 A 情景的价, 不跟。(b) 持有者在 $600+ 做收取期权权利金: 卖 2028-12 $1,000 call (IV 62%, 约 $130) 或 2027-01 $800 call; 不卖 put。(c) 同链错价候选: NVDA 前瞻 14.7x 对 AMD 39.5x, 同一客户同一 capex, 关系持有人反而便宜 (未 vet); INTC 涨价 48% 的 CPU 盘子 (未 vet)。
  • 转为看多的条件: 11-03 财报 Q4 指引 >= $15.5B 且 DC >= $9B 且非GAAP GM >= 57%; 2027-03 前 10-Q 披露 warrant 首档 vest (= 1 GW 交付实证); 2027-01/02 四家 2027 capex 指引 +30% 以上; NVDA GM 保持 >= 73% (不降价)。四条全中 = A 情景 35x, IRR +12%。硬数字 + 日期: FY27 收入 >= $88B 且非GAAP EPS >= $16 (2028-02 财报); FY28 非GAAP EPS >= $28 且稀释股 <= 1,750M (2029-02)。
  • 转为看空的条件: 任一季 DC 收入 q/q 下降; 10-K FY26 (2027-02) 采购义务 2027 列低于 $5.5B; NVDA GM < 70%; 超大规模 2027 capex 指引持平; OpenAI 采购延后公告或应收集中 > 25%; 出口管制再收紧。
