结论

现价 = 26.0x FY27 共识 EPS $19.75 = 21.7x FY28 共识 $23.65, 市场已按 "共识路径 (A): FY28 收入 $467B 且营业利润率守住 47%" 零折现付清; 本文第一性原理 (B) 把公司 capex 指引按 cohort 机械推成 D&A (FY26 $38.5B -> FY28 $76B -> FY30 $123B), FY28 EPS $21.1, 比共识低 11%。三年检验指标 (每股完全稀释 FCF, FY26 $8.99): FY27 三情景都跌到 $1.4-2.8 (公司自己只承诺 "FCF 为正"); FY26 -> FY29 增幅 A -38% / B -3% / C +41% (capex 被迫砍的 C 反而最高) / A' (共识收入 + capex FY28 封顶) +51%; FY30 每股 FCF A $10.5 / B $12.1 / C $15.6 / A' $19.4。倒算 IRR (含股息, 折现率 10.2%): 到 FY2028 末 (2028-06-30) A +11.4% / B -4.7% / C -22.9%; 到 FY2030 末 A +10.8% / B -1.1% / C -13.8%; 概率加权 (30/50/20, 估) -3.5% / -0.1%。最硬的一条事实: MSFT 五年来每股 FCF 原地踏步 (FY21 $7.38 -> FY26 $8.99, +22%), 同期稀释 EPS 2.2 倍, 盈利增长全部转成了 GPU 与数据中心; 管理层 PSA 按 Azure 与云收入增速发放 (DEF 14A), 不含 FCF 或 capex 回报指标, capex 纪律没有内部制衡。
