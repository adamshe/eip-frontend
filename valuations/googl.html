本体在长: 核心 EPS FY25 $9.17 -> B FY28 $13.88 (1.5x) / FY30 $16.90 (1.8x); A FY30 $23.45 (2.6x); C FY30 $7.25 (0.8x)。

三年检验指标 (每股完全稀释 FCF): FY26 -> FY29 三年: A -0.17 -> 7.28 / B -0.42 -> 4.33 / C -1.14 -> 4.00, FY26 基数为负, 尺失效; 改 FY25 基数 $5.99: FY29 A 1.22x / B 0.72x / C 0.67x; 五年 FY30 A 2.23x / B 1.23x / C 0.76x。机制: CFO 从 $165B 长到 B FY29 $334B (2.0x), 但 capex 从 $91B 长到 $280B, 差额被吃掉; capex 若 2029 降到 $220B, B FY29 每股 FCF 为 $9.17 (1.5x), 维护性口径 (CFO - D&A) 为 $18.96。尺的结论: GOOGL 是 "净利长、FCF 推后" 的公司本体, 三年尺不过, 五年尺在 B 勉强过 (1.23x), 过不过取决于 2028-29 capex 是否见顶, 这是公司自己的选择 (采购义务已签到 2030)。

现价 IRR: 到 FY28 末 A +12.7% / B -8.4% / C -36%; 到 FY30 末 A +14.9% / B 0.0% / C -24.7%。现价 = 22.6x 共识 FY27 = 24.4x B FY28, 市场已按共识 36% 利润率 (不计 D&A 翻倍) 付清 B 情景, 只在 A 情景有 12-15% 年化。

买入区间: 大额期权交易者布局隐含 2027 区间 $290-390 (卖 2027-06 C345 上沿 $389, 卖 2027-12 P290 / 2028-12 P240 下沿); 保守公允价 $221 (20x) 至 $276 (25x); K = $350 (Berkshire)。买入区间 $270-290 = 20x B FY28 EPS, 与 2027-12 P290 大额期权交易者地板重合, 低于 K 17-23%; $290 以上只做 A 情景确认后的加仓 (AI Mode 单价披露 >= 传统, 或回购恢复 >$10B/季)。
