独立研究, 非投资建议。价格与一致预期为发布日数据, 估算值已在文中标注。

结论

现价 = 36.7x FY27 共识 EPS $5.45 = 29.9x FY28 共识 $6.71 = 34.7x B 情景 FY28 EPS $5.77; 市场已按 "FY27 +33%, FY28 +18%, 之后无周期回落" 付清。 三情景倒算 (折现 11.7%): FY28 末 A 公司自述全兑现 -0.5% (30x) 至 +8.6% (35x) / B 中性 -23% / C 下行 -44%; FY30 末 A +4.5% / B -10% / C -27%。 机制链比 GEV 软: 过程控制是先进制程良率的守门人 (一客户 TSMC 19%, 积压一年 +60% 到 $12.57B, 服务 23% 是收取期权权利金底), 但量跟 WFE (晶圆厂设备支出) 周期走, 中国 30% 收入在管制之下, 2027-28 存储 capex 翻倍后的回落是最大的已知未知; 三年检验指标 (每股完全稀释 FCF, FY26 -> FY29): A 2.54x / B 1.97x / C 1.54x, 本体三年确实会长, 但 $200 已付了 A 的价。

判断与推翻条件

  • 五年每股 FCF (FY26 $2.85 -> FY31): A $9.11 (3.19x) / B $6.82 (2.39x) / C $4.88 (1.71x); 三年尺 (FY26 -> FY29): A 2.54x / B 1.97x / C 1.54x。 本体三年会长 (B 年化 +25%), 这是公司本体名单候选的理由;
  • 买入区间 (大额期权交易者布局 vs 保守公允价): 大额期权交易者 put 地板 175-180 (2028-01 P180 / 2027-06 P175 买方), 2029-01 P240 卖方的有效买入价约 $156, 7 月低点 $170, SMA50 地板 $182 (hunt 表); 保守公允价 $105 (22x) 至 $119 (25x)。三档: (a) $170-182 只做卖出期权卖 put 收 63% IV 的租, 不长期持有 (= 30x B FY28); (b) $150-160 (= 26-28x B FY28, 2029-01 P240 卖方的位置, 2026-01 至 03 平台 $142-152 上沿) 可建观察仓; (c) $105-120 = 保守公允价, 周期中值长期持有位, 对应 2027-28 WFE 见顶被定价之后。现价 $200 无动作 (hunt 表同判)。
  • 转为看多的条件: 10-28 12 月季指引 >= $4.6B 且 GAAP 毛利 >= 62%; 加 2027-01 TSM 2027 capex >= $60B 与 MU FY27 capex >= $35B; 加 AMAT / LRCX 1 月把 2027 WFE 说成 +15% 以上。三条全中 = A 情景, 但 A 在 30x 也只 -0.5% (FY28) / +4.5% (FY30), 转 "持有" 不转 "长期持有"; 转 "长期持有" 还需 PE 回到 25x 以下 (价 < $165 对 B FY28)。
  • 转为看空的条件: 10-28 收入 < $3.8B 或 12 月季指引 < $4.3B 或 积压 / 递延系统收入环比下降 或 毛利 < 60.6%; Affiliates Rule 2026-11 恢复且公司砍中国占比指引 > 5 pt; DRAM 合约价环比转负两季 (存储 capex 先砍); 连续两季 CFO / 净利 < 0.8。
