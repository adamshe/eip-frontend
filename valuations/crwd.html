  • 转为看多的条件: 2026-12-01 Q3 net new ARR >= $380M 且 FY27 ARR 上调 >= $6.70B; 加 2027-03 初 FY28 指引 net new ARR 增速 >= +20% 且 non-GAAP OM >= 27%、FCF 率 >= 30%; 加 2027-05 DEF 14A 披露 FY27 四季 NRR 均 >= 117%。全中仍只把 A 的 FY31 IRR 抬到约 0%, 所以 推翻条件 只改 "观察 -> 持有", 不改 "不追高"。
  • 转为看空的条件: net new ARR 同比转负两季 ; NRR < 110% (CIP 目标下沿); GRR < 95%; 10-Q note 11 出现 Wells notice、和解或 ARR / 收入重述; WESP GA 且 Defender 同 API ; 第二次全球宕机级事故; non-GAAP 订阅毛利 < 79%; Flex ARR 增速 < 30%。
