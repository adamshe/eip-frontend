结论

现价 = 55x FY26 共识 non-GAAP EPS $7.65 = 40x FY27 共识 $10.54 = 31x A 情景 FY28 $13.60 = 20x A 情景 FY30 $21.30 (零折现); 市场已按 "2028 目标 ($6B 收入 / 28% EBITDA 率 / 60% FCF 转换) 全兑现并延续到 2030" 付清。三情景倒算 IRR (折现 11.5%): 到 FY28 末 (2.25 年) A +5.5% (35x) / B -11.8% (28x) / C -38.6% (18x); 到 FY30 末 (4.25 年) A +14.3% / B +1.4% / C -18.0%。三年检验指标 (每股完全稀释 FCF, FY26 -> FY29): A 2.68x / B 2.06x / C 1.25x, 本体三年都在长, 问题只在付的价。机制链比 GEV 软 (客户是政府预算, 现金晚于收入 1-2 年, FY25 FCF 仅 $75M), 但位置比 GEV 硬 (证据链记录系统 + NRR 126% + 十年合同); 会计红旗 (2025-05 8-K 4.02 + 两年重大缺陷) 2026-06-30 公司自称已补救, 审计师背书要等 2027-02 的 10-K。

判断与推翻条件

  • 现价对应 IRR: 到 FY28 末 A +5.5% / B -11.8% / C -38.6%; 到 FY30 末 A +14.3% / B +1.4% / C -18.0%; 期望为负到持平。与 GEV 同型 (EPS 不是风险, 倍数是), 与 LITE 不同 (LITE 的 FY28 EPS 本身有供给翻倍压价)。
  • 买入区间 (大额期权交易者隐含 vs 保守公允价): 第 1 档 $380-400 (2028-01 put 墙 + 10-30 P430 卖方买入 $398; = A 情景按 FY27 共识 36x, 卖出期权收取期权权利金位, 归 hunt 第 1 档); 第 2 档 $320-330 (12 月 put 地板 2 sd; = B 情景 FY30 28x 折现 $282 上沿); 第 3 档 $223-250 (保守公允价, B 情景 25-28x 折现)。长期持有 (结构 long) 只在第 2-3 档; 第 1 档只做卖出期权 (IV >= 50% 已满足)。
  • 机会窗口: 不在做多现价。(a) 11-03 财报若 "率低于 25% + FCF 指引下修" 砸到 $357 (hunt 三周低) 以下而 NRR >= 125 / 订单 +30% 不变, 是 B 情景的错价窗 (公司本体对价格错, 不是公司本体坏); (b) 持有者卖 11-20 $470-480 call (OI 238 / 145, IV 70%) 收取期权权利金; (c) 同层错价候选: MSI 23x 对 AXON 40x, 同一客户同一预算 (未 vet)。
  • 转为看多的条件: 11-03 NRR >= 126 且 ARR +38% 以上 且重申 FCF $450M; 加 2027-02 给 2027 收入 +30% 以上、国际占比 >= 22%、SBC <= $650M、10-K 9A 内控有效且审计师无保留; 加 2026 全年 FCF >= $450M。三条全中 = A, 现价可持有不加。
  • 转为看空的条件: 任一季 NRR < 118 或 ARR 增速 < 28% ; FY26 FCF < $300M 或 CFO < $500M; 未来合同订单同比 < 20%; 任何 8-K 4.02 或新重大缺陷; LAPD 市议会否决或 2027 丢 >= 2 个前 20 大机构; 2027 SBC > 18% 收入。
