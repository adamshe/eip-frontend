结论

现价 = 30.5x 干净 FY26 共识 EPS $8.15 (GAAP 共识 $12.88 含 H1 Anthropic 账面重估 $69.4B, 不可用) = 23.6x FY27 共识 $10.50 = 22x 本文 A 情景 FY28 EPS $11.30; 市场已按 "AWS 五年 25% CAGR + capex 2027 后趋平 + D&A 爬坡被 EBITDA 吃掉" 付清。五年盈利最大变量不是收入 (RPO $496B 已锁), 是 D&A: capex $220B/年、服务器 5 年折旧 => PP&E 折旧从 2025 $41.9B 升到 2030 $186B (B 情景), EBITDA 要先多赚 $140B 才能让营业利润持平。三情景倒算 IRR (折现 11.5%): FY2028 末 A +11.4% (28x) / B -10.1% (22x) / C -38% (15x); FY2030 末 A +12.1% / B -4.6% / C -28%。三年检验指标 (每股完全稀释 FCF, 不扣 SBC): FY2026 为负 (-$2.0 至 -$2.8), FY2029 回到 +$3.8 至 +$5.2, 三年增量 +$6.1 (B) 至 +$6.5 (A); C 情景 FCF 反而最高 (capex 砍掉), EPS 却跌 36%, 是 FCF 尺的已知盲点。

判断与推翻条件

  • 五年每股 FCF (FY25 $1.03 -> FY30): A $7.44 (7.2x) / B $5.81 (5.6x) / C $6.79 (6.6x, 靠砍 capex); 三年三年检验指标 (FY26 -> FY29, 基数为负只能记增量): A +$6.46 / B +$6.09 / C +$7.98; EPS 三年 A 1.61x / B 1.17x / C 0.64x。本体长不长的判定: B 情景 EPS 五年只长 19%, 全部增量被 D&A 吃掉; 长的是 EBITDA (2025 $122B -> 2030 B $321B, 2.6x), 不是每股利润。
  • 现价 IRR: FY2028 末 A +11.4% / B -10.1% / C -38%; FY2030 末 A +12.1% / B -4.6% / C -28%; 期望值按 A 30 / B 50 / C 20 为负 (约 -5%)。现价 = 30.5x 干净 FY26 / 23.6x FY27, 已付清 A 情景的 22x。15% IRR 要 FY30 EPS $16 (28x), A 情景也不到。
  • 买入区间: 大额期权交易者布局隐含区间 230-280 (2027-09 P230 托底, 2028-12 C280 封顶), put 墙 240 / 247.5, 三周预测低点 234.5; 但 $230 只是 A 情景 15% IRR 的买入区间 ($222 = 403 / 1.15^4.25); B 情景 保守公允价 = $153 (22x) 至 $174 (25x 折现); B 情景 28x 加 15% IRR = $143。两档: $220-235 (信 A: AWS >= 35% 两季 + capex 2027 <= $260B) / $150-175 (信 B)。
  • 机会窗口: 不在做多现价; 在 10-29 财报若 capex 2027 口径 > $280B 引发 -10% 以上且 AWS 仍 >= 35%, 到 $225 以下是 A 情景的赔率; 若 AWS < 32%, 任何价都不是窗口 (B -> C)。做空非主张: RPO 锁收入, 空头赌的是倍数, IV 33-38%, 财报日 6%。
  • 转为看多的条件: 10-29 AWS >= 36% 且 AWS OI 率 >= 37%, Q4 指引 OI >= $32B, 2027 capex 口径 <= $250B; 加 2027-02 10-K 不再缩寿命; 加 RPO >= $560B 且预收款开始同步增 (客户真金); 三条全中 = A 情景 28-30x, IRR 12-15%。
  • 转为看空的条件: AWS 任一季 < 30% 且 capex 不减; OpenAI 融资失败或重谈; RPO 一季不增; FTC 结构性救济; agent 代购在站外 > 10% 美国 GMV; 10-K FY26 把芯片寿命缩到 4 年。
