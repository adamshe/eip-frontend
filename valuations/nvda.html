NVDA 五年估值 (2026-10-01)

独立研究, 非投资建议。价格与一致预期为发布日数据, 估算值已在文中标注。

结论

现价 = 24.8x FY27 共识 EPS $9.31 = 14.7x FY28 共识 $15.70 = 18.5x 本文 B 情景 FY28 $12.50; 市场已经在用周期股的倍数 (AVGO 17.7x / TSM 20.9x / MU 5.3x) 乘一个 "FY28 全兑现" 的盈利, 即把 FY28 当周期顶定价, 既没付 FY29-31 继续增长 (A), 也没付 FY29 起下行 (C)。三情景倒算 IRR (折现 15.2% = 5.24% + beta 2.22 x 4.5%): 到 FY28 末 (2028-01, 1.3 年) A 公司自述全兑现 +52% (25x) / B 中性 -2% (18x) / C 周期顶 -44% (12x); 到 FY30 末 (2030-01, 3.3 年) A +27% (22x) / B +1% (16x) / C -27% (12x)。三年检验指标 (每股完全稀释 FCF, FY26 $3.94 -> FY29): A 4.8x / B 3.4x / C 2.0x, 三情景都过 2x, 因为 FY27 已被供给锁定在 FY26 的 1.9 倍; 本体三年必长高, 赌的全是 2027-28 客户 capex 是否见顶和退出倍数。大额期权交易者布局 (2028-01 卖 C400 买 P180, 2029-01 卖 C360 买 P180) 与本文 B 情景同一读法: 上限 = A 情景 25x, 地板 = B 情景 14x。

判断与推翻条件

  • 五年每股 FCF 增幅 (FY26 $3.94 -> FY31): A 6.5x / B 4.1x / C 2.0x; 三年三年检验指标 (FY26 -> FY29): A 4.8x / B 3.4x / C 2.0x; 参考 EPS 三年: A 4.2x / B 2.8x / C 1.5x。本体三年必长高 (FY27 已锁 1.9x), 公司本体尺 NVDA 过线; 分歧在 FY28 后斜率。
  • 现价对应 IRR: 到 FY28 末 A +52% / B -2% / C -44%; 到 FY30 末 A +27% / B +1% / C -27%; 以先验 A 30% / B 45% / C 25% 加权, FY30 期望 IRR 约 +2%, 即现价公允于 B, 赌注是 U2 (2027 capex regime) 与 U3 (份额) 的二分叉。与 GEV / LITE 不同: NVDA 不是 "已付清 A", 是 "付清 B, A 与 C 都没付", 所以上下都是胖尾: A 兑现是 +27-52%, C 兑现是 -27-44%。
  • 买入区间: 大额期权交易者领口地板 $180 (2028-01 / 2029-01 P180 买方, delta 0.19-0.20) 与 保守公允价 $187 重合; 52 周低 $164.79 (2026-03-30); 2027-06 P140 OI 144.6K 是市场的崩塌地板。买入区间 $165-190 = 11-12x 共识 FY28 / 13-15x B 情景 FY28, 下沿 $150 (2027-06 P150 OI 49.8K); 现价 $230.86 不是入场, 是 B 公允。持有者动作 = 跟大额期权交易者: 卖 2028-01 C400 / 2029-01 C360 收取期权权利金, 买 P180 保地板。
  • 机会窗口: 不在现价做多方向; 窗口在 U2 揭晓前后 (2027-01 下旬至 02-25 NVDA Q4 FY27 财报): 若四家 2027 capex 指引合计 +40% 以上且 NVDA Q4 指引 >= $130B 而股价仍在 $230 以下 = A 情景按 B 价卖, IRR +27-52%, 时点在那两周; 反之若任一家持平而股价仍 $220+, 是 C 情景按 B 价, 做空 / 买 2027-12 P200 的窗口。
  • 转为看多的条件: (1) 2027-02 前 MSFT / GOOGL / META / AMZN 2027 capex 指引合计 >= $1.0T (+40%) 且 ORCL FY27 capex >= $100B; (2) NVDA Q4 FY27 指引 (2027-02-25) >= $130B 且毛利指引 >= 74%; (3) AVGO FY27 AI 收入增速 < NVDA DC 增速 (份额企稳)。三条全中 = A, 目标 2028-01 $399 / 2030-01 $511。
  • 推翻条件 (B 转 C "回避 / 空头检查"): 任一超大规模 2027 capex 指引持平或下修; NVDA 任一季毛利指引 < 72%; AR / 季收入 > 0.8 两季 (DSO > 75 天); OpenAI / CRWV 类客户付款违约或 SB Energy 担保生效前融资断; 新一轮全球 (非中国) 出口管制覆盖 Rubin; AVGO + AMD DC 增速连续两季 > 2x NVDA DC 增速。到期日: 2026-11-17 (Q3), 2026-12 中 (ORCL / AVGO / MU), 2027-01 下旬至 02-25。
