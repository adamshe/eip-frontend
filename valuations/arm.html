独立研究, 非投资建议。价格与一致预期为发布日数据, 估算值已在文中标注。

结论

现价 = 131.5x FY27 共识 non-GAAP EPS $2.22 = 95.7x FY28 共识 $3.05 (GAAP 口径约再翻 2-3 倍), 也 = 64x 本文 A 情景 (公司自述全兑现: AGI CPU 走向 $15B + 版税年增 20%) 的 FY29 EPS $4.57 零折现; 市场已把 "自研硅 $15B + 数据中心份额 50% 以上 + 倍数不降" 一次付清, 另加 SoftBank 控股 86.4% 下 13% 流通盘的稀缺溢价。倒算 IRR (现价买入): 到 FY2028 末 (2028-03) A -27% / B -47% / C -69%; 到 FY2030 末 (2030-03) A +1.6% / B -21% / C -43%; 到 FY2031 末 A +6.8% / B -16% / C -36%。本体在长 (B 情景 FY26A -> FY29 每股 FCF 2.7x, 版税按构造自增), 错的是价格; 且 FY26 收入的 30% 来自关联方 (Arm China 16% + SoftBank 顾问费 14%), 控股股东一边把 72% 股权押给 $25B 保证金贷款, 一边向 ARM 付顾问费。

判断与推翻条件

  • 买入区间: (1) 大额期权交易者布局的承接区 $240-250 (11-12 月卖 put) 恰好落在 "A 情景 FY31 40x 按 12.5% 折现 = $232" 一线 -- 期权卖方把 A 当成地板; (2) 保守公允价 $80 (40x 为 $106); (3) 中间价 $130-160 = B FY31 EPS 30-35x 不折现。对相信 B 的人, 合理买入区间 <= $135; 对相信 A 的人 <= $232。现价两者都不是。机会窗口候选: SoftBank 被动卖股 (U6) 或 Qualcomm 判决 (U5) 造成的流通盘踩踏, 只在 $135 以下按 B 接, 不在 $240 按 A 接。
  • 转为看多的条件: 11-04 或 2027-02 财报把 AGI CPU 两年需求提到 >= $4B 且给出 FY28 硅收入 >= $3B、硅毛利 >= 55%; 数据中心版税披露占版税 >= 25%; 版税连续两季 >= +25% 而 QCOM 手机仍为负; 公司在 6-K 写明 $15B 的年份为 FY2031 或更早。三条全中 = A 60x, FY31 IRR +17%。
  • 转为看空的条件: Qualcomm 案不利判决或 Qualcomm 宣布 RISC-V 旗舰手机 AP; SoftBank 顾问费单季 < $100M 且合同资产不回款; 版税增速连续两季 < 10%; AGI CPU 量产推迟过 2027-03 或首季硅毛利 < 45%; SoftBank 任何 Form 144 / 13D/A 减持或 6-K 披露 margin loan 提前还款。
