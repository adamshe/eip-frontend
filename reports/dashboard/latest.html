How to read this board -- 层级读法

Layer A -- 本体质量 (NET 自身遥测)

测什么: 直接测 NET 这台收费站的运转: 流量过站量 (radar)、开发者飞轮 (npm)、路网覆盖 (w3techs)、管理层信心 (jobs)、硬承诺 (cRPO)。

怎么读: 三针同向绿 = 本体质量 SIGNAL UP, 基本面动能确认; 单针只作注意。A 层强而 C 层弱 = 好公司坏环境, 仓位帽压低; A 层弱 = 不管环境多好都别加。

Layer B -- 行业趋势 (上游水位)

测什么: NET 活在互联网扩张 + 云需求两条水系里: 新域名 (DNIB) 是进水口, 三大云增速是潮汐。水位决定所有船的吃水。

怎么读: 季度更新的慢层, 作背景板: 两针齐绿 = 涨潮, A 层的绿更可信; 水位转弱而 A 层还绿 = NET 在逆水行舟, 检查是份额扩张还是滞后。

Layer C -- 市场逻辑模式 (玩家的实际下注)

测什么: 现在整个市场按哪套规则在跑, 由玩家真金白银的下注读出: 信用 (HY OAS = 拒付定价)、汇率杠杆 (USDJPY = carry 心电图)、事件钟 (S-1 = IPO 发令枪)、价格闸门 ($305 = 市场对 agent 经济故事的实际下注线)。

怎么读: C 层一票否决: 任一针 RED 直接把全局打 RED, A/B 再绿也不放行 -- '市场逻辑裂了, 好标的也先站开'。C 层 SIGNAL UP + A 层跟上 = 全绿放行。

Layer M -- Mirror-本体 (玩家对 NET 的下注)

测什么: 三元 Law 里 mirror 的本体侧: C 层是市场整体的镜子 (可不可读), 这层是玩家对这一个名字的下注方向 (期权流 / 跨日 / gamma)。alpha = 本体与 mirror 的偏离, 偏离要有两边才算得出。

怎么读: 不进否决。只和 A 层一起决定今日格子: 本体 UP 而下注不动 = 错价买点; 本体不动而下注偏多 = 叙事溢价, 卖 call 的位置。

合成规则 (L2 教义): 市场逻辑模式决定该不该在场 (一票否决), 本体质量决定在场买什么 (三针同向才叫信号), 行业趋势决定本体那几针的可信度; 全局 = worst(C 层, A 层); NET 收破 $305 或任何 EVENT = 无条件顶格横幅。今日格子 = 本体信号 x mirror 状态查表 (action_matrix), 每格一个动作。
