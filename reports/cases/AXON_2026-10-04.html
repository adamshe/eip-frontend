本体: 证据链记录系统, 为什么是结构 long 候选

先排除它不是什么。不是纯硬件公司: 硬件有换机周期 (TASER 10 / AB4), 但增量来自订阅 (ARR $1,639M +39%, S&S 收入 +36%), 不取 ASP 年降硬件的 12x。不是成熟公共安全公司: MSI 同层 Video / Command Center 只长 11-15%, 前瞻 PE 23.1x, 是 Axon 的对照组而不是同类。不是纯 SaaS: 客户锁十年但不预付 (客户押金仅 $16.5M, 合同资产 $1,047M), 现金晚于收入 1-2 年, 与 GEV 的押金结构相反。不是 AI 叙事股: AI Era +700% 来自小基数, 公司只给倍数不给美元基数。

排除后剩下的是: 美国执法证据链的记录系统 + 装备装机 + 政府订阅。关系作证: 客户 (LAPD 十年 $235M 续约, NRR 126%)、对手 (MSI 把并购资金投向无线电 / 国防 / 911, 不正面攻记录仪; MSI 10-K 列 Axon 为对手)、资本方 (五家投行联席 0% CB, capped call $1,049.94)、新进入者 (efts 全文检索 S-1 零家 Axon 级)。三道门全过 (Adversary: 叙事归零后存量 TASER + 记录仪 + Evidence.com 仍活; 范式: 攻本层者未成; 判断类型: structural)。创始人 Rick Smith F = 4 (经历 2 / 信而见 2 / 在位 0), 持股 3.5% 无控制权, 是 "在位而非掌舵"。

弱点也在本体上: 第二层 (国际 18% 收入、企业、Dedrone、AI Era) 已有美元但概率只给 0.5; 国际有出口许可 (CED 属 crime control) 与 EU AI Act 摩擦; 替代路径 N2 = 0。所以交叉格是 "结构 long 候选", 不是无条件终态。

估值: 自身便宜不等于绝对便宜

系统读数说 non-GAAP PE 54.0x 只在自身第 33 百分位, 看起来便宜; 但 10-01 倒算记录的自身 trailing non-GAAP PE 是 62-107x (2023-12 至 2025-12), 自身常态本来就是高倍数, 第 33 百分位仍是 54x (系统百分位的样本口径未核)。GAAP PE 153.3x 在第 62 百分位, GAAP / non-GAAP 折算 0.35: 利润大半在股权激励之前, SBC 等调整项吃掉约三分之二 -- 这是 "non-GAAP 便宜、GAAP 不便宜" 的来源。

倒算回答 "现价付了多少": 按 $413.35, 零折现等于 A 情景 FY28 EPS $13.60 x 30.4 或 A 情景 FY30 EPS $21.30 x 19.4 (算); 市场已按 "2028 目标 ($6B 收入 / 28% EBITDA 率 / 60% FCF 转换) 全兑现并延续到 2030" 付清, 对会计红旗重演、州地方预算 regime、SBC 稀释、现金晚收零折价。要 15% IRR, 2028-12 价须约 $566 (算) = FY28 EPS 16.2 (35x), 相当于 A 情景提前一年。Fair Value A = B FY28 EPS $11.38 x 25x 折现 = $223 (28x 为 $249), 无战略资本 K (CB 转股价是债权人条款, capped call 是投行对冲上限), SPR 10-01 为 +89%, 按 10-02 价 +85% (算)。

风险结构不对称: 上行要 "2028 目标全兑现 + 2030 仍 +19% + 35x 维持" 三条都对, 才有到 FY30 末 +14.9% (算); 下行只要会计红旗重演 / 州地方预算 regime / FCF 不转换任一条, 倍数先压到 C 的 18x (MSI 23x 再打会计折价)。与 GEV 同型 (EPS 不是风险, 倍数是)。三把接货尺子: 鲸鱼地板第 1 档 $380-400 (= FY27 共识 36-38x, 是护盘位不是价值位)、12 月 2 sd 地板 $320-330 (B 情景 FY30 28x 折现 $282 之上)、Fair Value A $223-250; 买房只在后两档。

现金质量与稀释: 承重的弱环

本体分高、价格层却过不了门, 中间隔着现金。FY25 CFO $211M 由净利 $125M + SBC $634M + D&A $83M 撑起, 营运资金吃掉 $482M (应收与合同资产 -$506M), FCF 只有 $75M, 每股 $0.91; 2026 FCF 指引 $450M 只在 Q1 稿出现, Q2 稿只说 "positive operating cash flow", H1 实际 CFO -$11M。公司自认 "need to get through this period of inventory investment"。管理层现金奖金看收入 / EBITDA 率 / 新订单 / 新产品采用, 没有 EPS 与 FCF 指标 -- 激励不指向现金转换, 这是 FCF 承重句最弱的一环。

稀释的现金成本是真的: 净额结算代缴税 2025 $351M (等效回购, 按 Adam 口径不从 FCF 扣), 零回购 (2016 授权余 $16.3M), ATM 在约 $500 卖股, 2027 warrants 3.0M 股 2028-03 起自动行权, 2031 CB 转股价 $652.06。公司承诺年稀释 < 2.5%, 但股价越低同样美元的 RSU 换越多股, 这条在下跌中会自动变差。

鲸群与资金: 持股者在收租, 没人为 A 付钱

期权流 (09-28 至 10-01) 的形状是持股者自保: 2028-01 P380 挂股包 $990K 买保险、12 月 P330 / P320 各 300 张开仓 (财报后 -22% 地板)、10-16 至 10-30 ATM call 多笔卖开 (进财报前收租); 方向性单两边都小 (10-30 P450 多在 ask $620K 对 C460 开仓 $153K); 唯一远月方向性新 call 2029-01 C710 x11, 盈亏平衡 $803 = FY28 EPS $13.6 x 59x, 是小注赌倍数重扩张。期限结构给财报日 1 sd 约 15%, 2028-01 跨式 54% ($230-650)。hunt 机械表与期权流一致: 底区收租 + 等财报。
