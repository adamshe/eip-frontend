零件强, 整链弱。rent_stats 的 strike 级定价、OPRA 成交码读单、链完整性检查都是同级以上的零件; 但同一个决定 (哪一边、哪个 strike、方向) 被 4 到 6 个互不知情的工具各算一遍, 10-02 一页里至少 7 处同票同日给出相反动作: NET 持仓 (LLM 写 C380 继续收租, 持仓块写已卷入 C375 且到期前不再卖 call)、TSM (卖 ITM call vs 持有)、ORCL (坏车 vs 卖 put 买股)、周一 (call 倾向 vs 不卖 call)、ARM (腿早段 vs 腿衰竭)、NET 租金 (便宜 vs 噪声)、SPY (三周最空 -4.5 vs 底区卖 put)。证据面更薄: 猎场的 101 条票记录与 99 条三周预测 0 条到期 (首批 10-19 预测 / 10-26 票), 期权流票的权重 1.0 是假设; 房东没有任何记分 (open_price 全空)。鲸群多日布局这一侧, 我们每天其实已经下载了整条期权链的逐 strike OI, 却只存前 3 档汇总就丢掉; 唯一的跨日战役检测器 (whale_campaign) 09-27 起已停跑; 单日读单读得准, 但没有一张把同一合约跨日累计、用 OI 确认 "开了并留过夜" 的账本, 所以看不穿 2-6 周的布局。今天的版面重排只改位置, 冲突在源头, 要靠四件事去掉: 每个量一个 owner, 一张规则表, 一个读结构化数据的决策摘要步, 一本逐 strike 的战役账本。P0 五项约 9 小时, 应在 10-05 周一开盘前做完: 四项会直接让人下错单, 一项 (OI 落盘) 每晚不做就永久丢一天数据。

5.3 动机读法: 对在哪, 错在哪, 最小战役视图

对的部分: 单笔的执行机制读得准。Side-first 定发起方, OPRA 码分开电子单 / 扫单 / 拍卖 / 场内 / 对敲 / 挂股, delta 门把长期限的锁利 put 排除, 同一秒多腿合成组合, 双到期同向不误判为 roll。错的部分都在 "跨日": 第一, 同一合约连续 5 天被买, 是 5 张互不相干的 "主动 call 买盘" 票, 没有累计张数、均价与留存; 第二, 三周前建的仓今天平掉 (例如买回之前卖出的 call) 在单日读里像新开的多头, 而开平标记只覆盖 3.8% 的行, 没有 OI 就分不出; 第三, roll 只认同一秒的两腿 (daily_hunt.py:157-202), 今天平 C380 明天开 C400 读成一空一多; 第四, gamma 墙来自全体 OI, 是人群的布局不是鲸群的布局; 第五, LLM 只见两天, 用 "公开看法 diff" 判 hidden / priced, 但不知道战役年龄与成本, 判不出 "布局已完成待发动" 还是 "刚起步"; 第六, 动机缺 方向 / 对冲 / 收入 / 波动率 四分的查表判据, 现在把收租式卖 call 算成看空 (冲突 7)。

最小战役视图, 每票一张表, 放依据区; 当日有战役新动作时进 A1 / A2 / A3:

合约簇或结构首见出现天数 / 窗口主动方净 premium累计张数OI 首见 -> 最新 (留存)码分布均价 -> 现价 (鲸群浮盈)建仓期股价判读
例: 2027-06 C350 (组合腿)日期3 / 10+$x.xM 买na -> b (c%)组合 / 撮合p0 -> p1横盘 / 逆势方向建仓, 已确认

表头一行给 票 / 现价 / 活跃战役数 / 鲸群口径净 delta 美元 / 主战役动机。动机按查表判, 不交给 LLM: 同簇多日 + 打 ask + OI 留存 >= 50% + 无股票腿 = 方向建仓; 挂股包或与持股配对的远端 put = 对冲; 近月 OTM call 卖且挂股或已知持有者 = 收入; 跨式 / 两边价差 = 波动率; 留存 < 20% = 日内或平仓, 不计战役。LLM 改为读这张表写意图与剧本, 不再读两日原始大单。
