  • 判断: 交叉格 = 收租 (Yoneda 3.5 / 5, 必然性 2 / 4; yaml ceiling_class platform, type structural) -- 手机里是 ISA 收租者, 数据中心里是三方共存的份额玩家, 硅业务是新进入者; 按 PE / PEG 定价, 不付终态溢价。种子尺: 本体在长 (B 情景每股 FCF FY26A -> FY29 2.7x, 正常化基数 2.0x; FY31 $3.57); 错配尺: 价格已付清 A。三情景 IRR 到 FY2028 末 A -27% / B -47% / C -69%, 到 FY2030 末 A +1.6% / B -21% / C -43%, 到 FY2031 末 A +6.8% / B -16% / C -36%, 期望为负。现价唯一能赢的路径是 "A 全兑现且 FY31 仍给 60x" (IRR +17%), 两条都要对。
  • 接货位: (1) 鲸鱼布局的承接区 $240-250 (11-12 月卖 put) 恰好落在 "A 情景 FY31 40x 按 12.5% 折现 = $232" 一线 -- 期权卖方把 A 当成地板; (2) Fair Value A $80 (40x 为 $106); (3) 中间价 $130-160 = B FY31 EPS 30-35x 不折现。对相信 B 的人, 合理接货位 <= $135; 对相信 A 的人 <= $232。现价两者都不是。勇者窗口候选: SoftBank 被动卖股 (U6) 或 Qualcomm 判决 (U5) 造成的流通盘踩踏, 只在 $135 以下按 B 接, 不在 $240 按 A 接。
  • Kill (推翻 "价格已付清", 转拿着): 11-04 或 2027-02 财报把 AGI CPU 两年需求提到 >= $4B 且给出 FY28 硅收入 >= $3B、硅毛利 >= 55%; 数据中心版税披露占版税 >= 25%; 版税连续两季 >= +25% 而 QCOM 手机仍为负; 公司在 6-K 写明 $15B 的年份为 FY2031 或更早。三条全中 = A 60x, FY31 IRR +17%。
  • Kill (B 转 C): Qualcomm 案不利判决或 Qualcomm 宣布 RISC-V 旗舰手机 AP; SoftBank 顾问费单季 < $100M 且合同资产不回款; 版税增速连续两季 < 10%; AGI CPU 量产推迟过 2027-03 或首季硅毛利 < 45%; SoftBank 任何 Form 144 / 13D/A 减持或 6-K 披露 margin loan 提前还款。
  • 工具接口: Fair Value A $80, SPR +265%; D2: 对账表 FY30 公司 vs 基准差 55% (> 30%) 且 regime 4 条, D2 不取上限; 新事实回查 yaml: insider_10b5_1_sell 实为 true (Child / Haas / Abbey 10b5-1 卖出 $28.8M), 关联方收入 30% 与 SBC 21% 两个 D4 新旗标命中 (见查表块, 主线程决定是否 ingest)。
