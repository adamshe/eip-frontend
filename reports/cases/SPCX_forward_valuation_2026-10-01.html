9. 结论与 kill 条件

  • 判断类型: yaml ceiling_class = platform。本文拆开看: 星链 + 发射是位置高的收租资产 (B 2030 营业利润 $18.4B, 增长 20%+), AI 分部是 GPU 出租周期资本品 (B 营业利润约零, 内部训练算力纯成本)。现价 $1.95T 是按 "共识路径 = AI 9-10 GW 于 2027 + 全部出租" 付的, 不是按星链付的: 星链 + 发射在 B 情景的分部加总价值约 $0.5T。
  • 三情景 IRR: FY28 末 A -5.6% (PE) / -0.2% (分部加总), B -55% / -37%, C 无意义 / -58%; FY30 末 A +2.3% / +12.7%, B -34% / -14%, C -67% / -33%。每股 FCF FY2030: A 2.24 / B 0.39 / C 0.70; FY2026 -> FY2029 三情景基数为负 (约 -$4.6/股), 改善量 +6.7 / +4.3 / +5.0。
  • 风险结构: 上行要同时满足 2027 年 AI 规模化出租、融资不稀释、Starship V3 按期; 下行只要 AI 租户按 90 天条款缩量或解禁周承接失败任一条。与 GEV 相同点: 风险在倍数; 不同点: SPCX 的 EPS 本身也不确定, 因为 AI capex 规模是管理层的选择。
  • 接货位: 鲸鱼布局隐含 $134 (SMA50 地板) 与 2027-06 卖 P140 (扣权利金有效约 $122); 本文 A 情景现值 $99-113 (2028 PE / 分部加总), B 情景 $40-48。基本面接货位 $100-110 (只在 A 路径信号出现时); 鲸鱼的 $122-140 高于 A 现值, 读作押解禁后流动性与远期期权, 不是盈利。
  • Kill (推翻负面, 转 "拿着"): 11-03 Q3 AI 基础设施收入 >= $4.5B 且云合同额 >= $25B、Customer B 占比下降、订户 >= 13.7M 且 ARPU >= $64; 加 11-05 解禁周收 > $150 放量 (yaml upgrade); 加 2026-12-31 前 Starship 规模部署 V3。三条全中 = A 权重升到 50% (B 40% / C 10%), 概率加权分部加总 2030 约 $157, IRR 约 +1% (估), 仍低于 12.4% 折现率, 只够 "拿着" 不够加仓。
  • Kill (B 转 C): 任一主要 AI 租户解约或 AI 收入环比下降; V3 部署延过 2026 年底; 2027 以低于 $135 发股或可转债; 解禁周 (11-05 / 12-08) 周收 < $130 且放量 (yaml)。
  • 工具接口: Fair Value A $19 (PE 口径) / $40-48 (分部加总), SPR +2.1 至 +6.8 倍; D2 不取上限 (FY27 对账差 +75%, regime 4 条)。
