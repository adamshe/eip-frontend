TSLA 综合报告: 三年公允价值远低于现价; 民主党上台压的是自动驾驶溢价, 不是汽车利润 (2026-10-10)

结论

Tesla 是一家能自己活下去、正把现金押在自动驾驶与机器人上的车厂; 现价 $382.70 (2026-10-09 收盘) 已经超额付清 "公司自己的计划全部兑现", 动作 WATCH: 不买股, 不卖 put。

  • 公司: 汽车与储能还赚钱但利润薄 (二季度营业利润率 1.4%), 2026 年资本开支 > 250 亿美元让自由现金流转负; 无人驾驶刚起步 (德州 169 辆 Cybercab, Waymo 已有 4,000+ 辆无人车)。
  • 价格: 按利润算, 2029-10 的公允价值 p10 / p50 / p90 = $45 / $135 / $510, 概率加权 $194。今天按 $382.70 买、拿到 2029-10: 最好情况每年 +10%, 中性 -29%, 最坏 -50%。要每年赚 15%, 买入价 <= $128 (概率加权); 只信最好情况也要 <= $336。期权市场给 2029-01 的中位数 $325, 差额是市场为远期故事付的钱。
  • 政治: 民主党 2026-11 拿下众议院 (预测市场 90.5%) 只能听证和卡立法, 公允价值约 -2% 到 -3%; 2028 年拿下白宫 (63.5%) 才能换掉汽车安全监管的执行者, 中位 -11%, 加权 -13%。它压的是自动驾驶溢价; 恢复购车抵免与碳积分反而抬高汽车利润底, 但最早 2031 年见钱 (估)。
  • 催化剂: 10-21 盘后三季度财报 (期权隐含 +/-5.1%, 历史财报日中位 8.8%); 联邦对 Cybercab 自认证的调查; 与 SpaceX 合并 (预测市场 2027 年底前宣布 59.5%)。

要点与动作

  1. 不买股, 不卖 put (WATCH) -- 现价高于最好情况三年价值的 15% 买入线 $336。失效: 第 6 条。复核: 10-22 财报反应日收盘后。
  2. 财报前不押方向 -- 10-21 前大概率钉在 $370-400 (call 墙 400, 期权翻转位 364.5)。
  3. 买 put 只在单边下跌浪 -- 触发 (任一): 放量 (>= 1.3 倍 20 日均量) 收破 20 日低 (现 $352.84); 20 个交易日跌 >= 15%; 收在 $364.5 下方且期权结构转向下。动作: 小注买约 60 天到期、约 5% 价外的 put; 目标 $300-310 (2026 低点 $298, 2028-12 大额 put 行权价 $300); 失效: 收回 $364.5 上方。每日收盘复核。
  4. 财报看三件事 -- 汽车毛利 (剔积分) >= 18% 且 2027 资本开支 <= 250 亿 -> 中性情况 FY27 EPS 上调到 >= $2.0, 公允价值中位约 +15% (估); 有效 FSD 订阅 (二季度 148 万); Cybercab 监管答复。
  5. 合并 -- 按市价换股, Tesla 股东约占合并后 41%, 每股价值不变; 每 10% 溢价约 +$38/股; 成交价 >= $506 (+32%) 时 CEO 奖励第一档只按市值即可赚得。合并会把 SpaceX 的国防合同与对华风险一起装进来。宣布当日复核。
  6. 改判转拿着 -- 2028-01 前同时满足: 有效 FSD 订阅 >= 350 万; 无监督 Robotaxi >= 10 个都会区且累计付费里程 >= 1 亿英里; Cybercab 获联邦豁免或新规落地; FY27 自由现金流 >= 0。全中且价 <= $336 -> SMALL。
  7. 转更坏 -- 两季汽车毛利 (剔积分) < 14%; 2027-09-29 前定期贷提款 > 100 亿美元且资本开支不降; FSD 工程分析升级为召回并限功能; 2028-01-19 前后 Musk 出售或质押 > 2.36 亿股。

分析

最终判断

  1. 现价付了什么: $382.70 = 219 倍 FY26 共识 EPS $1.749 = 175 倍 FY27 $2.182。要每年赚 15%, 2029-10 股价须 $582 = 70 倍 x 前瞻 EPS $8.31, 比最好情况 ($7.28) 还高 14%。
  2. 10-01 以来为什么涨 8%: 三季度交付 486,532 超公司汇编共识 461,974 (10-02 +4.7%), 加上合并预期 (SPCX 同期 +9.8%); 两者都不改利润路径。
  3. 必然性: 无人出租车能做成已被 Waymo 证明 (周付费 > 50 万单); 不确定的是 Tesla 的时点与监管路径 -- 它没申请豁免就自认证上路, 联邦正在问 21 个问题; 豁免路线每年上限 2,500 辆 (Zoox 获批口径)。
  4. 基本面变了什么: 真变化 = Cybercab 商用、交付回到同比持平、储能低于预期、FSD 在欧洲改名换审批; 没变 = 利润率、资本开支、自由现金流为负。
  5. 空方: 对在汽车是可替代商品 (BYD 一个季度多卖约 27.6 万辆), 自动驾驶要钱要时间; 错在低估交付韧性 (连续两季超共识) 与油价危机对 EV 的推力。
  6. 多方: 对在成本与车队数据领先、银行给了 300 亿授信; 错在把 2030 年以后的终局当现价的锚, 忽略监管时间窗。
  7. 谁对: 按时间两边都对 -- 2028 年前空方 (利润与现金流) 先兑现, 2029 年后多方的自动驾驶才可能见钱; 现价已把多方结果算进来, 所以现在不站多方。
  8. 是不是有人在推: "合并预期推价" 已证实 (两股同涨, 预测市场与分析师喊 80-90%); "有人设局" 不支持 (无合并文件, 无特别委员会)。
  9. 动作规则: 分类不碰 -> 不买股不卖 put; 单边下跌浪三条见证任一 -> 小注买 put; 改判四条全中 -> 拿着。

前瞻 EPS = 0.25 x FY29 + 0.75 x FY30 (沿用 10-01 三条盈利路径, 三季度交付超预期与储能低于预期相抵, 不改路径)。

一句话: 民主党上台对 Tesla 是 "汽车利润底抬高, 自动驾驶溢价压缩"; 现价约九成是后者, 所以净影响为负。证据: 现任共和党政府的监管也在查 Cybercab, Nevada 只批 10 辆 (申请 5,000), 说明监管阻力不全是党派问题; 民主党众议员已在要求查 FSD。

时间窗: 2026-11 到 2029-01 是联邦行政对 Tesla 最友好的窗口; 无方向盘车辆的新规 (去掉刹车踏板要求) 若在此期间落地, 后任要翻需重走规则程序, 下行有限; 若 2029 年前没落地, 最好情况的概率在 2028-11 大选前后就会被市场下调。

合并怎么算

Musk 持 SpaceX 约 46%、Tesla 19.9% (二手): 每给 Tesla 股东 1 美元溢价, 他在 SpaceX 一侧付约 0.46 美元, 在 Tesla 一侧收回约 0.20 美元, 所以他没有动机给高溢价 (可疑)。按 2025 委托书原文, 若交易构成 Tesla 控制权变更, CEO 奖励只按成交市值判定, 第一档 $2.0T 约合 $506/股; 但付 32% 溢价 (约 4,800 亿美元) 他净付约 1,260 亿, 远大于一档奖励的价值 (3,530 万股 x ($506 - $334.09) 约 61 亿)。结论: 合并更可能接近市价换股, 对 Tesla 每股公允价值中性, 改变的是风险构成 (国防合同、对华业务、听证)。

与 10-01 结论比

结论不变: 现价已付清最好情况, 不碰。变化: (1) 价 $354.11 -> $382.70, 更贵; (2) 期限改为三年 (2029-10), 最好情况的 15% 买入线从 $267 (按 2030 年底) 改为 $336 (按 2029-10 前瞻利润, 期限更短); (3) 中性倍数 45x -> 55x, 因为 2029-10 的前瞻年 FY30 仍增约 35% 且车队可见, 给 1.6 倍 PEG; (4) 新增政治与合并两个变量, 都不进利润路径。
