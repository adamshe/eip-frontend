分析

终局总结

两份同日写成, 分工不同: [估值] 答 "五年值多少、现金去哪", [Muse] 答 "Zuckerberg 说了什么、Muse 带来多少、成功有多必然"。裁决: 财务数字与现金以 [估值] 为准 (T1 filing 加可复算的 D&A cohort 模型); 原话与 Muse 各线以 [Muse] 为准 (电话会原文); 必然性分档沿用 [Muse] 框架, 但第 (1) 档由 "必然" 降为 "大概率" (第 3 问)。其余差异逐条见 F13。

  1. 为什么跌: 触发是 07-29 盘后 Q2 财报, 07-30 开盘 -10.2%、收 538.60 (-8.0%), 量为前三日均量的 3.7 倍 (F1)。同日 T1 内容全在现金侧: EPS $6.18 含法律 $2.40B 与遣散 $1.18B, 公司口径 FCF $784M, 回购 0, 全年费用 $165-169B, 税率指引升到 15-17% (F2 / F3)。谁在卖缺一手证据: 13F 只到 06-30 (FMR -17.8%、JPM -8.4%, 被动承接, F10), 早于下跌; 判为主动卖出, "为 EPS 压缩与 FCF 归零付折价" 是 [Muse] 的解读, 真值 可疑。
  2. 为什么止跌、为什么涨: 先后是 "现金坏消息一次出清, 8 月在 537-612 横住, 9 月由需求侧与产品侧数字接管定价"。浪 1 539.03 -> 777.59 (+44%) 的主体在 9 月, 09-09 +6.6% 与 09-21 +11.4% 两个放量日 (F1) 与 Muse app 首 12 天 280 万装机 (09-21 报道, 倒推上线约 09-09, 推断) 和 Connect 立 Muse 为核心同期 (F4); 高点在 Connect 次日, 当天 Zuckerberg 按 10b5-1 卖 27,474 股均价 $777 (F10, 非信号性)。时间先后已证实, 因果 可疑 (原报告无逐日归因)。
  3. 必然性: 锁死的三件 -- (a) 广告拍卖回路已运转 (单价 +12%、转化 +15.7%, META 广告 +27% 约为盘子增速两倍, F4 / F5); (b) 分发是物理的 (DAP 3.60B, Muse 95% 用户来自 Facebook, F3 / F4); (c) 折旧是会计锁死的 (2027 D&A +$14B、2028 再 +$16-17B, 与后续 capex 几乎无关, F7)。真不确定的: 2027 起 capex 封不封顶 (2030 每股 FCF $10.8 还是 $36.1)、单价能否守 +8%、无 OS 的 Muse 能否成为入口。[Muse] 把 "2028 前广告收入过 $300B 且营业利润增长" 定为必然, 本报告降为大概率: C 情景 (估 20%) 2028 收入 $293B、营业利润从 2026 的 $84.0B 降到 $73.2B (F9), 机制未被证伪, 必然档容不下两成反例。
  4. 基本面变了什么: 真变化在资本结构, 不在需求。事前 FY25: capex $72.2B、每股 FCF $17.91、回购 $26.3B、长期债面值 $59.0B; 事后 2026: capex 指引 $130-145B、Q2 FCF $784M、回购 0、债面值 $84.0B, 另有不可取消承诺 $349B 与未起租租约 $279B + $68B (F2 / F3) -- 从轻资产平台变成重资产平台。需求侧是加速 (Q2 收入 +28%)。重估: 无, PE 23.4x 恰在自身第 50 百分位 (F0)。
  5. 空方: 有组织的空方缺席 (空头 1.4%, F10), 最强反方是 [估值] 自己的 B / C: "EPS 可以涨, FCF 可以不涨, 位置租金付给算力、电力与房东"。对在: 三情景 2026-2028 每股 FCF 全部 <= $0.89, 2030 B 只有 FY25 的 0.60 倍, 概率加权到 2028-12 IRR 约 -7% (估, F9)。错在忽略的事实: capex 是自主变量, C 情景被迫砍 capex 后 2030 每股 FCF ($13.1) 反高于 B ($10.8); 公司自述算力有 "显著溢价" 的买家 (T1 自述, 未见成交, F4)。耐心: 空方的窗口是 2026-10 至 2027, 不是五年。
  6. 多方: 对在机制 (拍卖回路、分发、42 岁创始人持 60.8% 投票权, F10 / F11)。错三处: (a) "现金自给、不需要增发" 只对一半 -- 不增发股票, 但一年内发债 $55B、回购停、表外 JV 剩余价值担保约 $41B (F2), 是借钱自给; (b) 2028 底 $900-1050 依赖 FY28 EPS $39.3 (T3, 未复核), 只相当于 A 情景 ($923, 估 30%), 不是中枢 (F13); (c) $1400 要 FY28 EPS $58.3, 是 A 的 1.5 倍 (F9), 鲸群也只用卖 put 的租金买这条尾巴。
  7. 谁对: 争议票, 两边都对、先后不同。近端 (至 2027 年底) 空方先兑现: D&A 爬坡已锁定, 2027-01 C750 有 24.5 万张 call 墙, 场内卖方把 2027 封在 780 (F10)。远端 (2028-2030) 多方兑现的前提是 capex 2027 封顶 (A', 2030 每股 FCF 为 FY25 的 2.0 倍, F9); 不封顶则多方只赢 EPS 不赢 FCF。开关在 10-28 与 2027-01 两次 capex 指引。
  8. 设局震仓: "有人设局" = 不支持 (07-30 由 T1 财报内容直接触发, 无协同卖出证据)。"事件引发弱手出清 + 价值资金接盘" = 可疑: 支持的是放量跳空后 8 周 +44% 与 10-01 鲸群在 636-682 开仓卖 put 接货 (F10); 缺的是 07-30 谁接 (2026-09-30 13F 11 月中可核)。[估值] 所写 "2025-07 以来 600-748 箱体" 与价格序列不符 (2026-03 至 08 月月低 519-559, F1), 不作证据。
  9. 动作规则 (复盘产物): 条件 = 需求侧指标同季加速 (单价与展示量同升) 而现金侧一次性坏消息 (FCF 归零 / 回购停 / 一次性费用) 引发财报跳空 8% 以上 -> 动作 = 以跳空日低点或浪 1 起点为失效位, 用房东卖 put 分批接货, 仓位 SMALL, 不等 FCF 回来; 现金侧转好 (capex 封顶 + 回购恢复) 才升 MID -> 失效 = 需求侧同季转弱 (单价 < +8% 两季) 或收盘破失效位。本票当下的落地是要点第 2 至 5 条。

本体: 先证明不是什么

不是模型公司: 2024 年自述 "卖模型访问权不是商业模式", Muse Spark 发布时 AA 指数 52 落后前沿 57 五分, API 线 2027 年不到收入 1% (F4 / F6)。不是入口持有者: OS 级默认助手已被 Apple-Gemini 与 Android-Gemini 分完, Muse 是 app 级, 这是七条失格里唯一的红灯 (F11)。不是算力房东: 卖算力是选项, Zuckerberg 自己偏好卖智能 (F4)。不是商家图持有者: Amazon 封了 Muse 代购 (F4)。排除完剩下的是人与人的关系图加自家流量上的广告拍卖 (N1 / N3 / N4 = 1, N2 = 0; Yoneda 4/5; 位置分 27/30, F0 / F8 / F11): 广告主买的是人, 不能自建 3.6B 的触达。反方的 agent 论证 (agent 替人浏览、不看广告) 打的是注意力租金这一层, N2 = 0 已承认这层可绕, 但它没打到关系层 (N3), 所以它是 C 情景的单价驱动, 不是本体否定。

现金与估值: 价格已付到哪里

现价隐含 FY28 EPS $33 (22x 零折现), 介于 A 的 38.5 与 B 的 30.0 之间; 要 15% IRR 需 FY28 EPS $44.7 (F9)。系统读数与此一致: PE 23.4x = 自身第 50 百分位, 合理价 724.97 (F0)。两把独立的尺在 600-616 相遇: [估值] B 情景退出 20x 的 2028-12 目标 $599, 系统自身第 20 百分位的估值门价 616.07 (折算约 19.8x); 浪 2 第 2 档 630-658 与鲸群 2028-12 接货位 636 叠在其上 3-7%。

按 [估值] 的权重 (A 30 / B 50 / C 20, 估) 算, 2028-12 与 2030-12 的概率加权终值都在约 $640 (算术, F9)。含义: 现价比它高 14%, 期望为负; 在 616-658 接货大约只付清加权终值, 收益来自 put 权利金、股息与 10-28 之后权重向 A / A' 移动。所以接货只配 SMALL, 升档等 capex 信号, 不是等价格更低。[估值] 的双轨 Fair Value A $478 (B 情景折现到今, SPR +52%) 是更严的尺, 用它 616 仍溢价 29%; 两把尺的差别是要不要为 B 情景要求 10.8% 的年回报, 本报告以加权终值作中枢、以 Fair Value A 作 C 情景下的最坏承接参考。
