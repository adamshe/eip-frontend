分析

终局总结

本报告是估值合并, 不是事件复盘; 九问的主语按 "顶后回撤 + 现价付了多少" 改写。

  1. 为什么跌 (06-30 收盘 $1,174.86 -> 09-14 $874.76, -25.5%): 原报告没有下跌触发的一手原话, 不归因。可见的: 07-22 Q2 财报日公司把 2026 FCF 指引从 $6.5-7.5B 提到 $11.5-12.5B、签约 100 -> 116 GW, 股价当日 -8.7% (量 4.9M 股) -- 好消息下跌是 "已定价" 的形态, 且上调的 FCF 来自客户押金 (可疑, 推断); 另两个大跌日 08-18 (-6.9%) 与 09-14 (-8.6%) 原因未取。谁在卖: 13F 2026-06-30 显示主动机构在顶部区的二季度减 (FMR -11.9% 至 6.06%, JPM -7.4%, MS -10.3%), 被动承接 (BlackRock +5.0% 至 8.17%); 内部人只卖 $11.5M、零买入; 空头 3.3%。7-9 月是谁卖要等 Q3 13F。
  2. 为什么止跌、为什么涨 (09-14 -> 10-02 $988.70, +13.0%): 机制无一手证据, 不归因。可见的锚: 低点在公司 YTD 回购均价 $854 上方 2.4%, 现价在 Q2 回购均价 $952.47 上方 -- 管理层自评线; 10-01 单日 +3.9%, 量 2.9M 股。
  3. 必然性: N = 2 / 4。锁死的: 已装机必须被服务或退役 (服务 RPO 92% 在 15 年内兑现); 2026-2030 窗口内 GW 级可调度新建只有燃气 (SMR 2030 后, 电池小时级)。没锁死的: 新机 Siemens Energy / MHI 两条可行绕行 (N2 = 0); 数据中心可经公用事业 / IPP 走任一 OEM 或现场 SOFC 绕开 GEV (N3 = 0); 2029 后三家扩产追上需求 (先验 60%, 估)。
  4. 基本面变了什么: 真变化 -- 签约 62 -> 83 -> 100 -> 116 GW 四季连升, 订单单价约 $540 -> $820/kW (估), 设备积压利润 +6 pts, 合同负债半年 +$14.2B。重估 -- FY26 GAAP EPS $30.58 含约 $4.4B 一次性 (剔除后约 $12.9-14.2, 估), 2026 报表 FCF $12B 是押金时间差 (剔押金 CFO 为负); 公司 2025-28 累计 FCF >= $24B 隐含 2027-28 合计只需 >= $8.3B: 2026 的 FCF 峰不是趋势。
  5. 空方 (倍数压缩) 对在哪、错在哪: 对 -- 共识 2028 EBITDA $13.1B 已比公司自己的展望 $11.2B 高 17%, 订单增速 2026-27 见顶是基数必然, 10-K 自认 slot "may not result in orders", 三家都在扩产。错 -- 2028 EPS 被积压锁定 (设备 RPO 65% 两年内确认), 做空是与 "订单增速何时见顶" 对赌时点, IV 约 52%, 赔率不在空方; GE Power 2016-19 先例是记忆 (T3 未核), 不能当承重。
  6. 多方对在哪、错在哪: 对 -- 机制链硬: 116 GW = 5 年产能, 押金 $40B 真金, 下游用真金买现成气电 (CEG $21.8B 买 Calpine; 现成气电成交 $1,136-1,419/kW), 超大规模 2026 capex 约 +70% (估)。错 -- 把三家同步售罄的周期稀缺当成 "必须经过 GEV" 的结构位置 (该本体已被排除, 见反方审计第 3 步); 没计价格已付: 卖方均价目标 $1,230 隐含 FY28 共识 35.8x, 15% IRR 需 FY28 EPS $45 = 2030 年 30 GW 的利润提前两年。
  7. 到底谁对: 按时间尺度 -- 2026-2028 业务层多方对 (已证实, T1 积压与押金); 价格层空方对 (已证实: FY28 共识 = 全兑现情景, 倒算期望为负); 2029 以后的倍数压缩 可疑 (先验 >= 60%, 估)。两份报告方向一致 (观察, 不建仓); 不一致处以 vet 的逐项判定与 FY28 共识为准 (见下文 "两份报告不一致处的裁定")。
  8. 是不是设局震仓: "有人设局" 不支持 -- 无 13D、内部人零买、空头 3.3%, 三个大跌日两个原因未知, 没有可指认的设局方; "弱手出清 + 价值资金接盘" 可疑 (证据不足) -- 可见的价值买家只有公司回购 (Q3 金额 10-28 的 10-Q 才知), 主动机构的减仓在 6 月顶部区不在低点, Q3 13F 未出。
  9. 动作规则: 现在 WATCH: 不买、不卖 put、不追。条件: 价进入 $520-650 且最近一季 slot 转单 >= 已到期一半、Power 设备合同负债环比不降 -> 房东卖 put 接货 (同因子权利金合计 <= 2%); 价 < $620 -> 先重答判断类型门再加; 持有者卖 $1,150 以上 call。失效: B 转 C 任一条 -> 不接或全出; 转拿着三条全中 -> 停卖 call、升拿着。复核: 2026-10-28 / 2026-12 投资者更新 / 2027-02。

本体: 为什么按 "周期或收租" 定价

GEV 有两层。服务层是年金: 装机约 7,000 台燃机、1,800 台长协平均剩 10 年, 服务 RPO 2023 / 2025 / 2026H1 = $75.1B / $86.0B / $88.5B 逐年升, 每台新交付自带 20-30 年服务 -- 这是 Yoneda 第 3 条 "按构造自增" 过的理由, 也是 Adversary 门过的理由 (叙事不成立时存量自己能活: FY25 FCF $3.7B, 服务占收入 45%)。设备层是周期: 三家 OEM 同时售罄 (Siemens Energy Gas Services book-to-bill 2.65, MHI 积压 35 GW 同比 +52%), 拒绝权 (slot 费 + 新单 $/kW 升 10-20 点) 来自稀缺窗口, 10-K 自认 slot 预订可能不转订单、扩产可能跑在需求前。窗口关闭的物理时钟是三家扩产: GEV 自己 20 -> 24 -> 30 GW (2026Q3 / 2028 / 2030), 另两家 GW 数无数据。本体 = 装机房东 + 周期产能收租者, 不是 chokepoint: 按 PE / PEG 与周期定价, 不付终态溢价。

组织面: 职业 CEO Strazik 直接持股约 0.06%, 薪酬 FCF / EBITDA 导向 (AIP 40% FCF / 40% EBITDA / 20% 有机收入), 凹赔付, F = 0; 分拆两年半换了 Power CEO、CFO、CLO 三位, CFO 2027-01 换成前 Rivian CFO -- 长协会计是新 CFO 首份 10-K 的复核点。种子模型说它是合格种子 (活力公司 x 活力行业, 四时钟三对齐一错位), 但无天选之子且价格已付 -- LITE 型 "种子对, 价格错"。

估值: 现价付了多少

三条独立路径落在同一个数上: (1) 卖方 FY28 共识 EPS $34.33 (marketscreener 37 位); (2) 倒算 A 情景 (共识 FY27 + 公司 2028 分部率 22%) FY28 $34.0; (3) 产能上限 -- 2028 年 24 GW (公司自述, T1) x 交付价约 $720/kW (估) 推出 FY28 收入 $61.2B, 与 A 情景 $60.0B 同量级。现价 $988.70 = 28.8x 这个数, 等于把 "公司自述全兑现 + 22% 分部率" 零折现买下, 并假设 2028 年末市场仍付约 29x。所以全兑现也只有 +1.5% (30x) 至 +8.6% (35x) 的年化; 中性 B (利润率走公司线性路径, 退出 22x) -18%; 下行 C (2027 capex 平台 + slot 转单停滞, 退出 14x) -48%。上行要两条同时对 (FY28 EPS >= $45 且 PE 维持 30x), 下行只要任一条 (订单增速转负, 2027 起先验 >= 60%, 估; 或 slot 转单停滞) -- 赔率结构对现价做多不利。

与 LITE 的差别 (估值报告原判): LITE 的风险在 FY28 EPS 本身, GEV 的风险在倍数 -- EPS 不跌, 市场不再付 40x。FCF 质量放大这个风险: 1H26 CFO $10.68B 里 $13.7B 是合同负债增加, 剔押金 CFO 为负; 2027-28 押金随交付转收入, 营运资金反向。用报表 FCF 收益率 (2026 约 4.6%) 给估值会高估, 裁判尺用正常化每股 FCF (2025 $13.4 -> B 情景 FY28 $24.5, 1.8x)。

价值区间: Fair Value A $516 (B 情景 22x 折现; 25x 为 $586), 无战略资本 K, SPR +91% (按 $988.70 为 +92%)。接货区 $520-650: 下沿 = Fair Value A, 上沿 = 2025-12 价位 $652; $620 = FY27 PE 25x, 是 Yoneda 第 5 条 "尚未被定价" 的翻转线。现价离上沿 -34%, 离下沿 -47%。对照: 同一短缺同一客户的 Siemens Energy 前瞻 23x、ETN / ABB 27x、MHI 41x。

反方审计

第 0 步 承重句。我方: "FY28 EPS 被产能与积压锁在约 $34, 现价已按约 29x 付清"。两条独立证据指向同一数: 公司产能路径 24 GW (8-K 2026-07-22, T1) 与 FY28 共识 (T2 单源); 最弱一环是燃机交付价 $/kW (估, 非燃机分摊)。它若错 (Electrification 或新单价把 FY28 EPS 推到 $45), WATCH 结论倒。反方 (多方) 承重句: "稀缺定价延续到 2030, 市场继续付 30x 以上" -- 依赖 Siemens Energy / MHI 扩产 GW (无数据) 与超大规模 2027 capex (2027-01 至 02 才知)。

第 1 步 反方最强版本 (多方): (1) 116 GW 已签 = 5 年满产, 押金 $40B 在账, 设备积压利润 +6 pts, 2028 收入 $56B 是 1 月设、7 月上调 2026 后未更新, 偏保守 (8-K, T1); (2) 下游用真金买 GW: CEG 买 Calpine、VST 买 Cogentrix、Georgia PSC 认证 9,885 MW, 现成气电成交价给 OEM 设备价留了涨价空间 (对手方 10-Q, T1); (3) 33 位卖方评级 Buy, 均价目标 $1,230 (T2)。空方最强版本: 资本品订单增速转负时倍数先压缩; 报表 FCF 全是押金; 共识 2028 EBITDA 已高于公司展望 17%。

第 2 步 五项检查。对多方: 事实成立 (T1); 逻辑断在偷换 -- "三家同时售罄" 不等于 "必须经 GEV" (新机两条可行绕行); 忽略的事实是多方自己的数据: 公司 2028 展望低于共识, slot 可能不转单, 三家都在扩产; 情绪不极端 (Stocktwits 关注 10,687, 目标价离散 1.54x, 空头 3.3%), 无反向信号; 耐心维度多方对 (2026-28 业务兑现), 但价格已在 2026-10 付清。原样量我方: 事实上 FY28 共识只有单源、$/kW 为估; 逻辑上 GE Power 先例是记忆, 只能当旁证; 可能忽略的是 12 月投资者更新上调 2028 展望 (已列为 "转拿着" 条件); 耐心上, 接货区可能 2027 以后才出现或不出现, WATCH 没有仓位成本, 只有机会成本。

第 3 步 先证明不是什么。不是 chokepoint (新机三家可替代, 数据中心可绕, N2 = N3 = 0; EIP 先验 security-taxonomy 记 GEV 为 strategic 3.4, 非 Yoneda host); 不是平台 (封闭设备 + 自家服务, 无第三方在其上定价, 品类 = 硬件类); 不是 turnaround (燃气订单 9.5 / 20.2 / 29.8 GW 三年升); 不是有天选之子的种子 (F = 0); 不是风电公司 (Wind 24% 收入但年亏 $0.4-0.6B, 是拖累不是本体)。剩下 = 装机房东 (服务年金) + 周期产能收租者。多方 "必须经过 GEV" 建立在已被排除的 chokepoint 本体上; 空方 "周期顶" 与本体一致, 但忽略了服务年金底。

第 4 步 出口: 两边承重柱都站住 (多方: 2026-28 业务兑现, T1; 空方: 价格已付 + 倍数压缩先验), 兑现时间不同 -> 争议票, 走第 5 步。

第 5 步 时序。多方先兑现: 2026-10-28 签约 >= 125 GW、12 月投资者更新、2027-02 Q4, 业务数据大概率继续好 (Q3 超预期先验 60%, 估), 但价格已付 -- 近端仓位不是猎场做多, 而是持有者房东收租 (卖 $1,150 以上 call)。空方后兑现: 订单增速见顶与倍数压缩在 2027 起 (先验 >= 60%, 估), checkpoint = slot 转单 GW、Power 设备合同负债环比、Siemens Energy Gas Services 订单同比、超大规模 2027 capex 指引 -- 远端仓位 = 接货区 $520-650 卖 put。切换由 checkpoint 触发: 价进接货区且 B 转 C 未触发 -> 接; 价进接货区但 B 转 C 已触发 -> 不接, 按 C 重算。近端卖 call 与远端卖 put 方向相反, 不算对冲, 各自按同因子权利金上限算。
