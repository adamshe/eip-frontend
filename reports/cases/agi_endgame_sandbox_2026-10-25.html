AGI 终局沙盘推演: 2026-2036 十年时间线 (2026-10-25)

资料截至 2026-10-25 (周日); 行情为 2026-10-23 收盘, 2026-10-25 拉取。标签: [已核: 来源 日期] = 本轮现查到一手原文; [二手] = 只找到媒体或转述, 按可疑处理; [估计] = 本文推算或判断; [查不到] = 已查无结果, 附下次数据日期。B = 十亿美元, T = 万亿美元, 亿 = 1 亿美元。本文是 naughty boss 的十年推演公开版, 只放研究结论与最小依据。

缩写: AGI = 通用人工智能 (这里指能做掉大多数知识工作的 AI 系统); ASI = 超级智能 (在几乎所有领域超过最强的人); METR = 第三方 AI 评测机构, 用 "模型能独立完成多长的人类任务" 衡量能力; capex = 资本开支; YCC = 收益率曲线控制 (央行给长期利率设上限); UBI = 普遍基本收入; MTS = 美国财政部月度财政报表; TIC = 财政部国际资本流动数据; GENIUS = 美国 2025 年稳定币法; S-1 = 美国上市招股书; PIT = 个人所得税; PPA = 长期购电合同; GW = 吉瓦 (百万千瓦)。

结论

  • 主判断: 危机先于 AGI, 概率 65% (此前工作假设 60%)。 扳机不是 "债务自己爆", 而是一条链: AI 开支增速断崖 -> 信用最弱的一环先断 -> 衰退 -> 财政赤字被放大到 8-10% GDP -> AI 板块深跌 -> AGI 在低位出现。四条新事实站在这一边: 联储 2026-09-16 还在加息 [已核]; 六家主要建设方 2027 年开支增速从 +90% 掉到约 +14% [估计]; AGI 中位时点后移到 2028Q4 [估计]; AI 链股价已从高点回撤 12-51% [已核: 2026-10-23 收盘]。站在另一边的只有一条: AI 收入涨得比假设快 (2026E +250% [估计])。第一个弱信号约在 2026-12 下旬 (Anthropic 上市后 30 日); 主判别日 2027-01-27..02-04 (四家大云 2027 年开支指引); 确认日 2027-03-31 (OpenAI 过桥融资)。
  • 美国债务危机不会自己先来。 名义 GDP 同比 +6.3%, 约等于赤字率 6.2%, 公众债/GDP 一年只升约 1 个百分点 [已核: FRED, MTS]。财政是放大器, 不是起爆点。财政侧确认日: FY2027 全年 MTS (2027-10 中旬)。
  • 近端是通胀, 不是通缩。 联储目标 3.75-4.00%, CPI 同比 3.7%, 10 年期国债 5.00% [已核]。商品与服务的通缩起点在 2028 年下半年之后 (先是认知服务, 实物 2030+) [估计]。正式 YCC 只会在国债市场失灵时出现, 到 2030 年约 25%; 更可能的是不宣布的金融抑制 (定向购债、放松银行持债限制、稳定币持债), 约 70% [估计]。
  • AGI 中位 2028Q4。 第 7 代前沿模型需要 2028 年上线的 5GW 级集群, 正落在融资最紧的窗口 [估计]。可判别: 第 6 代在 2027-05-01 前发布 = 代际加速成立; 2027-08-27 后 = 放慢。
  • "搜索广告会死" 不成立。 Google 搜索收入 2026Q2 同比 +16.8%, 真正在萎缩的是给人看的网页广告网络 (-0.7%) [已核: Alphabet 8-K]。安卓默认 agent 已是 Gemini, 苹果下一代基础模型也基于 Gemini [二手]; 但 iOS 的入口仍是苹果自己的 Siri, Google 在那里收模型费, 不收广告位。下次读数 2026-10-28。
  • AI 实验室是加杠杆的租户, 不是基础设施的主人。 Anthropic 云承诺约 4,500 亿美元且多数不可撤销, 2025 年近一半收入经 Amazon 与 Google 渠道 [二手: 泄露的招股书草稿]; 截至 2026-10-25 没有公开 S-1 [已核: EDGAR]。上市是派发事件。
  • Cloudflare 拥有 agent 的身份核验位, 不拥有 agent 的钱。 AWS 的 agent 支付预览只接 x402 协议与 Coinbase / Stripe 钱包, 端点目录在 Coinbase [已核: AWS 2026-05-07]; Visa、Mastercard、Amex 的 agent 协议都用 Cloudflare 主导的 Web Bot Auth [已核]。下次读数 2026-11-05。
  • 国家选的数字美元轨道是稳定币, 不是 BTC。 OCC 的 GENIUS 终规 2027-01-18 生效 [已核]; "BTC 暴涨 = 大局已定" 降为 30%。Strategy (MSTR) 不是 "溢价时转、深跌时清零" 的二值机器, 而是扩张 / 收缩 / 清零三态, 今天在收缩档; 首个可转债回售日 2027-09-15。
  • 纽约市的税务风险是 "收入塌后 12-18 个月全类加物业税率", 不是 "先加商业楼后加小住宅"。 2002 年先例: 衰退后市议会批准 18.5% 税率上调 [二手]。下次读数: FY2028 市预算 (2027-06 末)。纽约州 Good Cause 驱逐法整条 2034-06-15 到期 [已核]。
  • 联邦遗产税免税额 $15M 无到期日, 是否下调看 2028-11-07 大选 [已核: IRC 2010(c)(3)]; 纽约州免除额 $7.35M, 3 年赠与回算适用于 2032-01-01 前死亡 [已核]。
  • 外部 AGI 推演框架压力测试 (第 14 节): 主判断不改。 四条判不成立: 原子与能源边际成本十年内趋零 (含绝对通缩)、常温超导与微型发电瓦解电网与铜、资本全面涌入 BTC、科学突破 "瞬间" 击穿秩序。科学突破按两段读: 发现那一刻金融先重定价 (真假一个月内可验证), 社会要等交付 (材料 10-20 年、聚变电厂 2030 年代后、肿瘤药危机速度下 2030-33、逆转衰老先要改法)。ASI 按 naughty boss 2026-10-25 裁定: 不公开推出, 只在实验室 (及国家), 本文不做点预测。新加要盯: Anthropic 公开招股书的治理一节 (预计 2026-10-26..11-02)、SPARC 聚变 Q>1 (目标 2027)、最强模型 "公布不上线" 满 18 个月 (2027-10-07)。
