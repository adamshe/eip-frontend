Oracle AI 基建: 血亏概率与时间表 (2026-10-03)

数据日 2026-10-02 收盘 (ORCL $142.30, 市值约 $431B, 现查 yfinance)。血亏 = 一块容量在整个寿命内的净现值低于投入 capex 的 -30%。T1 = SEC 文件 / 公司新闻稿; T2 = 三家以上独立来源或电话会转录; T3 = 一到两家来源; 估 = 本文推算。

结论

  1. OpenAI 这块账最终血亏的概率约 20% (区间 12-29%)。 期望净现值仍为正, 约 +18% capex。分布是两头的: 要么赚, 要么血亏, 中间很少。
  2. 血亏要两件事同时发生。 一是 OpenAI 停付或大幅降价; 二是 GPU 租价进入能效均衡 (旧卡租价每年跌约 44%)。只发生第一件不够: 在今天的稀缺价格下, OpenAI 违约反而能以更高市价转租, 模型里这种情形净现值是正的。
  3. 单价是唯一能单独翻盘的变量。 若真实每 MW-年合同价只有 IREN-微软水平 ($9.7M), 不论 OpenAI 付不付, 血亏概率都是 60%。合同单价目前只有单一媒体来源。
  4. 最危险的窗口是 2027 下半年到 2029 (Oracle FY28-FY29)。 OpenAI 付款从 FY28 起爬坡到每年 $30B 以上, 15-19 年的机房租约在 FY27 Q2 到 FY29 集中起租, OpenAI 价格战情景的现金在 2028 年见底, Amazon 的 $35B 认购承诺在 2028-12-31 前不投完就失效。第二次检验在 2031-2032 合同到期重新定价。租约尾巴拖到 2042-2046。
  5. 血亏不等于破产。 最坏路径 (FY29 停付 + 均衡价) 的名义缺口约 $66-96B, 对 $431B 市值、$125B 债务是重伤不是致命。传导链是: 评级跌出投资级, 再融资利率上升, 股权稀释。
  6. 股价已提前定价近端恐慌。 股价从 2025-09-10 的 $324.63 跌到 $142.30, 跌 56%。期权大资金没有押近端崩塌: 近月押反弹, 尾部保护放在 2028 年, 与模型的风险窗口一致。

1 口径与模型

单位是 1 MW IT 负载。Oracle 出 GPU 与网络设备 (capex), 机房向开发商租 15-19 年。OpenAI 按固定价照付; 停付或合同到期后, 这块容量按当年市场租价转租。市场租价每年按体制衰减, 转租毛利转负就停机。停机后机房租金继续付到租约结束, 一半面积能转租。所有 (违约率情景 x 价格体制 x 违约年份) 组合按概率逐一枚举, 不抽样。

两个读法:

  • 稀缺体制下违约是好事。合同价约为当时按需市价的 65%, 收回容量按市价转租反而多赚。这正是 Oracle 电话会说 4 年以上旧卡续约溢价 20% 的机制 (T2)。

5 期权布局 (09-28 至 10-02, 现价 133 -> 142)

先读布局:

  • 近月押反弹。 09-29 11:47:50 场内多腿包, 把 10-02 到期的 C150 / C155 (卖出约 5.3 万张) 卷到 10-16 的 C150 / C155 / C160 (约 7.1 万张, C155 与 C160 吃卖价)。净付权利金约 $11M, 目标 150-160, 期限两周半。10-03 至 10-16 之间没有排定的 Oracle 公司事件 (investor.oracle.com 事件列表为空, T1); AI World 年会是 10-25 至 10-28 (oracle.com, T1), 在到期日之后。这一注押的是无事件的价格反弹, 不是押消息。
  • 远期凸性做多。 2027-12 C180 两天在卖价买入约 6,400 张, 多腿切片, 买方权利金 $12.6M。10-02 场内风险逆转: 卖开 2028-12 P210 500 张, 买 2028-12 C220 500 张, 是合成多头。
  • 尾部保护放在 2028。 2028-12 P125 场内买 2,400 张, 同时卖 2028-12 P120 2,000 张、买 2028-01 P140 1,000 张, 是 2028 年保护的换挡。10-02 又有 2028-01 P140 对敲买 1,020 张、P150 对敲卖 1,250 张。
  • 挂股票的组合不计方向。 TLAT / TLFT / TLET 都是备兑或套利结构。近月 put 买入只有 $1-2M 级别, 没人花大钱买近端崩塌。

推出意图: 大资金在做哑铃。近端押反弹到 150-160, 远端押 2027-2028 的上行凸性, 把尾部保护停在 2028 年。

再对照公开看法: 头条是 CDS 纪录、评级下调、不可抗力、"$18B 债务问题", 看空叙事是共识。差异在时间: 共识在定价近端信用事件, 布局和模型都指向 2027 下半年到 2028 年。

7 反方检验

  • 稀缺能持续吗 (看多方)。 Q1 GPU 利用率 97.9%, 旧卡续约溢价 20% (T2)。若稀缺贯穿 2032, 血亏概率为 0%。权重不提高: 这是当前体制的证据, 不能外推到合同期满之后。AWS p5 表价三年年降 17% (T1) 说明稀缺期价格也在跌。
  • 客户自带硬件 (看多方)。 $75B 预付与自带硬件把 GPU 风险转给客户。若 Oracle 实际 capex 只有 $21M/MW, 血亏概率降到 6%。OpenAI 合同里自带硬件的比例未披露, 中心值不动。
  • 重谈比违约更可能 (看空方)。 若 OpenAI 从头压价 30%, IT 口径下等于每 MW-年 $9.3M, 血亏概率 60%; 园区口径下仍为 0%。重谈与停付同样危险, 取决于 4.5 GW 的口径。
  • 违约与价格战相关 (看空方)。 已纳入中心值, 血亏概率从 18% 升到 20%。
  • 历史同型。 1999-2002 光纤: 长约租给初创运营商, 客户倒闭与带宽价格崩溃同时发生, Global Crossing 2002 年破产。2000 年 Lucent / Nortel 的供应商融资循环: 设备商借钱给客户买自己的设备。2008 年干散货: 波罗的海干散货指数从 5 月约 11,800 点跌到 12 月约 660 点, 长租约对手违约与运价崩溃同步。共同点是交易对手违约和资产价格崩溃同时到来。Oracle 的不同点是有非 AI 的现金业务托底, 不是初创。

9 什么会改变结论

  • Oracle 或 OpenAI 披露合同单价或 4.5 GW 口径。单价是唯一能单独把血亏概率推到 60% 的变量。
  • 合同终止与违约补偿条款披露。当前假设停付后 Oracle 拿回容量、没有补偿。
  • 价格体制的实证。合同期满前若出现大规模旧卡折价续约, 均衡权重应从 60% 往上调。
