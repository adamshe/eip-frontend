LLM 本地化对 NET 与 Anthropic / OpenAI 的冲击 (2026-10-17)

naughty boss 10-17 提问: "VET LLM 本地化对 NET 和 AO 的冲击和影响", 附一篇 RTX Spark 首发体验帖。AO 按 Anthropic + OpenAI 读 (两家闭源前沿模型公司; 10-04 已核无歧义, 本次没有找到指向别的含义的证据)。股价取 2026-10-16 收盘, 汇率取 10-17 报价, 模型价格取 10-17 官网牌价; 标 "估" 的是推算。

结论

LLM 本地化是真的, 但它拿走的是最便宜的那一档词元 (token, 模型读写文字的计量单位, 一个汉字约 1-1.5 个), 不是 Anthropic / OpenAI 赚钱的那一档; 对 NET 净影响 0 到小正; 不改任何动作。

  • 机器是真的: 英伟达 RTX Spark 笔记本 10-16 全球开售 (美国 2,599 美元起, 国内 18,999 元起), 最高 128GB 统一内存 (CPU 与显卡共用一块大内存, 所以装得下 270 亿参数的模型); 华硕 128GB 版 37,999 元首发批次售罄, 数量未披露。帖子的数字大体属实, 只有视频生成时间被说短了一半。
  • "Token 自由" 按字面不成立: 37,999 元 (约 5,683 美元) 按 3 年摊, 就算 24 小时满载, 本地每单位成本约 3.0 美元, 比同档或更强的云端小模型 (Claude Haiku 5.5 / GPT-6 Luna, 2.0 美元) 还贵; 只有对比同一模型的云价 (约 8.5-10.5 美元) 或国内开发者整天跑循环的账单, 才在 10-13 个月回本。本地真正赢在隐私、零延迟和 "用了不心疼"。
  • 质量差距还大: 本地跑得动的 270 亿参数模型综合测评 34 分, 前沿模型 51-58 分 (第三方 Artificial Analysis 智力指数, 10-17)。编程 agent、长任务、大上下文仍在云上。
  • Anthropic 约九成收入来自企业 API 与编程 (第三方估), 暴露最小; OpenAI 消费订阅占比高、入口依赖手机与电脑系统, 暴露略大, 但消费者不会为省 20 美元月费买 2,599 美元起的电脑, 真正的渠道风险是系统厂商用本地小模型接走简单问题。两家已把小模型价降到每百万词元 0.10 / 0.50 美元 (Anthropic 比上一代低 10 倍, OpenAI 比上一代低 2-2.4 倍), 低档的价格战早已开打。
  • NET: 唯一直接受损的是 Workers AI (NET 在边缘机房按调用卖开放权重模型推理), 它卖的正是本地免费跑的同一个模型, 但这块收入未披露, 估不到总收入 2%; 本地 agent 照样上网取数、调工具, 机器人识别和收费口的需求只增不减。
  • 算力出租与信用层: 本地吃的是旧显卡上跑开放模型的长尾, 不是前沿训练与前沿推理; 对旧卡租价方向略负, 量级小, 不改信用层判断。

要点与动作

  1. 不因本地化改判 -- 做什么: NET / Anthropic / OpenAI / 算力链的既有动作一律不变; 条件: 本地机首年 500-1,000 万台 (券商供应链, 可疑) 能接走的词元按云端小模型价每年约 1-8 亿美元 (估), 不到两家合计年化收入约 1,170 亿美元的 0.7%; 失效: 任一家在招股书或财报里把小模型档或个人订阅放缓归因于本地 / 端侧模型; 复核: Anthropic 公开 S-1 (上市招股书; 按 11-09 当周路演倒推最晚约 10-25, 截至 10-17 EDGAR 无), 2027-02。
  2. 上市窗口防叙事, 不防经济账 -- 做什么: Anthropic 定价周 (11-17 到 24, 可疑) 若出现 "便宜模型 / 本地替代" 集中叙事 (英伟达与 AI 链同日大跌且原因指向便宜模型, 同 2025-01 DeepSeek), 不追空; 条件: 叙事冲击不改收入结构; 失效: S-1 显示小模型档或个人订阅占收入 > 20%; 复核: S-1 公开日, 定价周。
  3. 三个读数决定是否升级 -- 做什么: 每月看; 条件 (任两项出现 = 本地化升为一线因素): (a) 128GB 级本地机单季出货 > 300 万台; (b) 两家再次下调或下架小模型档, 或个人订阅增速连续两季低于 API; (c) H100 租价指数一季 -25% 且同期开放模型托管商降价; 失效: 一年内三项都不出现, 本主题降为年度复查; 复核: 每月初, 2027-04。
  4. NET 见 NET 综合报告第 0g 节与要点 0g。

用量结构 (谁的词元能被接走):

  • Mozilla 09-15 报告: 8 月开放权重模型处理了 OpenRouter (按调用转售各家模型的平台) 的多数开发者词元; 约 4% 的模型层收入份额出自 2025-05 到 09 的旧窗口 (最近一次有人公布收入的数据), 不是 8 月 (二手转述, 可疑; 中信里昂另有 29% 的数字, 未调和, 未核)。
  • OpenRouter 与 a16z 2025-12 报告: 开放权重约占词元三分之一, 其中 52% 是角色扮演; 价格降 10% 用量只增 0.5-0.7%, 付费用户选质量不选价格。
  • Ramp (企业支出平台) 8 月: 平均词元价 0.68 美元 / 百万, 3 月 1.15, 客户在换便宜模型 (TechCrunch 09-09)。
  • 小结: 本地能接走的词元约占三到六成 (估), 对应收入不到 5% (估)。词元数和钱数是两回事。

NET

净影响 0 到小正, 不改 WATCH 与加仓价。分渠道: (a) Workers AI / AI Gateway 负 (卖的正是本地免费跑的模型, 估 < 2% 收入, 影响 < 0.5%); (b) 本地 agent 照样上网取数、调工具, 机器人管理需求升, 正; (c) 零信任 / 防外泄约 0 (看不到本地提示词, 但 agent 调内网要权限); (d) 模型权重分发收入约 0 (10-17 实测 Ollama 模型文件走 Cloudflare R2, Hugging Face 走 AWS); (e) 买方碎成百万个个人 agent, 更需要统一收费口, 正, 但美元时点不变。三档: 已证实 = Workers AI 那一档被挤压; 可疑 = 本地 agent 增加边缘需求; 不支持 = 本地化绕开 NET。详见 NET 综合报告第 0g 节。

上市叙事: 截至 10-17 EDGAR 全文检索无 Anthropic 公开 S-1; 报道称最早 11-09 当周路演, 估值讨论 1.8-2 万亿美元 (彭博, 可疑)。RTX Spark 开售当天英伟达只跌 1.43%, 且是大盘日, 市场没有把本地化当成对云的威胁。路演里 "开放权重 + 本地化让模型变便宜" 会是空方标准问题, 两家的数字能答: 收入在企业与编程, 低档已主动降价。更大的上市风险是增速 (Q3 环比 +45% 被报道为放缓) 和估值, 不是本地化。叙事冲击 (同 2025-01 DeepSeek 一日让英伟达 -17%) 不改收入结构, 概率低 (估 < 10%)。

三档判断:

  • 已证实: 本地化接走的是最便宜那一档词元; 开放权重词元多、收入少; 两家已把小模型价降到 0.10 / 0.50 美元守量。
  • 可疑: OpenAI 比 Anthropic 更暴露 (消费订阅 + 系统入口), 量级估 < 5-8% 收入, 时间 2-3 年; 上市窗口的叙事风险。
  • 不支持: 2026-2027 本地化实质压低两家收入或上市估值; "推理搬本地 -> 云 GPU 需求下降"。

对算力出租 / 信用层的含义

  • 本地吃的是旧显卡上跑开放权重模型的长尾词元, 不是前沿训练与前沿推理; 首年 500-1,000 万台按每天 15-60 分钟生成, 约每月 65-520 万亿词元 (估), 按词元数可比 OpenRouter 全站 (约每月 100 万亿, 2026-05, 可疑), 按云端小模型价只值每年约 1-8 亿美元 (估), 不改云 GPU 需求。
  • 受压的是 H100 一类旧卡的长尾出租价, 正好是 GPU 抵押贷款的抵押品价值来源 (新云 = 专门出租 GPU 的云公司, 其前三大客户是前沿实验室与超大厂, 不在本地化射程内): 方向负, 量级小; 信用层风险仍由融资 (OpenAI 过桥轮、高收益利差) 决定, 盯 H100 租价指数。
