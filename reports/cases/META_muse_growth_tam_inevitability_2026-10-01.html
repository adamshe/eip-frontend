2. 自述的变化轨迹 (2024 -> 2025 -> 2026)

三条口径都变了, 变的方向一致: 从 "生态战" 变成 "入口战"。

开源 -> 闭源 (保留开源口头权): 2024-07 "卖模型访问权不是商业模式"; 2025-07 "对开源什么要谨慎"; 2026-04 Muse Spark 闭源, 只承诺旧 Llama 继续开源; 2026-07 "会回到部分开源, 不教条"。机制: 2024 的开源是把模型当 Android 用, 让别人替 Meta 压低对手 (OpenAI / Google) 的模型租金; 2025-04 Llama 4 落后后, Zuckerberg 判断 "前沿 AI 不会永远经 API 开放", 自研前沿模型从可选变成生存条件, 开源成为成本 (他自己说开源模型 "要更全面, 多费工")。

AI 助手 -> 个人超级智能 / agent: 2025-04 还在数 Meta AI 月活 (近 10 亿); 2025-07 改写为 "personal superintelligence"; 2026-04 把它拆成 "个人 agent + 业务 agent" 两个产品; 2026-09 Connect 把 Muse 立为 "centerpiece"。机制: 助手是功能, agent 是入口; 入口才有抽成权 (Connect 原话: 免费 token, 靠交易小额抽成)。

不急着货币化 -> 多线货币化: 2026-01 "未来两年广告仍是最主要引擎", 2026-04 "先规模后变现", 到 2026-07 一次性列出订阅 (Meta One) / API (Muse Spark 1.1) / 按效果付费的业务 agent / 直接卖算力 / 对算力跑拍卖。机制上这不是产品成熟, 是资产负债表: Q2 FCF 从 $85.5 亿掉到 $7.84 亿, 债务 $837 亿, 回购为零, capex $1300-1450 亿约等于经营现金流 (8-K T1)。收入线必须在 capex 高峰期间被讲出来, 否则资本成本上行。Q2 口径里 "卖算力" 与 "卖智能毛利更高" 并列, 就是给市场看 "算力有 bid, 投错了也能退"。

对手行为交叉验证 (看行为不看声明): (a) OpenAI 2026-01 在免费版上线广告, 2026-08 广告 run-rate $10 亿 (Wikipedia T3) -- 对手走向 Meta 的模式, 等于承认 "免费 + 广告" 是消费 AI 的终态, 这反向确认 Zuckerberg 2025-04 的判断, 也说明 Meta 的广告系统是对手要补的课, 不是 Meta 要补的课。(b) OpenAI 的 Jony Ive 设备推迟到 2027-02 后 (MacRumors T2, 2026-02-10) -- Meta 眼镜的无对手窗口至少多一年。(c) Apple 选 Gemini 给 Siri 供能 (Wikipedia T3), Google 把 Gemini Intelligence 塞进 Android (Google 博客标题, 正文未取得) -- OS 级默认助手两家分完, Meta 无 OS, 这是 Muse Charm 的存在理由 (自带壳), 也是 Muse "app 级入口" 的结构弱点。(d) Amazon 2026-09-21 封 Muse 代购 (09-25 vet 引 GeekWire, 本次 403) -- 商家图持有者把 Muse 当买方, 说明 agent 商务抽成必须经别人的图。(e) ChatGPT 2026-02 周活 9 亿 (T3) 对 Meta AI "日交互 +60%" 无绝对数披露 -- 注意力层的入口之争 Meta 未赢, 这一条是口径变化的真正驱动: 不是 Meta 想当 agent 公司, 是不当就被相邻层抽走。

4. 成功必然性的哲学定性 (必然性优先)

4.1 立场: 机制上不管谁执行都会发生的部分

  1. 分发是物理的: 3.60B DAP, Muse 上线 12 天 280 万装机, 95% 用户同时是 FB 用户, 内部广告位占推广主力 (TechCrunch T2)。任何 Meta 做出来的 agent, 获客成本近零; 对手要买这个分发得花真钱 (OpenAI 2026 广告预算进入 Meta 平台本身就是证据链的一环)。
  2. 广告的 ROI 回路不需要 Muse 成功: 算力 -> 更大的 GEM / Generative Recommender -> 转化率升 -> 广告主出价升 (单价 +12%) -> 现金 -> 算力。CFO 原话 "numerous ROI positive places that we would put compute toward if we had it"。这条回路是拍卖机制, 不是叙事; 只要广告主的边际 ROAS 为正, 它自己转。
  3. 现金自给: Q2 经营现金流 $319 亿 对 capex $311 亿, 债 $837 亿, BlackRock JV 分担土地与电。不需要增发。这决定了 "跌了会回" 的机制只是暂时关闭 (回购为零), 不是失效。
  4. 创始人与年龄: 42 岁, 投票权 60.8% (DEF 14A T1), 亲写 MSL 备忘录, 亲自在 Connect 发布, "My personal bet" 是第一人称。天选之子窗口 (35-60) 还剩 18 年, 掌舵权硬到可以连续两年压零回购而不被董事会动。
  5. 数据闭环的对象是人不是文本: agent 的价值 = 它能看见的上下文 (Zuckerberg 2026-01 原话); Meta 持有的是关系与消费行为的图, 这是 OpenAI / Google 拿不到的输入。

边界 (按原则不断言的): 不断言 Muse 成为唯一入口 (N2=0); 不断言 2028 幅度; 不断言眼镜替代手机的日期。

4.8 结论 (三档)

分层给: (1) "AI 投入把广告收入在 2028 前抬到 $3000 亿以上并保持经营利润增长" = 必然 (机制: 拍卖 + 分发 + 现金自给, 无反作用力可阻止; 边界: 不断言利润率水平)。(2) "Muse 成为数十亿人的个人 agent 默认入口之一" = 大概率 (0.6; 分发与关系图给的, 执行给 PMF; 反例: Facebook Phone / Portal / Humane 五连败说明没有 OS 的入口是别人的外设)。(3) "Muse 成为唯一或主导入口, 支撑 2028 年 $1400" = 偶然 (0.2; N2=0, OS 层已关)。整体标签: 大概率。

可证伪条件 (硬数字 + 日期): 2026-10-29 Q3: 广告收入增速 <20% 或 DAP <3.60B -> (1) 降为大概率; Muse 停自家推广后 30 日留存 <20% (Sensor Tower, 2026-11 前) -> (2) 降为偶然; 2027-01 Q4 电话会: 2027 capex 指引 >$2000 亿且 FCF 连续两季 <$50 亿、回购仍零 -> 现金自给前提破, 整体降一档; Meta AI 月活到 2027-01 仍不披露或 <10 亿 -> (2) 降; iOS / Android 一次系统级限制 Muse 后台或 BLE -> (2)(3) 同降。
