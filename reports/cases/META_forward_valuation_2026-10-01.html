9. 结论与 kill 条件

  • 判断: 交叉格 = 结构 long 候选 (Yoneda 4/5, 必然性 3/4, 沿用 2026-09-25 vet), 但本文的五年现金流把它压成 "条件型": 终态位置成立的前提是 capex 在 2027-28 封顶后 FCF 回归; 不封顶 (A 路径) 则五年里股东拿到的是 EPS 1.6x 而每股 FCF 到 2029 才回到 FY25 的一半, 租金全部转付给算力 / 电力 / 房东。五年每股 FCF (FY25 $17.91 基准): FY30 A $21.1 (1.18x) / B $10.8 (0.60x) / C $13.1 (0.73x) / A' $36.1 (2.0x); 三年 FY26 -> FY29: A -2.2 -> 9.5 / B -2.5 -> 4.5 / C -3.5 -> 9.1 / A' -2.2 -> 22.0 (基数为负报绝对值)。现价对应 IRR: 到 2028-12 A +11.8% / B -8.0% / C -31%; 到 2030-12 A +10.5% / B -6.3% / C -24%; 概率加权 (A 30 / B 50 / C 20, 估) 到 2028-12 约 -7%, 期望为负; 但与 LITE / GEV 不同, A 的 IRR 为正且 A' 到 2030 有 +12%, 这是三家里唯一 "自述全兑现就能赚钱" 的, 风险在 capex 纪律而不在需求。
  • 风险结构: 上行要两条 -- 广告单价 2027-28 维持 +8% 且 capex 2027 封顶 (两条都要对, A'); 下行只要一条 -- 单价增速掉到 +5% 以下 (agent / EU / TikTok 任一) 或 2027 capex >= $190B 而收入增速 < 15%。与 GEV / LITE 的差别: LITE 风险在 FY28 EPS (供给翻倍), GEV 在倍数, META 在现金 (EPS 可以涨, FCF 可以不涨)。
  • 接货位: 鲸鱼接货位 636-682 (两包风险逆转的 put 行权价减净权利金) 对照 Fair Value A $478 (B 20x 折现) 与 B 25x 折现 $598: 636-682 在 Fair Value A 之上 33-43%, 是 "A 与 B 之间" 的价格, 等于鲸鱼也在押 A/B 之间而不押 B; 房东法 ITM put 位建议 $600-640 (2025-07 以来箱体底 600 + 2026-04 洗盘低 560-593 之上, 与鲸鱼下沿重合), 在那里每股 FCF 2030 A' $36 对应 17x, B $10.8 对应 56x -- 只有相信 capex 会封顶才买。勇者窗口: 10-28 财报若 2027 capex 指引 <= $175B 且单价 >= +10%, 价在 700 以下 = A' 概率翻倍, 那是买点; 若指引 >= $200B 即便收入超, 也不追。
  • Kill (推翻本文 "不开新多" 倾向, 转 "拿着 / 买"): 10-28 Q3 收入 >= $64B 且 Q4 指引 >= $75B 且单价 >= +10%, 加 2027 capex 指引 <= $175B 或明说 "capex 增速显著放缓", 加 Q3 D&A <= $7.0B (爬坡不快于模型), 加回购恢复 (任一季 > $5B)。四中三 = A' 成立, 2030-12 IRR +12%。
  • Kill (B 转 C): 单价 y/y < +8% 连续两季; 展示量 < +8%; 2027 capex 指引 >= $200B 且收入指引增速 < 18%; 欧洲收入增速比全球低 > 5 点; SBC / 收入 > 12%。
  • 工具接口: Fair Value A $478, SPR +52%; D2 建议 "结构 long 条件型", 对账表 FY28 共识无数据、regime 5 条, D2 不取上限; 取证触发: FCF / 净利 < 0.1 (2026-28) 进现金硬红旗候选, 不进尺。
