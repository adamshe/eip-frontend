9. 结论与 kill 条件

  • 判断: 交叉格 = 收租 (Yoneda 4 / 5, 必然性 2 / 4; yaml ceiling_class platform, D1 terminal 减 4); 服务年金 (递延 $14.9B, 付费账户创新高, Google 总盘子 +10%) 是收租底, iPhone 是周期顶; 按 PE / PEG 与周期定价, 不付终态溢价。现价已付清 A 情景 (FY28 收入 $570B, OM 34.5%) 按 29x; 三情景 IRR 到 FY28 末 A +2.1% / B -13% / C -34%, 到 FY30 末 A +4.8% / B -5.5% / C -19%, 期望为负。裁判尺 (FY26 -> FY29 每股 FCF): A +45% / B +21% / C -9%; 五年 (FY26 -> FY30) A +61% / B +29% / C -5%; 本体三年长 20% 上下, 价格付的是 45%。空头非主张: FCF $134B/年 + $138B 回购授权托底, 做空是与 "法律线何时落地" 对赌时点, IV 24%。
  • 风险结构: 上行要 FY28 EPS >= $14.6 且 PE 维持 30x (= A 情景再加 27%, 即服务 +15% 与 iPhone 台数 +5% 同时发生三年); 下行只要 FY27 产品 GM -2 pt (存储) 或任一法律线落地 (SCOTUS 佣金 / D.C. Circuit 付费默认), 倍数先压缩。与 GEV 的差别: GEV 的 EPS 被 backlog 锁定, AAPL 的 FY27 EPS 本身就有 -8% 的下行路径 (C), 风险在 EPS 与倍数两头。
  • 勇者窗口: 不在做多现价。(a) 接货位 $245-295: 上沿 = 鲸鱼 2027-12 P320 托底的有效接货价 $293 (50 日线 $322 的 -9%), 下沿 = B 情景 25x FY28 零折现 $249, 再下是 Fair Value A $206 (买房线); (b) 持有者跟鲸鱼同向: 卖 2028-01 $350 call (IV 33%) 收租, 或 2027-12 $320 put 收 8.4% 权利金; (c) 10-29 财报若 12 月季 GM 指引 < 47.5% 引发 -8% 至 $305, 仍不急, 等 $295 下。
