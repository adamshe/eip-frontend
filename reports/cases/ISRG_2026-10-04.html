锁定程度、利润质量与是否错价

四个问题: 锁定程度、增长是否由结构决定、利润是否干净、是否错价。逐条:

(1) 锁定程度: 只锁一半。 锁死的一半: 已装机医院换平台 = 全科室重训 + 重做 credential, 耗材芯片计数 + 服务独家 = ISRG 有定价权。没锁死的一半: 手术本身不必经过它 (腹腔镜 / 开放可行); 新放置没锁 (中国招标国产 63%, T3)。真值: 装机内锁死 已证实 (T1 10-K, 经常性 85%)。

(2) 结构性增长: 写得出三条机制, 但终态与替代路径都没锁死。

  • 机制 1, 装机内收费: 器械内有计数芯片, 用到次数器械停止工作, 医院只能再买; 每台手术耗材收入 $900-3,700 (10-K 原话), 2025 耗材 $6,018.9M = 收入 60%, 另收服务年费 $95-225K。证据 T1 (10-K item_1 / item_7)。真值 已证实; 漏洞在法律层: 再制造耗材 510(k) 已获, 反垄断集体诉讼 (2025-03 集体认证, 2027-09-14 开庭) 攻的正是次数锁, 败诉先验 25% (估)。
  • 机制 2, 装机量自增: 装机只增不减 (11,106 -> 11,710, +12%) x 每台利用率年增约 3% = 手术量构造上限约 +15%; 新放置 54% 走经营租赁, Q2 131 台按用量付租 = 医院按手术付费, 增量手术自动带耗材与服务。证据 T1 (10-Q item_2)。真值 已证实 (方向); 速度在降 (18% -> 15% -> 14.5%)。
  • 机制 3, 份额切换 (需求侧): 美国总手术量在降 (HCA Q2 住院 -2.3%、门诊 -4.4%) 而 da Vinci 美国 +12%; 对手 MDT 10-K 自述吻合器下滑因 "shifts to robotic surgery"。证据 T1 (客户与对手方 filing)。真值: 方向 已证实; 五年延续 可疑 -- 公司自述胆囊 / 阑尾已高度腹腔镜化、疝 "a large portion ... different modalities", 美国渗透 35-45% 只是 T3 估。
  • 没锁死的两条: 终态不唯一 -- 软组织手术终态是机器人、腹腔镜、开放并存; 替代路径没关死 -- Hugo 泌尿 FDA (2025-12)、Ottava De Novo (2026-07-22)、中国国产 63%。

(3) 利润是否干净: 干净, 已证实。 GAAP / non-GAAP 折算 0.85 (FY25 $7.87 / $8.93 = 0.88, H1 2026 $4.57 / $5.31 = 0.86), 差额主体是 SBC $788M = 收入 7.8%。会计质量检查 (as-of 2026-10-02, 数据到 FY2025 10-K): 无红旗, 18 项检查全部通过, Beneish M -2.917, Sloan 应计 -0.9% (现金高于利润), CFO / 净利 1.061, 首报与最新无重述, 现金可信度检查通过。零负债, 无客户预付押金, 三份原报告未见自我交易结构。两处口径注 (不是红旗): 2025 FCF 跳升来自 capex 从 $1.1B 降到 $0.54B (厂房周期过峰); 2025 GAAP 税率被超额税收优惠压低 7.4 点 ($246M), 现价低于 RSU 归属均价 $412, 这部分优惠归零, GAAP 税率回到 20-21%。

(4) 是否错价: 比自己的历史便宜, 但不是市场错价。 便宜的部分: non-GAAP PE 36.4x = 自身第 17 百分位, GAAP 42.8x = 第 14; 现价低于自身第 20 百分位对应价 $415.64; 历史中位对应价 $535.16。不支持错价的部分: 按情景反推, 现价落在 B 情景 FY28 28x 零折现 $406 附近, 15% IRR 要 A 情景 (FY28 末 $537), 成熟期合理价 $282-316 (估)。两种算法相差近一倍, 原因是: 历史百分位隐含 2021-25 的倍数体制 (trailing 57-72x, 手术增速 15-18%), 反推用 FY28 EPS 和与 10-12% 增速相称的退出倍数; 增速换挡是 T1 事实, 所以历史百分位高估。同业前瞻 PE 12.7-25.2x, ISRG 仍是同业 2-2.5 倍。抄底信号未出现。真值: "便宜于自己的历史" 已证实; "市场错价" 不支持 -- 这是看见增速换挡后的重估。

判定。 ISRG 的定价权只在已装机之内, 不在手术必经的一跳上; 绕开它的路 (腹腔镜 / 开放 / 对手平台) 医院今天就能走。一句话: ISRG 是 "装机内的干净收费商", 不是 "所有手术必经的一跳"; 现价也只付清中性情景, 不值得下大注。真值: "不是所有手术必经" 已证实 (T1: 10-K 自述替代术式 + 对手获批)。

它是什么: 软组织机器人子域的硬件收费商

先排除: 不是平台 (da Vinci 封闭, 无第三方器械 / app); 不是网络 (星形: 医院之间不经 ISRG 互连, 没有网络迁移成本); 不是全部手术的必经 (腹腔镜 / 开放可行); 不是周期股 (经常性 84-85%, 装机只增不减); 不是创始人掌舵 (职业 CEO Rosa, 持股约 0.07%, 薪酬盯营业利润率与手术量)。剩下 = 剃刀刀片结构的子域收费商: 收入 = 手术数 x 每台耗材 + 装机 x 服务年费 + 放置 x 单价。空方 "被替代" 建立在 "全部手术必经" 这个已被排除的定位上 (它本来就不是), 真正的攻击面是每台耗材价格; 多方 "终态平台" 建立在 "平台" 这个已被排除的定位上。

估值: 现价付了多少

现价 $391.95 比估值报告用的 $401.24 (10-01) 低 2.3%; 倍数 FY26 36.4x / FY27 32.4x / TTM 非 GAAP 38.3x / B 情景 FY28 27.0x。市场已付: "手术 +12% 五年 + 利润率扩约 2 点 + 倍数 28x" (B); 没付: A (利润率再扩 5 点 + 倍数回 35x); 对 C (美国耗材压价 + 中国扩散) 零折价。按 $391.95 重算 (估): FY28 末 A +17.1% / B +1.6% / C -21.1%; FY30 末 A +15.8% / B +5.3% / C -11.7%; 15% IRR 需 FY28 末 $537 或 FY30 末 $710。风险结构不对称: 上行要三条同时对 (手术 >= 13% 到 2030、利润率再扩 5 点、倍数回 35x), 下行只要一条 (美国耗材压价 或 美国总量 regime)。与 GEV 的差别: GEV 的 2028 EPS 被积压锁定, 风险在倍数; ISRG 的 EPS 是构造自增, 风险在 "每台手术价格" 这条公司自述永远不含的杠杆。每股 FCF FY26 -> FY29 (估): A 1.67x / B 1.47x / C 1.19x; B 情景生意三年 +47% 是合格的增长, 错的是价格: 倍数从 33x 向 28x 压缩吃掉一半。FCF 口径注: 用量租赁把现金回收摊到 7 年, 装机越快 FCF 越被压。远月 call 墙 (2028-01 $520-530, 2028-12 $750) 隐含的 EPS 高于 A 情景, 更像 buy-write 卖方认为到不了。

多空双方的证据

多方最强版本。 (1) 85% 经常性 + 装机按构造自增, FY26 共识 EPS +20.7%, 公司年内两次上调毛利指引; (2) 估值在自身第 17 百分位, 管理层 H1 用 $1.51B 在均价 $475.67 回购, 现价低 17.6%; (3) 卖方均价目标 $476 (29 位, $324-685), 32 位里 24 位买入。空方最强版本 (C): 耗材价格被对手报价、再制造、诉讼三面攻; 美国总手术量在降; 换机峰 2027-28 后系统收入掉到个位数增速。

双方各自的漏洞。 多方 -- 事实成立 (T1); 逻辑断两处: 时间倒置 (Ottava 之后 "仍上调" 不成立) 与偷换锚 (历史百分位 = 旧增速体制); 忽略的事实是多方自己的数据: 公司自述胆囊 / 阑尾天花板、10-K 不给多年目标、PSU 盯营业利润率与手术量不盯 EPS / FCF; 情绪不极端 (Stocktwits 关注 21,783, Reddit 前 300 榜外, 目标价离散 2.1x, 空头 2.31%, OI P/C 0.83), 无反向信号; 耐心维度多方对 (2026-27 兑现), 但价格已付 B。同样检验本文 -- 事实: B 情景是估、FY28 共识缺; 逻辑: 折现 11.8% 用 beta 1.465, 按 9.5% 折现 PV 上浮 5-9%, B 的 IRR 仍低于 9.5%, 结论不翻; 忽略: 10-20 若手术 >= 15% 且指引上修, A 的概率升; 耐心: 接货位可能不出现, WATCH 只有机会成本。

判断。 两边依据都站住 (多方: 2026-27 业务, T1; 本文: 价格已付 B, 算术), 兑现时间不同 -> 争议票, 看时间先后。

时间先后。 多方先兑现: 10-20 与 2027-01 的业务数据大概率不差 (Q3 超预期先验 55%, 估), 但价格已付, 近端不做短线做多, 而是持有者卖远月 call。空方后兑现: 2027-28 Hugo / Ottava 美国普外落地、I&A 每台实收转负、换机峰后系统收入减速、2027-09 诉讼开庭; 远端 = 观察区卖 put、长期买入区买正股。切换由 checkpoint 触发: 价进入观察区且 B 转 C 未触发 -> 接; 已触发 -> 不接, 按 C 重算。近端卖 call 与远端卖 put 方向相反, 不算对冲。
