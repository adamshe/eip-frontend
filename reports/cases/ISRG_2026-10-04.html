分析

终局总结

本报告是估值合并, 不是事件复盘; 九问主语改为 "从 $592.85 跌到 $332.02 再回到 $391.95: 跌的是什么, 现价付了多少"。

  1. 为什么跌: 两段, 跌的是倍数不是盈利。(a) 2026-01-06 收盘高点 $592.85 -> 06-30 $397.68 (-32.9%): 同期公司 04-21 把手术指引从 13-15% 上调到 13.5-15.5%, H1 非 GAAP EPS $5.31 对去年 $4.00 (+33%); 同窗发生的是 Hugo 美国首例 (02-17)、中国 H1 招标国产 63% (T3)、美国减重手术下降; 无一手原话, 不归因。(b) 07-14 -6.8% (原因未取); 07-16 Q2 财报后 07-17 -14.2% (量 11.56M 股, 约 07-10 / 07-13 日量的 6 倍); 07-23 收 $332.02, 是 J&J Ottava De Novo (07-22) 的次日。Q2 公司原话: 美国手术 +12% (去年同季 +14%), 归因减重 "high-single-digit decline" 与 "expiration of enhanced ACA premium subsidies"; 手术区间不再上调, 只说 "closer to the midpoint"。谁在卖: Q2 13F 主动长线减 (T. Rowe -10.1%, Capital World -3.8%), 被动承接; 内部人零买, 只有 10b5-1 小额卖。真值: 价量与原话 已证实; "增速换挡 + 对手获批 -> 倍数下移" 的因果 可疑 (推断)。
  2. 为什么止跌、为什么涨: 07-23 $332.02 -> 09-28 $414.79 (+24.9%), 10-02 回到 $391.95; 机制无一手证据, 不归因。可见的锚: 公司 H1 回购均价 $475.67、Q2 $438.68 (现价低 17.6% / 10.7%), 剩授权 $4.7B; 日本 7 个术式报销 6 月生效。
  3. 必然性: 锁死的两件 -- 已装机每台手术必须买芯片计数限用耗材并付服务年费 (经常性 84-85%); 装机只增不减、利用率年增约 3%, 手术量按构造自增。需求侧方向 -- 美国总手术量在降 (HCA 住院 -2.3% / 门诊 -4.4%) 而 da Vinci 美国 +12%, 份额切换在发生。没锁死 -- 手术本身可走腹腔镜 / 开放, 新装机可选 Hugo / Ottava / 国产, 收费线本身被再制造 510(k) 与反垄断诉讼攻击。N = 2/4, 逐条见下节。
  4. 基本面变了什么: 真变化 -- 手术增速 18% (2025) -> 15% (H1 2026) -> 指引中值 14.5%, 美国单季 12%; 两家对手在美国获批; 中国一地已丢。没变 -- H1 收入 +20.7%, 非 GAAP 毛利指引两次上调到 68-69%, dV5 放置 +37%, 装机 +12%。重估 -- 12 月 trailing PE 2025 63x -> FY26 前瞻 36.4x; 价格离高 -34% 而 FY26 共识 EPS +20.7%: 跌的几乎全是倍数。
  5. 空方 (C 情景) 对在哪、错在哪: 对 -- 增速换挡是基数必然; 美国增长全靠份额切换, 份额有上限; 每台耗材实收是公司自述永远不含年降的杠杆, 对手报价、再制造、诉讼都在压它; C 情景按现价 FY28 末 -21.1%。错 -- 对手方 filing 里没有 Hugo / Ottava 的单位数 (MDT 10-Q 只列 "增长来源之一", JNJ 10-Q 零字) = 2026 尚无规模; 美国外 +20%、日本支付端加码; 押下一季则耐心不在空方 (10-20 超预期先验 55%, 估)。
  6. 多方对在哪、错在哪: 对 -- 机制链 T1 成立, 零负债、现金与投资 $8.63B, 取证卡 18 项全绿, 管理层回购均价高于现价。错 -- (a) 把子域房东当成全部手术的必经 (Yoneda 强制通行不过); (b) 时间倒置: vet 与打分写 "Ottava De Novo 07-22 后 Q2 手术指引仍上调", 但 Q2 财报 07-16 在 Ottava 之前, 且 7 月版手术区间未再上调 -- Ottava 拿不拿得走手术目前零观测, 10-20 是第一季; (c) 拿自身历史百分位当锚, 而 2021-25 的 57-72x 对应 15-18% 的手术增速。
  7. 到底谁对: 2026-27 业务层多方对 (已证实, T1 指引与 Q2); 价格层中性: 现价付清 B、没付 A、对 C 零折价 (已证实, 倒算算术); 2028 以后耗材实收转负与对手美国落地 可疑 (先验 50% / 35%, 估)。打分 "买房" 与估值 "现价不是接货位" 不冲突: 前者答什么车, 后者答什么价; 以打分定类别, 以倒算定价位。
  8. 是不是设局震仓: "有人设局" 不支持 -- 无 13D、2026 无新 13G、内部人零买、空头 2.31%、期权流无逆势大注。"事件引发弱手出清 + 价值资金接盘" 可疑 -- 07-17 的量是出清形态, 但可见的价值买家只有公司回购 (Q3 金额 10-20 后 10-Q 才知), 7-9 月谁接要等 Q3 13F (11 月中)。
  9. 动作规则: 现在 WATCH。10-20 后价进入 $350-385 且 B 转 C 无一触发 -> 房东卖 put 起步 (SMALL, 同因子权利金 <= 2%) -> B 转 C 任一条触发即停; 价进入 $282-316 且装机 / 利用率未断 -> 正股分批 (MID, 波 2 加仓) -> 诉讼改判先重答本体门; 升档三条全中 -> 现价 SMALL 建仓 -> 任一不中回 WATCH。可迁移的规则: 增速换挡的装机房东跌到自身低百分位时, 接货价用倒算 (未来 EPS x 与新增速相称的倍数), 不用历史百分位。

ISRG 是不是第二个 clean alpha

定义未定 (Adam 2026-10-04 暂缓)。候选口径两种: 选项 A 四条同时满足 -- 位置被锁死 (位置分 >= 24/30)、必然性 >= 3 条逐条机制、干净 (GAAP / non-GAAP >= 0.8 + 取证无红旗 + 无自我交易结构)、错价 (估值 <= 自身第 30 百分位或浪 2 门打开); 选项 C 只认 NET 同型 (必经且能拒绝的那一跳上收费)。逐条:

(1) 位置是否被锁死: 机械分过, 实质只锁一半。 位置分 27/30 (引擎 v2.3 10-01, 系统读数 10-02 已核), 过 24 线。锁死的一半: 已装机医院换平台 = 全科室重训 + 重做 credential, 耗材芯片计数 + 服务独家 = 拒绝权 (Yoneda 第 2 条过)。没锁死的一半: 手术强制通行不过 (Yoneda 第 1 条, 腹腔镜 / 开放可行); 新放置没锁 (中国招标国产 63%, T3)。引擎自注 "前提 N >= 3 未核" -- 27 分站在一个未核前提上。真值: 装机内锁死 已证实 (T1 10-K, 经常性 85%); 位置分 27 的前提 可疑 (估值报告逐条给 N = 2, 与前提冲突)。

(2) 必然性逐条 (机制级): 写得出三条, 只占 N1-N4 的两格。

  • 必然 1, 装机内收费 (N3 关系层不可绕过): 器械内有计数芯片, 用到次数器械停止工作, 医院只能再买; 每台手术耗材收入 $900-3,700 (10-K 原话), 2025 耗材 $6,018.9M = 收入 60%, 另收服务年费 $95-225K。证据 T1 (10-K item_1 / item_7)。真值 已证实; 漏洞在法律层: 再制造耗材 510(k) 已获, 反垄断集体诉讼 (2025-03 集体认证, 2027-09-14 开庭) 攻的正是次数锁, 败诉先验 25% (估)。
  • 必然 2, 按构造自增 (N4 时间箭头): 装机只增不减 (11,106 -> 11,710, +12%) x 每台利用率年增约 3% = 手术量构造上限约 +15%; 新放置 54% 走经营租赁, Q2 131 台按用量付租 = 医院按手术付费, 增量手术自动带耗材与服务。证据 T1 (10-Q item_2)。真值 已证实 (方向); 速度在降 (18% -> 15% -> 14.5%)。
  • 必然 3, 份额切换 (需求侧时间箭头, 也落 N4): 美国总手术量在降 (HCA Q2 住院 -2.3%、门诊 -4.4%) 而 da Vinci 美国 +12%; 对手 MDT 10-K 自述吻合器下滑因 "shifts to robotic surgery"。证据 T1 (客户与对手方 filing)。真值: 方向 已证实; 五年延续 可疑 -- 公司自述胆囊 / 阑尾已高度腹腔镜化、疝 "a large portion ... different modalities", 美国渗透 35-45% 只是 T3 估。
  • 写不出的两条: N1 终态唯一 -- 软组织手术终态是机器人、腹腔镜、开放并存, 写不出; N2 替代路径关死 -- Hugo 泌尿 FDA (2025-12)、Ottava De Novo (2026-07-22)、中国国产 63%, 写不出。按 N1-N4 计 2/4 (与估值报告一致); 按机制条数计 3 条。

(3) 利润是否干净: 干净, 已证实。 GAAP / non-GAAP 折算 0.85 (系统读数; FY25 $7.87 / $8.93 = 0.88, H1 2026 $4.57 / $5.31 = 0.86), 差额主体是 SBC $788M = 收入 7.8%。会计取证卡 (系统输出, as_of 2026-10-02, 数据到 FY2025 10-K): 绿, 红 0 / 黄 0 / 绿 18, Beneish M -2.917, Sloan 应计 -0.9% (现金高于利润), CFO / 净利 1.061, 首报与最新无重述, 现金可信度六锚绿。零负债, 无客户预付押金, 三份原报告未见自我交易结构。两处口径注 (不是红旗): 2025 FCF 跳升来自 capex 从 $1.1B 降到 $0.54B (厂房周期过峰); 2025 GAAP 税率被超额税收优惠压低 7.4 点 ($246M), 现价低于 RSU 归属均价 $412, 这部分优惠归零, GAAP 税率回到 20-21%。

(4) 是否错价: 机械判据过, 实质不支持。 过的部分: non-GAAP PE 36.4x = 自身第 17 百分位, GAAP 42.8x = 第 14; 现价 < 估值门价 $415.64 (自身第 20 百分位); 历史中位合理价 $535.16。不支持的部分: 倒算说现价落在 B 情景 FY28 28x 零折现 $406 附近, 15% IRR 要 A 情景 (FY28 末 $537), Fair Value A $282-316。两把尺相差近一倍, 机制是: 历史百分位隐含 2021-25 的倍数体制 (trailing 57-72x, 手术增速 15-18%), 倒算用 FY28 EPS 和与 10-12% 增速相称的退出倍数; 增速换挡是 T1 事实, 所以历史尺高估。同业前瞻 PE 12.7-25.2x, ISRG 仍是同业 2-2.5 倍。浪 2 门未开。真值: "便宜于自己的历史" 已证实; "市场错价" 不支持 -- 这是看见增速换挡后的重估。

判定。 选项 A: 贴线 -- 位置、干净、错价三条机械过, 必然性按机制条数过、按 N 格数不过; 但错价一条的实质 (倒算) 不成立。选项 C: 不过 -- ISRG 的拒绝权只在已装机之内, 不在手术必经的一跳上; 绕开它的路 (腹腔镜 / 开放 / 对手平台) 医院今天就能走。一句话: ISRG 是 "装机内的干净房东", 不是 "必经一跳的 clean alpha"; 就算口径放宽到按机制条数, 现价也只付清中性, 不配 clean alpha 的大注。真值: "不是 NET 同型" 已证实 (T1: 10-K 自述替代术式 + 对手获批); "按选项 A 贴线" 可疑 (取决于计数口径)。

本体: 软组织机器人子域的硬件房东
