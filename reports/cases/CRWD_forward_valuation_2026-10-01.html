  • 盈利增幅 (每股完全稀释 FCF): 五年 FY26A -> FY31 A 3.21x / B 2.61x / C 1.84x; 三年 FY27 -> FY30 (裁判尺) A 2.07x / B 1.78x / C 1.34x (FY26A -> FY29 A 2.17x / B 1.94x / C 1.51x)。三情景都在长, 但 SBC 占 FCF 约 9 成, 尺偏宽。
  • 现价对应 IRR: PE 倒算全负 (FY29 末 A -14% / B -27% / C -42%; FY31 末 A -8% / B -17% / C -26%); EV/S 倒算 A 约 -1% / B -12% 至 -18% / C -22% 至 -35%; 15% IRR 需要 FY31 收入 $34-46B (B 的 3-4 倍)。
  • 风险结构: 上行要 "NNARR 每年再增 + 倍数 2028 年仍 170x 以上" 两条同时成立 (期权鲸鱼押的正是后者); 下行只要倍数回到同业 (PANW 81x) 就是 -50%, EPS 不必错。与 NET 同型 (风险全在倍数), 比 NET 多一个 DOJ / SEC 的 ARR 口径询问。
  • 勇者窗口: 不在做多现价。(a) 价值接货位 $100-125 = A 情景 60x 折现到 10% IRR ($124) 与 EV/S 口径 Fair Value A ($100) 之间, 下沿贴管理层回购线 $91.47 与 Mythos 前 2026-04 平台 $111; (b) 交易位 $200-212 = 12 月 P205 全链最大 OI + SMA50 $212-225, 只作波段不作价值; (c) 持有者: 学卖 call 鲸, 卖 2028 年 $350-420 call 收 60% IV 的租 (平衡点即鲸鱼上沿)。
  • Kill (推翻 "不追", 转 "拿着" = A 再上一档): 2026-12-01 Q3 net new ARR >= $380M 且 FY27 ARR 上调 >= $6.70B; 加 2027-03 初 FY28 指引 net new ARR 增速 >= +20% 且 non-GAAP OM >= 27%、FCF 率 >= 30%; 加 2027-05 DEF 14A 披露 FY27 四季 NRR 均 >= 117%。全中仍只把 A 的 FY31 IRR 抬到约 0%, 所以 kill 只改 "观察 -> 拿着", 不改 "不追"。
  • Kill (B 转 C): net new ARR 同比转负两季 (yaml); NRR < 110% (CIP 目标下沿); GRR < 95%; 10-Q note 11 出现 Wells notice、和解或 ARR / 收入重述; WESP GA 且 Defender 同 API (yaml); 第二次全球宕机级事故; non-GAAP 订阅毛利 < 79%; Flex ARR 增速 < 30%。
  • 工具接口: Fair Value A $76 (PE 基) / $100 (EV/S 基), SPR +250% / +166%; D2 不取上限 (regime 4 条, 公司长期目标比基准低 6-12%, 对账表 FY28 差异 < 30% 但 FY29+ 无共识); yaml fair_value_a 待 Adam 定口径。
