3. BE: 泡沫国家意志筛

判定: 受害方候选 (90% 侧), 非 survivor。依据五条:

  1. 关系层不在它手: Q2 单一客户 73% (非关联方, 即 Oracle, 估); H1 两客户 44% + 21%, 第二家是关联方 Brookfield Fund JV, H1 关联方收入 $3.761 亿而 Q2 仅 $280 万, 即 Q1 约 $3.73 亿卖给自己持股 9.9% / 15% 的 JV (10-Q/A T1, 原 10-Q 把三 / 六个月写反, 修正版确认)。
  2. 溢价靠两个临时条件: SOFC $400-500 万/MW (ITC 后 $300-350 万) vs 轮机 $200-250 万/MW; PPA $0.10/kWh vs 电网 $0.06-0.08 (T2/T3)。轮机排队解除 (GEV 交期 <24 月) 或 ITC 变动, 任一消失溢价即归零。
  3. 意向 : 合同 = 40 : 1: 公司口径 backlog 约 $200 亿 / 产品 $60 亿 (Q4 2025 call, T2); 10-Q 未满足履约义务仅产品 $4.424 亿 + 服务 $5170 万 (T1)。Oracle MSA "up to 2.8 GW", 已签 1.2 GW (PR 4/13 T1); Brookfield $50 亿 -> $250 亿是 "framework" 非约束 (PR 6/30 T1)。

6. Kill switch / 触发

INTC kill switch (律置信 45 -> 25):

  1. 2027-06-30 前 14A 仍无具名外部客户承诺 (8-K / 财报)。
  2. Mercury 任一季 ARM 服务器单位 >= 25% 或 AMD x86 服务器收入份额 > 50%。
  3. 2027-01 Q4 财报 DCAI 同比 < 15% 或 Xeon 涨价回吐。
  4. 政府 / NVDA / SoftBank 任一减持 (13D/G, Form 4) 或 escrow 条款改动。

    5. INTC 触发: (a) 14A 具名 hyperscaler / Apple 承诺 -> 天花板从硬件类 $6000 亿升平台类; (b) 回撤 <$95 增发价且陈立武再买 -> 机构成本线, 收租位 (期权深度足); (c) Foundry 季亏 <$10 亿。

BE kill switch (受害方判定坐实):

  1. Oracle 削减 / 延后已签 1.2 GW 或 Jupiter 2028 目标再推 (8-K)。
  2. 10-Q 产品履约义务连续两季 < 当季产品收入 (10/29 Q3 首查) = 意向不转合同。
  3. 48E 燃料电池条款修改或财政部指引收紧。
  4. GEV / Siemens 重型轮机交期 <24 月 或 GEV 8-K 新产能投产。

    5. BE 触发: (a) 单季非 Oracle 非关联方收入 > 50% 且 GM >= 34% -> 重过判断类型门; (b) 第二家 hyperscaler 签 >= 1 GW 具约束力合同 (非 MSA); (c) 空头进场 = kill 1 或 2 触发 + 短仓 <5% + 价在 50 日线下。
