  • 判断: 交叉格 = 平台收租 (yaml ceiling_class: platform, d1 multi_host) 叠 AI capex 周期; Yoneda 约 2.5/5, 必然性 2/4, 按 PE / PEG 与每股 FCF 定价, 不付终态溢价。五年每股 FCF (FY26 $8.99): FY31 A $15.5 / B $15.0 / C $17.3 / A' $24.6; 三年裁判尺 FY26 -> FY29 A -38% / B -3% / C +41% / A' +51%。现价 IRR: 到 FY2028 末 A +11.4% / B -4.7% / C -22.9%; 到 FY2030 末 A +10.8% / B -1.1% / C -13.8%; 概率加权约 -3.5% / -0.1%, 期望不够 10.2% 的折现率。
