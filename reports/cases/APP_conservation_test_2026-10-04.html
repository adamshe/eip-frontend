APP 钱守恒检验 x 对手原话: 增长背离从哪来 (2026-10-04)

一句话结论: 守恒检验没有找到 "无来源的钱" -- TTM 净收入增量 $2,577M 由抽成上升、电商新钱、独立渠道整体扩张 (四家不同审计师的同行同期 +19% 至 +35%)、MAX 闭环再投解释掉中值约 92%, 残差中值 +$0.2B (p10 -0.15 / p90 +0.6), 落在误差内; Meta / Alphabet 的申报与电话会、Apple 的申报里没有一句指向收入虚构, 广告主与发行商的法定申报确认真钱双向流动。所以 "报表造假" 维持不支持; Adam 看到的背离是真的, 但它指向收入质量 (价格驱动 + 循环放大 + 自营竞价与自家归因), 不是虚构收入。

价格锚: APP $268.22 (2026-10-02 收盘, Yahoo chart API, 2026-10-04 现取), 52 周 $266.84-738.01。

终局总结

  1. 增长从哪来: 量没长, 价长了。2025 安装 +3%、每安装净收入 +72%; 1H26 安装 -10%、每安装净收入 +75% (10-K / 10-Q, T1)。多收的钱来自四处: 每个安装卖得更贵 (高价值用户 + 价值竞价)、抽成上升 4-11%、电商新广告主、发行商把从 MAX 拿到的分成再投回 APP。"手游内购 -2%" 不是买量总盘: 同期 Meta 游戏垂类 "strong" (2025Q3)、AdMob 连续增长 (Alphabet 10-Q)、Unity / Liftoff / Mintegral / DT 全部两位数增长, 唯一 "没长" 的是两个第三方估算 (Sensor Tower 商店内购、AppsFlyer 成本数据), 而 Playtika 站外直充已占收入 39.3% -- 商店口径正在系统性漏计。
  2. 必然性: 锁死的 = 现金已收 (税、回购、审计, 前一份报告)、对手方申报里的真实付款、安装量随大盘 (量没编)。可被切断的 = 抽成 (Unity Vector 战略 Grow Q3 指引 +68-70%)、MAX 位置 (Unity 律师函指其 "well over a majority ... share of wallet" 与自我优待)、归因 (APP 自有 Adjust; Google / Meta / Moloco / Unity 联手入股 AppsFlyer 做 "中立裁判")、Apple / Google 平台规则。
  3. 空方 (含 Adam 造假论) 对在哪错在哪: 对 -- 背离真实, 增长全靠价格, 广告主在用利润买量 (Playtika 广告费 2023-2025 +68%, 净利 $235M -> -$206M), Take-Two 说有对手 "vastly overspending in UA"。错 -- 用商店内购当买量总盘是偷换口径; 同一把尺子会同时 "证明" EY / Deloitte / KPMG / Grant Thornton 审计的四家对手一起造假, 证明过度; 最有动机揭穿 APP 的 Meta / Google / Apple 在申报里 0 次指控。
  4. 多方对在哪错在哪: 对 -- 现金与同行双重印证, 增长有机制。错 -- 把价格驱动当永久; 低估闭环的反身性 (外部每 $1 在系统里给 APP 的净收入从 0.45-0.50 放大到 0.49-0.59, 估) 与 "竞价场 + 买方工具 + 裁判" 三位一体的利益冲突。
  5. 到底谁对: 命题不同, 时间不同。"造假" 在 4-8 季尺度上不会兑现 (现金与对手方账已对上); "收入质量" 在 1-2 季尺度上更可能兑现 -- Q2 26 环比只 +4.4% 且低于预期, Playtika 把 2H26 营销最大降幅放在 Q3, Edgewater 称 MAX 份额到顶。
  6. 是否设局 / 循环做大收入: "APP 出钱让客户买自己广告" -- 不支持 (对外股权投资 2023-1H26 合计约 $115M, 关联方 Tripledot 收入 1H26 $42.9M, 合计不到年增量 3%)。"发行商用 APP 付的分成再买 APP 的量" -- 已证实存在 (CEO 电话会原话 + 应付发行商 +41% + CooTek 申报里同一家公司既从 APP 收钱又向 APP 付钱), 规模为估; 这是真钱的反身性, 不是虚构, 下行时同样放大。
  7. 动作规则: 现在 = 观察 (不进坏车, 不以造假做空)。升级为小注做空 (承重句 = 价格驱动见顶, 不是造假) 的任一触发: 2026-11 初 Q3 收入 < $2,055M 指引下沿; Q4 指引环比 < 5%; Q3 10-Q 应收 / 季收入 > 1.25 且安装量同比仍降; Apple / Google 公开执法或政策点名。撤销观察 (转多方候选): 连续两季环比 >= 8% 且 consumer 占比披露 >= 20%、应付 / 收入不再下降 (抽成不再靠挤发行商)。复核: Q3 财报后 3 个交易日内; 2027-01 AppsFlyer 游戏年报出来重算 b1 / b2; 2027-02 FY2026 10-K。

3. 反方审计 (我方 = 造假, 主审)

  1. 反方最强版本: 收入的另一端是 JOYBYTE / Gamehaus / CooTek 等广告主在 SEC 申报里写下的真实采购额, 以及 PLAYSTUDIOS / Zedge 等发行商写下的 APP 应付款; 同期四家同行由四个审计师审计, 全部两位数增长; Meta 说游戏垂类强, Google 说 AdMob 长。
  2. 五项检查 (对我方): 事实 -- "总盘没长" 只有 T3 估算撑, 且与一手数据冲突; 逻辑 -- "背离 -> 造假" 是肯定后件, 背离同样是 "价格驱动 + 份额 + 新钱" 的症状; 忽略的事实 -- 站外直充 (Playtika 39.3%)、广告变现、中国出海、同行同涨; 情绪 -- 股价距高点 -64%, 两起集体诉讼, 情绪已极端; 耐心 -- 造假无暴露时间表, (b) 的检验点就在 2026-11 初。对多方同样跑: "价格还能涨" 在 Q2 miss、Playtika 减投、Take-Two 抱怨超支面前站不稳。
  3. 先证明不是什么: 不是凭空记账 (对手方申报有对应付款); 不是拿自己的钱回流 (投资通道 < 年增量 3%); 不是编量 (安装量随大盘降)。它是: 一个同时拥有竞价场 (MAX)、最大买方工具 (Axon) 与归因工具 (Adjust) 的收费站, 靠更准的高价值用户定价与发行商回投循环收高价。风险在这三位一体能否被平台、诉讼或对手拆开。
  4. 出口: 我方承重柱 ("总盘没长 -> 钱无来源") 在事实层倒; 反方承重柱 T1 站住 -> (a) 不支持。(b) 两边都站住, 时间不同 -> 争议票: 近端空方 (价格见顶, checkpoint 2026-11 初), 远端多方 (现金真、电商第二曲线, checkpoint consumer 占比披露)。
