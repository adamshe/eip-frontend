  • 判断: 交叉格 = 周期或收租 (yaml: Yoneda 4 / 5, 必然性 2 / 4, ceiling_class standard_hw); 服务 (23%, 下行年仍正增长) 是收租底, 产品 (77%) 是 WFE 周期顶; 按 PE / PEG 与周期定价, 不付终态溢价。现价已付清 A 情景 (FY28 收入 $21.4B, OM 46%) 按 30x 零折现; 三情景 IRR FY28 末 A -0.5% 至 +8.6% / B -23% / C -44%, FY30 末 A +4.5% / B -10% / C -27%, 期望为负。空头非主张: FY27 被积压 + 指引锁定 (收入 +25% 以上几乎确定), IV 63%, 做空是与 "2027 capex 指引何时见顶" 对赌时点。
  • 五年每股 FCF (FY26 $2.85 -> FY31): A $9.11 (3.19x) / B $6.82 (2.39x) / C $4.88 (1.71x); 三年尺 (FY26 -> FY29): A 2.54x / B 1.97x / C 1.54x。本体三年会长 (B 年化 +25%), 这是种子名单候选的理由; 入场归油田规则, 现价不是。
  • 风险结构: 上行要 FY28 EPS >= $8.5 且 PE 维持 30x (即 2027 capex 再 +20% 且无人在 2028 定价回落, 两条都要对); 下行只要 2027-01 的 TSM / 存储 capex 指引平台 (先验 40%) 或 Affiliates Rule 恢复 (2026-11) 任一条, 倍数先压缩 (2022 先例: 收入 +33% 当年 PE 26.6x -> 13.9x)。与 GEV 的差别: GEV 的 2028 EPS 被 RPO 锁定, KLA 的积压 "does not provide meaningful information about the timing", FY28 EPS 本身就有 +/-20% 的分歧 (共识区间 5.81-7.95)。
  • 接货位 (鲸鱼布局 vs Fair Value A): 鲸鱼 put 地板 175-180 (2028-01 P180 / 2027-06 P175 买方), 2029-01 P240 卖方的有效接货价约 $156, 7 月低点 $170, SMA50 地板 $182 (hunt 表); Fair Value A $105 (22x) 至 $119 (25x)。三档: (a) $170-182 只做房东法卖 put 收 63% IV 的租, 不买房 (= 30x B FY28); (b) $150-160 (= 26-28x B FY28, 2029-01 P240 卖方的位置, 2026-01 至 03 平台 $142-152 上沿) 可建观察仓; (c) $105-120 = Fair Value A, 周期中值买房位, 对应 2027-28 WFE 见顶被定价之后。现价 $200 无动作 (hunt 表同判)。
  • Kill (推翻本文的空头倾向, 转 "拿着"): 10-28 12 月季指引 >= $4.6B 且 GAAP 毛利 >= 62%; 加 2027-01 TSM 2027 capex >= $60B 与 MU FY27 capex >= $35B; 加 AMAT / LRCX 1 月把 2027 WFE 说成 +15% 以上。三条全中 = A 情景, 但 A 在 30x 也只 -0.5% (FY28) / +4.5% (FY30), 转 "拿着" 不转 "买房"; 转 "买房" 还需 PE 回到 25x 以下 (价 < $165 对 B FY28)。
  • Kill (B 转 C): 10-28 收入 < $3.8B 或 12 月季指引 < $4.3B 或 积压 / 递延系统收入环比下降 或 毛利 < 60.6%; Affiliates Rule 2026-11 恢复且公司砍中国占比指引 > 5 pt; DRAM 合约价环比转负两季 (存储 capex 先砍); 连续两季 CFO / 净利 < 0.8。
