9. 结论与 kill 条件

  • 判断: 交叉格 = 结构 long (Yoneda 5/5, 必然性 4/4, ceiling_class platform, 终态 "所有先进算力的唯一物理出口, 收租但租金随算力总量自增"); 这是三份 case (LITE / GEV / TSM) 里唯一一个机制链成立且位置不在缩的, 但形态仍是收租 (代工费), 租金的增幅受自身产能与 capex 强度约束, 不受 "关系图变现" 驱动。
  • 五年每股 FCF 增幅 (FY2026 -> FY2030): A x2.44 / B x2.03 / C x1.62; 三年裁判尺 (FY2026 -> FY2029): A x2.04 / B x1.74 / C x1.41; EPS 三年: A x1.68 / B x1.37 / C x0.96。即使 C, 每股 FCF 三年仍 +41% (capex 随周期下砍), 这是 TSM 作为 "种子" 与 LITE (供给翻倍压价) / GEV (押金反向) 的本质区别: 基本面尺三情景都过 "三年长高" 门。
  • 现价对应 IRR: 到 2028 末 A +12.9% / B -6.3% / C -35.2%; 到 2030 末 A +12.0% / B -0.9% / C -15.8%; 概率加权 (A 35% / B 45% / C 20%, 估) 2028 末约 -5%, 2030 末约 +1%。结论: 基本面尺过门 (候选名单), 价格尺不过门 (现价已付清 A 情景 EPS 按 18x, 只有倍数扩张或 A 兑现才有 13% 回报) -- 进 "观察 / 等接货位", 与 yaml "拿着" 不冲突 (持有者不卖, 不加)。
  • 接货位: 鲸鱼布局隐含对冲线 $420 (2027-04 420P 4,514 张买入, -9%, SMA50 411-436) 与愿接货线 $350 (2028-01 350P 2,600 张卖出, -24%); Fair Value A $315 (18x) / $350 (20x) / $385 (22x); 接货带 $350-420: 上沿 = 鲸鱼对冲线 = 22x B 情景 FY27 EPS, 下沿 = 鲸鱼卖 put 线 = 20x Fair Value A; 在 $385 以下 B 情景 2028 末 IRR 转正 (18x), 在 $350 B 情景 2030 末 IRR +7%。
  • 勇者窗口: 不在做多现价 (IRR 期望为负, 腿到中位)。(a) 10-15 财报若 Q4 指引 < $48B 或 GM < 65% 引发 -8% 以上, 到 $420 接第一笔 (鲸鱼同一价位); (b) 2027-01-15 的 2027 capex 指引若 >= $75B 且四家 2027 capex +25% 以上 = A 情景被公司与客户同时确认, 那时现价 (若仍在 $460 附近) 的 2030 末 IRR 12% + 倍数从 18x 回到 24x 的凸性才是 "认知窗口", 鲸鱼的 2027-12 460-470C 就是押这个; (c) 持有者在 10-16 opex 前卖 $500 以上 call 收 36% IV 的租, 用 2027-04 420P 的同款做对冲线。
  • Kill (推翻 "等接货位", 转 "直接加"): 10-15 Q4 指引 >= $50B 且 GM >= 66.5% 且公司预告 2027 capex "明显高于 2026"; 加 2027-01 capex 指引 >= $75B; 加四家 2027 capex 指引 +25% 以上; 加 NVDA 2026-11 财报 supply commitments 再增 -- 四条全中 = A 情景 24x, 现价 2028 末 IRR +13%, 接货位上移到 $460 (= 现价, 即 "拿着" 变 "买房")。
  • Kill (B 转 C, 减仓到尾部仓位): temporary receipts 连降两季 (2026-09 < NT$234B 且 2026-12 再降) + 应付设备款 q/q 降; NVDA supply commitments q/q 降; 四家 2027 capex 指引持平; 任一季 GM < 60% (= 公司长期下限 56% + 海外稀释 4 pts); CoWoS 报价下降 (yaml kill #4); 232 关税落在晶圆 (yaml kill #3); Intel 拿到 AAPL / NVDA 外部量产 (yaml kill #2)。台海 (yaml kill #1): 军演常态化 -> 仓位归零, 与估值无关。
  • 工具接口: Fair Value A $315, SPR +46%; D2 建议维持 terminal 档但置信 H -> M (regime 2 条); 对账表 FY28 公司线 vs 基准差 +8% (< 30%), FY28 无共识; 升级触发 (yaml): 亚利桑那 N2 / A16 产能占比 > 10% -> 地缘折价缩 = 退出 PE 从 18x 回到 24x 的路径, 2028 前不可观测。
