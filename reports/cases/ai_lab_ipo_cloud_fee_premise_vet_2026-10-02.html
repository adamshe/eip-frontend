Vet: 超大规模 FCF 回正的前提 = AI 实验室 (OpenAI / Anthropic) 卖股票的钱付云费再记成利润? (2026-10-02)

Adam 的命题 (AO = Anthropic + OpenAI): FCF 为什么失效; 实验室 IPO 后, 卖股票的钱可以付云费, 然后在云厂商那里记成利润 -- 这是不是前提。

0. 结论

对 AMZN / GOOGL / MSFT / ORCL 的增量部分: 是前提, 置信约 75%。对 META: 不是, 它的前提是广告主付钱。 再补一处 Adam 命题没说到的: 这条资金环里有一段是云厂商自己的钱绕回来的, 那一段按定义不进 FCF 的减项, 却进 FCF 的加项, 所以 FCF 本身被抬高了; 另有一段是账面重估, 只进 GAAP 利润不进现金。

1. 拆命题 (前提 -> 推理 -> 结论)

  • 前提 1: 现在 FCF 为负是因为 capex 先花、收入后到 (META / AMZN / GOOGL 的 FY26 每股 FCF 为负)。[T1, 各家 10-Q]
  • 前提 2: FCF 回正要靠这批产能被卖掉, 即云费收入。
  • 前提 3: 增量产能的边际买家是两家烧钱的实验室。
  • 前提 4: 实验室付云费的钱来自股权融资 (私募 -> IPO), 不来自自己的客户。
  • 结论: 云厂商 2027-2029 的 FCF 回正 = 公开市场股民的钱经实验室流过。
  • 逻辑检查: 前提 1-3 有一手证据; 前提 4 是全命题最弱的一环, 取决于实验室自己的收入 / 算力承诺之比, 这个数没有一手披露 (实验室的 S-1 才会给)。推理本身有效 (无形式谬误), 结论成立的范围 = 增量, 不是存量。

3. 资金环的三层 (Adam 命题的补全)

  1. 外部钱 (真的): 实验室用股民 / 私募的钱付云费 -> 云厂商收入 -> CFO -> FCF。这是 Adam 说的那一层。
  2. 绕回的钱 (抬高 FCF): 云厂商投资实验室, 现金流量表记在 "投资活动 - 购买股权", FCF = CFO - capex 不减它; 实验室把同一笔钱付回云费, 记在 CFO, FCF 加上它。同一美元出去不扣、回来算数。AMZN 的 OpenAI 承诺里约 36% 是这一层。
  3. 账面重估 (只进 GAAP 利润): 实验室估值升 -> 云厂商持股按公允价上调 -> 非经营收益进 EPS (AMZN H1 $62.8B)。不进 CFO / FCF, 但进 PE 的分母。IPO 定价会给这一层一个公开的价: 若 IPO 低于最后一轮私募价, 这层反转成亏损。

4. 反例 (对 Adam 命题的三个最强反驳)

  • 历史同型 (支持命题, 强度高): 1999-2001 电信设备商向 CLEC 放贷 / 入股, CLEC 用这钱买设备, 设备商记收入; 2000-01 高收益债与 IPO 窗口关, CLEC 断粮, 设备商收入塌、贷款核销。形状完全一致: 供应商的收入 = 客户进入资本市场的能力。
  • 反例 1 (数据, 强度中): 实验室自有收入在长 (订阅 + 广告 + API)。若其增速快于算力承诺增速, 股权钱只是桥, 不是源。方向未定, 缺一手数。
  • 反例 2 (结构, 强度中高): 若实验室断粮, capex 可以砍, FCF 反而回升 (AMZN 报告 C 情景 FY30 每股 FCF $6.79 > B 情景 $5.81)。真正受伤的是 EPS (已建产能的折旧照摊) 与已签的租约 / 担保 (GOOGL 未开始租赁 $85.2B + 兜底 $75.5B, NVDA 残值担保 $105B), 不是 FCF 本身。所以命题对 "FCF 回正" 成立, 对 "FCF 崩" 的方向要改成 "EPS 崩 + 表外负债落地"。
  • 反例 3 (边界, 强度中): 存量 (AWS 核心、M365、搜索广告) 本身赚钱, 前提只管增量。
  • 加权: 命题对增量成立约 75%; 对存量不成立; 风险落点是 EPS 与表外承诺, 不是 FCF。

5. 对裁判尺的含义 (待 Adam 裁)

原选项 (a) 三年尺记 "不可裁" / (b) D&A 替代 capex 之外, 本 vet 给出第三个:

  • (c) 对账版 FCF = CFO - capex - 对自己客户的股权 / 贷款投资净额, 并把 backlog 按质量分三档: 现金预付 (TSM / GEV 押金) > 投资级客户承诺 > 烧钱实验室承诺且由卖方自己出资。XBRL 可机械取 (投资活动里的股权购买项), 不需判断。

6. 时点与可观测量

  • 决定性的 T1 文件是实验室的 S-1: 第一次给出收入、算力承诺、现金消耗、资金来源; 它把前提 4 从已知的未知变成已知。
  • IPO 后 6 个月 (解禁) 与第一次增发是 "第四池 (公开股权) 能否持续吸收" 的检验; 失败信号 = 破发 / 增发失败 / 估值低于最后一轮私募。
  • 云厂商侧: 预收款是否开始随 RPO 增长 (承诺变押金 = 前提变硬); 投资活动里的股权购买额; NVDA 应收天数。
