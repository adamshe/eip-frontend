1. 一句话结论

  • LLY: skip (判断类型门不过: 多头逻辑是 tirzepatide -> Foundayo -> retatrutide 的分子 / 专利接力; 关系持有人是 PBM 与处方医生, 不是 LLY)。替代镜头: 双寡头 ATL 律指向 NVO 不指向 LLY; 右轴 FY26/27/28 forward PE 32 / 25 / 22。
  • REGN: skip (范式门 + 判断类型门都不过: Eylea 关系层替换已发生; Dupixent 关系持有人是 Sanofi; 2026 全是临床 / 专利事件)。右轴 PE 13.9 / 11.9 / 10.7, 便宜有结构性原因。

6. Kill switch (skip 结论恶化, 转空头检查) / 改分触发 (可重审过门)

LLY kill switch

  1. 2026-10-29 Q3 [S44]: 美国实现价格降幅从 -3% 扩到 <= -10%, 或 Zepbound 环比负增长 -> 供应商行为确证。
  2. MARITIME-1/2 2027 初读出 [S8]: MariTide 月注射减重 >= 20% 且耐受可接受 -> 第三寡头, 双寡头律失效。
  3. Lilly Endowment 任一季净卖 > 200 万股 (13G/A / Form 4), 或新增 10b5-1 计划 > 5 人 -> 结构性卖盘升级。
  4. 2027-01-01 NVO Wegovy 挂牌价 $675 生效后 [S6], LLY 挂牌跟降 >= 40% -> 价格战开打。

LLY 改分触发

  1. LLY 披露 LillyDirect 活跃患者数且 >= 美国 tirzepatide 患者 1/3, 附续方留存 -> 关系持有人变 LLY, 重审判断类型门。
  2. 2026-10-01 CVS 恢复后两季内 (2027-04 前), Zepbound 在 CVS 覆盖人群份额回到 >= 50% -> 关系在患者 / 医生端而非 PBM。
  3. NVO 跌破 $35.12 且 LLY / NVO 市值比 > 8x -> 双寡头 ATL 律触发, 受益对象是 NVO (另开 vet), 不是 LLY。

REGN kill switch

  1. 2026-10-30 Q3 [S44]: Eylea + Eylea HD 美国合计 < $950M (Q2 $1,008M) -> 存量替换快于 HD 换代。
  2. 2026 Q4 三家类似药上市后 [S15], 2027-Q1 Eylea HD 环比转负 -> HD 未能承接。
  3. odronextamab / cemdisiran 2026-11 PDUFA 任一 CRL [S10] -> 管线接力叙事受损。
  4. Dupixent 2027-10 美国组合物专利被 IPR 挑战成功, 或 Sanofi 分成条款变更 [S23][S24] -> 最大现金流源受损。

REGN 改分触发

  1. REGN 拿回 Dupixent 商业化主导 (或买断 Sanofi 份额) -> 关系持有人变 REGN, 重审范式门。
  2. COURAGE 组合 (semaglutide + trevogrumab) 进三期且换用自有 GLP-1, 不依赖 NVO 供药 -> 肥胖第三层位置。
  3. 股价回到 $541 区域且单季回购 > $2B -> 转现金流 / 回购标的 (非本框架类别)。
