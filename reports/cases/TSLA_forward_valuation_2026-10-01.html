9. 结论与 kill 条件

  • 判断: yaml ceiling_class = standard_hw (封闭产品), D1 single_hub 且位置在缩; 交叉格 = 终态叙事期权 (不是收租: 无拒绝权, 毛利 15-20%; 不是周期: 增长靠新品类); 按 PE 与里程碑二元事件定价, 不付位置溢价。现价 $354 已高于 A 情景 2030 末 60x 的折现值 $282: 即使公司自述全兑现, 到 2030 末 IRR 也只有 +7.6%, 低于 13.5% 折现率; 上行只在 A + 退出倍数维持 100x (IRR +21%)。
  • 裁判尺: 每股完全稀释 FCF FY26 -> FY29 三情景都由负转正或仍为负 (A -2.52 -> 2.04 / B -2.58 -> 0.41 / C -2.98 -> -0.37), 对 FY25 基数 $1.76 三年后 A 1.16x / B 0.23x / C 负; 五年 (FY25 -> FY30) A 3.2x / B 1.04x / C 0。种子尺不过: 本体三年不长, 这是 capex 超周期的必然结果, 不是经营失败。
