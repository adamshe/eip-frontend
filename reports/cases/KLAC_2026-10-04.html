分析

终局总结

  1. 为什么跌 (2026-06-30 $301.37 -> 07-29 $170.00, -43.6%): 跌的是估值不是业务 -- 07-28 财报里 CEO 说动能 "accelerating in the second half of calendar 2026 and continuing through 2027" (8-K, T1), 股价照跌; 同期 AMAT -39.6%、LRCX -41.8%, 是设备板块高 beta 出清, 跌掉的是 2025-04 至 2026-06 比 SOX 多涨的部分 (+423% 对 +296%); 卖方只降目标价不降级 (T3); 内部人 10b5-1 一路卖、零买入 (Wallace 08-11 $17.4M @ $198.95, 09-15 $12.4M @ $171.88, T1)。
  2. 为什么止跌、为什么涨 (09-16 $167.36 -> 10-02 $206.89, +23.6%): 机制无一手证据, 不归因。可见的: 回撤到浪 1 (02-04 $130.24 -> 06-30) 的 78.3%, 未破 0.786 失效线, 低点 RSI 32-37; 但卖压枯竭门不过 (低点前日均量为破位日的 37%, 门槛 30%)。10-01 期权流: 2028-01 C260 买方新开 $1.28M, 同时 P175 / P180 买保护 -- 鲸鱼买的是一波冲高的凸性加地板, 不是持有到 2030 的结构。
  3. 必然性: N = 2 / 4。锁死的: 任何节点都要检测, 不检测的终点是良率死亡 (N1 = 1); 2nm / GAA / HBM 抬强度、服务随装机自增 (N4 = 1)。没锁死的: 替代路径 (10-K: "In each of our product markets, we have many competitors", N2 = 0); EUV 光罩 actinic 子层在 Lasertec 手里 (T3, N3 = 0)。强度上升提高的是用量, 不是独占, 所以交叉格 = 周期或收租, 不付终态溢价。
  4. 2027 第二波是不是真的: 业务层 可疑 (偏强) -- 积压一年 +60% 到 $12.57B、Q1 指引同比 +25%、SEMI 预测 2027 WFE +21.8% (T3)、TSMC 亚利桑那 Fab 2 / SK hynix 龙仁 Y1 / Samsung Taylor 新厂集中在 2027 爬坡、韩国收入 +26.2% 增速最快。但替代已写进共识 (FY27 收入 +33%), 中国退出 (29.8% 收入) 还没说出口; 中国若降 25%, 非中国收入要 +58% (估), 远高于 SEMI 的 DRAM +27% / 逻辑 +18%。
  5. 空方对在哪、错在哪: 对 -- 周期在减速 (SEMI 2026 +23% -> 2027 +22% -> 2028 +14%; MU 单季收入 $54.2B 对上年同期 $11.3B 是顶部特征), 中国 30% 挂在 11 月规则上, 估值第 94-96 百分位, 对手更快 (Nova +31% / Camtek +16% 对 KLAC +12%), 10-K 自认客户可能降采样率。错 -- FY27 被积压 + 指引锁定, 收入 +25% 以上几乎确定; 做空是与 "2027 capex 何时见顶" 对赌时点, IV 63%, 赔率不在空方。
  6. 多方 (含 Adam 第二波判断) 对在哪、错在哪: 对 -- 强度上升有公司原话; 2027 新厂整套检测机群的一次性采购是真机制; 毛利穿越周期, 收费能力 "部分是 ASML" (已证实)。错 -- 把用量当独占; 没计入价格已付 (A 全兑现到 FY28 末 IRR -0.5% 至 +8.6%, B -23%, C -44%) 与中国退出尚未发生。
  7. 到底谁对: 按时间尺度 -- FY27 业务层多方对 (可疑偏强); 价格层空方对 (已证实: 自身第 94-96 百分位 + 倒算期望为负); FY28-29 的风险是 WFE 回落 (先验 60%, 估) 与中国。四份材料方向一致 (观察 / WATCH, 不建仓); 动作细则冲突时以 10-04 两份为准: 估值百分位是 10-01 没有的硬证据, 所以 10-01 的 "$170-182 卖 put 收租" 作废 (见下文 "动作细则冲突的裁定")。

  9. 动作规则: 现在 WATCH: 不接货、不卖 put、不追反弹。条件 (a) 中国下调说出口 + (b) 同季非中国增速 >= 中国降幅 1.5 倍 + (c) 当年 PE <= 自身第 20 百分位 (约 $72-103, 估) + (d) 回撤 >= 10% 且 RSI < 50 同时成立 -> 房东卖 30-60 天 delta -0.25 至 -0.35 的 put 起步; 再加必然性 >= 3 (actinic 夺回) -> 才升买房 / 浪 2 加仓。失效: 2028 WFE 预测转负或 DRAM 合约价环比转负、毛利连续两季 < 60%、actinic 2027 未出货 -> 不进场或全出。复核: 2026-10-28 (估) / 2026-11-10 / 2027-01-29 (估)。

本体: 为什么按 "周期或收租" 定价

KLA 的收费能力是真的: 毛利三年穿越周期, 服务 23% 在下行年仍增长 (FY24 +10%), 这是 "周期在量不在价", 与 MU / SNDK 的 "毛利即周期" 不同类。但位置不是物理锁死: 10-K 自述每个市场多个对手, 锁的是配方与机群匹配 (习惯 + 合同), 子层 actinic 已被 Lasertec 拿走, 所以 N2 = N3 = 0。Yoneda 五条过四条 (强制通行只算弱过, 份额全 T3), 第 5 条 "尚未被定价" 不过 -- 右轴 PEG 从 FY27 0.80 回到 FY28 1.26 就是它的定量形式。D1 反方 (multi_host, 光学检测近 ASML 级) 只有 T3 单源, 不改判。职业 CEO 持股 0.03%、五个月套现 $47.9M, F = 0, 凹赔付。所以按 PE / PEG 与周期定价, 不付终态溢价; 判断类型门 "过 (有保留)" 待 Adam 裁 (security-taxonomy 把 KLAC 归非 Yoneda host)。

是不是第二个 ASML (ASML 节 + 第二波第 5 问)

部分是: 像的是收费能力 (毛利穿越周期 + 23% 服务收租), 不像的是位置必然性 (N 2 对 ASML >= 3) 与错价。没有 ASML 式错价的三条证据: (a) 估值起点相反, ASML 700 时在自身第 6 百分位, KLAC 09-16 低点仍在第 88 百分位、现价第 94-96; (b) 叙事相反, ASML 是公司说 "不能确认" 而订单比叙事强, KLAC 是 CEO 说加速而股价照跌 = 好叙事已被定价后的估值出清; (c) 相对表现, KLAC 与 AMAT / LRCX 同步下跌, 是板块高 beta 出清, 不是个股折价。替代的可见度与时序也相反: ASML 的存储订单在 700 时写在演示里却被忽略, KLAC 的替代已在共识 +33% 里; ASML 的中国退出发生在上涨途中, KLAC 的还没说出口。形态对应 ASML 2024 的失败浪 2 (当时估值也在第 71-94 百分位), 不是 2025 的 700。五门: 本体门、情绪门不过, 鲸群门数据不足, 结构门 (贴边) 与时间门过。反方 "支持是" 的三条 (毛利定价权 / 光学检测 > 85% / 对 SOX 比值第 8 百分位) 只采信第一条为 "部分是"。真值: "不是第二个 ASML" 在位置与估值两层 已证实, "部分是" 在定价权一层 已证实。

2027 第二波: 替代不对称

业务层的第二波机制是真的: 新厂整套检测机群在 2027 集中采购, 强度随 2nm / GAA / HBM 上升, 积压加指引已锁住 FY27。问题在先后: 替代 (存储 / 新厂 / 先进封装) 已被看见并写进共识, 退出 (中国 30%) 还没被说出口。替代先定价、退出后定价, 下一个价格事件的方向偏下; ASML 式窗口只能出现在 "退出被说出口 + 价格掉进估值门" 之后, 这就是要点第 4 条四个条件的来源。上限在 WFE: WFE 受客户 capex 对现金流比例约束 (MU 0.34, TSM 约 0.6 估); 存储 capex 翻倍 (MU FY26 +94%) 的历史后果是两年内回落, 2027-28 为 WFE 周期顶的先验 60% (估), 而共识 FY28 仍 +18%, 没有人在模型里放回落。

估值与情景: 现价付了多少

现价按 30x 零折现已付清 A 情景 (FY27 +33%, FY28 +18%, 营业利润率 46%), 对 FY29 回落、中国管制、DRAM 成本、CEO 换届零折价。三情景按 $200.33 倒算 (折现 11.7%): FY28 末 A -0.5% (30x) 至 +8.6% (35x) / B -23% / C -44%, FY30 末 A +4.5% / B -10% / C -27%, 期望为负。要 15% IRR, 2028-06 价须 $256 = FY28 EPS $8.5 (30x), 相当于 A 的 FY30 收入提前两年。本体三年确实会长: 每股 FCF FY26 $2.85 -> FY29 A 2.54x / B 1.97x (年化 +25%) / C 1.54x, 这是留在种子名单的理由, 但入场归估值规则, 现价不是。风险结构不对称: 上行要 FY28 EPS >= $8.5 且 PE 维持 30x 两条都对; 下行只要 2027-01 TSM / 存储 capex 平台 (先验 40%) 或 Affiliates Rule 恢复任一条, 倍数先压缩 (2022 先例: 收入 +33% 当年 PE 26.6x -> 13.9x)。与 GEV 不同, KLA 的积压不提供确认时点, FY28 EPS 共识区间 5.81-7.95 本身就有 +/-20% 分歧。空头也不是主张: FY27 被积压与指引锁定, IV 63%, 做空是赌 "2027 capex 指引何时见顶" 的时点。

接货价的三把尺: Fair Value A $105 (B FY28 x 22x 折现) 至 $119 (25x), 无战略资本 K, SPR 10-01 为 +91%, 按 10-02 价约 +97% (算); 自身第 20 百分位价 FY27 口径约 $72-84、FY28 口径约 $89-103 (估); 鲸鱼地板 175-180 与 2029-01 P240 卖方有效接货价约 $156。前两把尺在 $89-119 一带重合, 第三把是鲸鱼的护盘位, 不是价值位。

情景概率 (已知的未知的先验, 全为估): Q1 FY27 超指引中点 55%; 2028 下半年起 WFE 回落 60%; 两年内中国占比 < 20% 40%; 强度每年 +0.2-0.3 pt 60%; 下行年服务仍 +5% 以上 75%; 232 关税落地 40%; DRAM 成本压毛利 0.5-1.0 pt 70%; actinic 2027 出货 50%; TSM 2027 capex >= $56B 65%。regime 类三条 (WFE 周期 / 中国 / 关税) 使 D2 置信降一档。基准 B 已含 FY29 回落 -7%; 期望值的方向由两条 regime 决定 -- 2027-01 TSM / 存储 capex 指引平台 (先验 40%) 与中国规则恢复, 任一出现倍数先压缩。

动作细则冲突的裁定 (以哪份为准)

三份的现在动作一致 (不建仓), 细则冲突三处:

  1. 10-01 估值给三档接货位: (a) $170-182 只卖 put 收租, (b) $150-160 建观察仓, (c) $105-120 Fair Value A 买房位。10-04 ASML 节: 当年 PE 百分位 > 20 或必然性 < 3 -> 不接货、不卖 put。以 10-04 为准: $170-182 仍是 FY27 约 31-33x (算), 远在自身第 20 百分位之上, 10-01 报告当时没有百分位读数。(a)(b) 档作废; (c) 档与第 20 百分位价 (FY28 口径 $89-103) 衔接, 保留作参考。
