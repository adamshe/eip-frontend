估值: 剔除 Anthropic 后贵不贵

两把尺读数相反, 不矛盾。相对尺: 干净 FY26 PE 30.9x (10-02) 是 2016-2025 第 7.2 百分位, 浪 2 估值门据此判过。绝对尺: 五年倒算把 D&A 从 capex 时间表推出来 -- 服务器 5 年直线, capex 约 $220B/年, PP&E 折旧 2025 $41.9B -> 2027 $109B -> 2030 $186B (B 情景, 估); EBITDA 2025 $122B -> 2030 $321B 长 2.6x, 但 B 情景每股利润五年只长 19%, 长的是 EBITDA 不是 EPS。相对尺偏松的机制: AMZN 历史高 PE (2021 52x, 2023 46x) 出在低利润率年代, AWS / 广告占比上移后, 同样 PE 对应的增长更低; 系统护栏 "PE 第 0 vs PS 第 66" 的背离约一半来自 Anthropic 重估进了 GAAP 共识, 另一半就是这个结构因素。

远端以绝对尺为准: 现价已按 22x 零折现付清 A 情景 (RPO 全兑现 + capex 2028 后趋平 + AWS EBITDA 率升到 64%); 情景概率取 A 30 / B 50 / C 20 (估), 加权 IRR 约 -5%; 15% IRR 要 FY30 EPS $16 (28x), A 情景 $14.39 也不到。最可能先动的数是共识 FY27: $10.51 比 B 基准 $8.39 高 25%, 差在没算满 2027 D&A +$24B, 2027-02 的 capex 口径是它的检验日。接货位由此分两档: 信 A $220-235 (A 情景 15% IRR 位 $222), 信 B $150-175 (Fair Value A $153 至 25x 折现 $174)。FCF 尺有盲点: C 情景 FCF 最高是 capex 砍 $95B 换来的, 同期 EPS 0.64x, 所以 "FCF 转正" 先问是增长还是停投资。做空不主张: RPO 锁收入, 空头只能赌倍数。

本体与必然性

零售侧是终态位置: 买家 - 卖家双边图 (3P 件数 61%), 付费件数 +17% 快于美国电商 +12.2% = 份额在升; 自建物流让 UPS 让出 > 50% 件量, 配送层也在自己手里。Yoneda 五条过四条 (强制通行 / 拒绝权 / 按构造自增 / 组合收费过, 尚未被定价不过); 可行绕路三条 (Walmart / Shopify 直营 / Temu-TikTok), N2 = 0; agent 代购层攻的是入口 (U8)。AWS 侧是 "位置在缩" 的收租: Trainium 把长约单价压到现货约一半, 换来 OpenAI / Anthropic 的 GW 级承诺 (合计 >= $238B, 约占 RPO 一半), 但客户自建、neocloud 与另两家云同步满产; 合同是承诺不是押金 -- 预收款 $25.0B 没同步增, 芯片性能条款给对手方留了退路, AMZN 先出 capex 再收钱。必然性 N1 1 / N2 0 / N3 1 / N4 1 = 3/4, 交叉格 = 结构 long 候选, 不付唯一终态溢价, 失格 F (已被定价) 对 AWS 段适用。拐点在 2027: D&A 跳升而 OpenAI 的 2 GW 合同 2027 起才确认, FCF 2026-27 为负, 2028 转正, 回购为零、股数年增约 1%。

IPO 是不是催化剂
