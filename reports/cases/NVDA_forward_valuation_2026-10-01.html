9. 结论与 kill 条件

  • 判断类型: 交叉格 = 周期 + 平台收租 (Yoneda 3 / 5, 必然性 2 / 4; yaml ceiling_class platform, 失格 E 位置在缩; 终态 Intel 路径 vs AWS 路径两分叉)。CUDA 装机与网络 / 软件是收租底, 加速器系统是周期顶; 按周期 PE 定价, 不付终态溢价。
  • 五年每股 FCF 增幅 (FY26 $3.94 -> FY31): A 6.5x / B 4.1x / C 2.0x; 三年裁判尺 (FY26 -> FY29): A 4.8x / B 3.4x / C 2.0x; 参考 EPS 三年: A 4.2x / B 2.8x / C 1.5x。本体三年必长高 (FY27 已锁 1.9x), 种子尺 NVDA 过线; 分歧在 FY28 后斜率。
  • 现价对应 IRR: 到 FY28 末 A +52% / B -2% / C -44%; 到 FY30 末 A +27% / B +1% / C -27%; 以先验 A 30% / B 45% / C 25% 加权, FY30 期望 IRR 约 +2%, 即现价公允于 B, 赌注是 U2 (2027 capex regime) 与 U3 (份额) 的二分叉。与 GEV / LITE 不同: NVDA 不是 "已付清 A", 是 "付清 B, A 与 C 都没付", 所以上下都是胖尾: A 兑现是 +27-52%, C 兑现是 -27-44%。
  • 风险结构: 上行要 2027 五家 capex 指引合计 +40% 以上 且 份额守住 65% 且 毛利 >= 73% (三条都要); 下行只要 任一超大规模 2027 指引持平 或 AVGO + AMD 增速持续两倍于 NVDA 或 一笔循环融资对手违约 (任一条), 倍数先压 (MU 5x 是周期顶倍数的实证)。
  • 接货位: 鲸鱼领口地板 $180 (2028-01 / 2029-01 P180 买方, delta 0.19-0.20) 与 Fair Value A $187 重合; 52 周低 $164.79 (2026-03-30); 2027-06 P140 OI 144.6K 是市场的崩塌地板。接货区 $165-190 = 11-12x 共识 FY28 / 13-15x B 情景 FY28, 下沿 $150 (2027-06 P150 OI 49.8K); 现价 $230.86 不是入场, 是 B 公允。持有者动作 = 跟鲸鱼: 卖 2028-01 C400 / 2029-01 C360 收租, 买 P180 保地板。
  • 勇者窗口: 不在现价做多方向; 窗口在 U2 揭晓前后 (2027-01 下旬至 02-25 NVDA Q4 FY27 财报): 若四家 2027 capex 指引合计 +40% 以上且 NVDA Q4 指引 >= $130B 而股价仍在 $230 以下 = A 情景按 B 价卖, IRR +27-52%, 时点在那两周; 反之若任一家持平而股价仍 $220+, 是 C 情景按 B 价, 做空 / 买 2027-12 P200 的窗口。
  • Kill (推翻 B 中性, 转 A "买房"): (1) 2027-02 前 MSFT / GOOGL / META / AMZN 2027 capex 指引合计 >= $1.0T (+40%) 且 ORCL FY27 capex >= $100B; (2) NVDA Q4 FY27 指引 (2027-02-25) >= $130B 且毛利指引 >= 74%; (3) AVGO FY27 AI 收入增速 < NVDA DC 增速 (份额企稳)。三条全中 = A, 目标 2028-01 $399 / 2030-01 $511。
