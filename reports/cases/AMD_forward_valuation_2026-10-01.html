3. 两重验证

3a 定性: 机制链

环节判断证据
谁必须买三家 AI 实验室各 1 GW 有约束力 (原文 "binding commitment"); 五家超大规模 2026 capex 约 $680B (估, 五家合计) 且 2027 承诺已签 (META 2027 到期 $81.7B); NVDA 自述供应受限 + $279B 产能锁定 -> 客户必须有第二供应商[8-K 10-06 / 02-24 item_1_01]; [META / GOOGL / AMZN / MSFT / ORCL filing]; [NVDA 10-Q]
为什么必须经 AMD不必须。商用 GPU 层的关系持有人是 NVDA (CUDA / NVLink); 客户自研 ASIC 攻同一层; AMD 是 "价格锚 + 供应保险" 的第二供应商, 客户以 $0.01 warrant 换采购 = 拒绝权在客户手里。服务器 CPU 层是真位置: x86 双寡头之一, 对手在涨价 48%[10-K item_1a 自认 Nvidia 生态 / 客户自研]; [INTC 10-Q]
替代与物理上限(a) NVDA 降价或供给追上 (Rubin 量产, $279B 产能承诺挤占 CoWoS / HBM); (b) 客户 ASIC; (c) 电力 / 厂房限制 GW 落地节奏; (d) 资金: capex 已转股债融资 (GOOGL 发股 $49.6B, AMZN TTM FCF 负举债 $82B, META 票据 $84B) = regime 风险; (e) HBM 供给 (MU 前瞻 EPS $205 = 内存卖方市场)[NVDA 10-Q]; [GOOGL / AMZN / META 10-Q]; yfinance
拐点2027 是三家首 GW 同时落地的首年, FY27 收入增速见顶是基数的必然; 2028 加速器周期是否见顶看 2028-01/02 的 capex 指引; 稀释 (warrant vest) 2027-2029 随 GW 交付逐批出现, 与收入同步[8-K warrant 条款]; [10-Q note_12]

9. 结论与 kill 条件

  • 判断: 交叉格 = 低位置 + 条件必然 = 行业 beta (AI 算力第二供应商), 与 yaml type structural / ceiling_class standard_hw 一致; CPU 层是真收租 (x86 双寡头 + 对手涨价 48%), GPU 层是周期 + 客户用 warrant 买走拒绝权。本体: B 情景三年每股 FCF 2.4x (FY26 $5.25 -> FY29 $12.53), 五年 2.5x; A 4.0x / 4.3x; C 1.0x / 0.9x -- 种子是活的 (3 GW 约束力 + CPU 盘子涨价)。价格: 现价 IRR 到 FY28 末 A +4.8% / B -27% / C -59%, 到 FY30 末 A +1.7% / B -17% / C -42%, 期望为负; 即使 A 全兑现也只有国债收益。与 GEV 的差别: GEV 的 EPS 被 backlog 锁定、风险在倍数; AMD 的 FY28 EPS 本身有三条杠杆 (稀释 / ASP / 配额) 可以砍掉三分之一, 风险在分子也在分母。
  • 风险结构: 上行要 FY28 非GAAP EPS >= $28 (14 GW 在 2028 前全交付、GM 57%+、稀释 < 5%) 且 PE 维持 30x, 三条都要对; 下行只要 2027 capex 平台、或 NVDA 降价 (GM < 70%)、或 CoWoS 配额缩任一条, B 直接转 C。空头非主张: 11-03 财报 60% 超预期, IV 50%+, call 墙 630, 2028 远月卖 put 的鲸鱼在接。
  • 勇者窗口: 不在做多现价。(a) 接货位: Fair Value A $236 (22x) 至 $268 (25x) 是 B 情景的价; B 情景 FY28 EPS x 25x 零折现 $346 与 FY27 共识 x 25x $390 之间是房东法接货区 $300-390 (估), 需现价 -40% 到 -50%; 鲸鱼布局隐含的接货位 $444 (2028-12 P600 保本) 与 $560 (2027-06 合成多头成本) 是 A 情景的价, 不跟。(b) 持有者在 $600+ 做收租: 卖 2028-12 $1,000 call (IV 62%, 约 $130) 或 2027-01 $800 call; 不卖 put。(c) 同链错价候选: NVDA 前瞻 14.7x 对 AMD 39.5x, 同一客户同一 capex, 关系持有人反而便宜 (未 vet); INTC 涨价 48% 的 CPU 盘子 (未 vet)。
  • Kill (推翻本文空头倾向, 转 "拿着"): 11-03 财报 Q4 指引 >= $15.5B 且 DC >= $9B 且非GAAP GM >= 57%; 2027-03 前 10-Q 披露 warrant 首档 vest (= 1 GW 交付实证); 2027-01/02 四家 2027 capex 指引 +30% 以上; NVDA GM 保持 >= 73% (不降价)。四条全中 = A 情景 35x, IRR +12%。硬数字 + 日期: FY27 收入 >= $88B 且非GAAP EPS >= $16 (2028-02 财报); FY28 非GAAP EPS >= $28 且稀释股 <= 1,750M (2029-02)。
  • Kill (B 转 C): 任一季 DC 收入 q/q 下降; 10-K FY26 (2027-02) 采购义务 2027 列低于 $5.5B; NVDA GM < 70%; 超大规模 2027 capex 指引持平; OpenAI 采购延后公告或应收集中 > 25%; 出口管制再收紧。
  • 工具接口: Fair Value A $236, SPR +161%; 对账表 FY28 公司 (A) vs 基准差 +36% > 30% 且 regime 4 条, D2 不取上限; D4 建议 circular_financing -> true (对 Anthropic 出资 $5B + 采购), insider_10b5_1_sell -> true (Su / Papermaster / Norrod / Hu 10b5-1 卖 $300M+); 本文不改 yaml, 交主线程。
